# GameDev Atlas · 全平台上架手册（含网络游戏专项）

> **迭代第 ⑧ 轮**。定位：从"做完游戏"到"各平台上架"的完整流程地图——国际 PC/主机/移动、国内渠道、小游戏，以及**网络游戏专项**（版号、防沉迷、实名、运营资质）。
> **时效声明**：平台政策与监管规则持续变化；本文信息核实于 **2026-10**，行动前请以官方最新文档为准。涉及监管事项建议通过正规出版代理/法务渠道办理。
> 配套：《避坑大全》（⑥）、《法务、专利与竞争手册》（⑦）、《资源大全》（含各平台官网链接）。

## 3. PC 平台

### 3.1 Steam（十步流程）

1. 注册 Steamworks 开发者账号，支付每款 $100 应用费（销量达 $1000 后返还）。
2. 完成税务与银行信息（W-8BEN 等）→ 决定收款主体。
3. 创建应用 → 制作**商店页**（胶囊图、截图、预告、标签、描述）→ 提交商店页审核（建议尽早公开，积累愿望单）。
4. 接入 Steamworks SDK：成就、云存档、排行榜、创意工坊（按需）、Steam Input。
5. 用 steamcmd 上传构建（depots 管理分支：default/beta）。
6. 提交**构建审核**（Build Review）；有问题按反馈修改再审。
7. 设置发售日期（可随时改）；发布前 2 周开启鉴赏家/媒体资源。
8. 配置区域定价与首发折扣（参考《资源大全》定价工具与同类型定价带）。
9. 发布：核对所有语言页面、系统需求（含 Steam Deck 兼容性评级）、退款政策提示。
10. 发售后：热修流程走 beta 分支验证 → 推进 default；用 Steamworks 数据看转化与区域表现。

> 注意：AI 内容披露在 Steamworks 内容调查中完成（预生成/运行时生成两类，见设计文档 §14.9）；商店页素材规范与"即将推出"页面越早越好。

### 3.2 Epic Games Store

- 通过官方表单申请入驻 → 签数字发行协议（88/12 分成）→ 提审商店页与构建；可申请 EOS（Epic Online Services）免费联机服务。
- 官方入口：https://store.epicgames.com/ （开发者：https://dev.epicgames.com/ ）。

### 3.3 GOG

- 官网提交申请（人工筛选，偏好 DRM-free 与完成度高的作品）→ 商业条款谈判 → 上架；适合精品独立与经典游戏。

### 3.4 itch.io

- 注册即发布：上传构建、自定义页面与定价（可"自由定价"）、支持 Pay-What-You-Want；最适合原型、Jam、早期测试与社区运营。

### 3.5 Web 游戏平台（HTML5）

- **CrazyGames**：开发者门户 https://developer.crazygames.com/ ，侧重可玩性与性能审核，广告分成模式。
- **Poki**：开发者平台 https://developers.poki.com/ ，审核严格，注重移动适配与加载性能。
- 适合轻量玩法；上架前务必做移动浏览器兼容与加载优化。

### 3.6 国内 PC（WeGame / 蒸汽平台）

- 均需要**版号**与完整合规材料；WeGame（https://www.wegame.com.cn/ ）另有平台独占政策沟通；蒸汽平台（https://store.steamchina.com/ ）为国内合规发行版。

## 4. 主机平台（共性流程）

1. **申请入驻**：ID@Xbox（https://www.xbox.com/en-US/developers ）、PlayStation Partners（https://partners.playstation.net/ ）、Nintendo Developer Portal（https://developer.nintendo.com/ ）。
2. **概念审核/孵化**：提交 pitch 与可玩 demo；通过后签署 NDA 与开发协议。
3. **开发机与认证**：获取开发套件；对照平台技术要求（TRC/TCR 等）开发。
4. **认证（Certification）**：提交候选版本送审——重点检查：异常处理（拔线/断电/满存档）、UI 规范、多语言、成就、家长控制。
5. **发布**：商店页、年龄分级、区域与定价→ 首发。

> 认证是主机上架最大的时间变量：预留 **2-6 周**（首次可更久）；认证失败要改完重排队，发售日应留缓冲。

## 5. 移动平台

### 5.1 App Store

- 流程：Apple 开发者账号（$99/年）→ App Store Connect 建档 → 元数据与截图 → TestFlight 内测 → 提交审核 → 发布（手动/自动）。
- **中国区**：游戏类上架**必须提供版号**（无版号不能上架，海外发行不受此限）。
- 常见拒因：4.3（重复/换皮）、2.1（完成度不足）、3.1（绕开 IAP）、5.1（隐私标签/ATT 不一致）、素材侵权。
- 审核指南：https://developer.apple.com/app-store/review/guidelines/

### 5.2 Google Play

- 流程：开发者账号（$25 一次性）→ 创建应用 → 数据安全表单、内容分级（IARC）、目标 API 合规 → 测试轨道（内部/封闭/开放）→ 生产发布。
- **新个人开发者账号**：申请生产发布前需先完成**封闭测试（至少 12 名测试者、连续 14 天）**——政策随版本调整（部分时期/说明为 20 名），以 Play 管理中心最新说明为准：https://support.google.com/googleplay/android-developer/answer/14151465
- 常见拒因：数据安全表单与实际不符、权限滥用、商店素材侵权。

### 5.3 国内安卓渠道（TapTap / 应用宝 / 华为 / 小米 / OPPO / vivo / 好游快爆）

- 共同点：**企业主体 + 软著 + 版号**（正式商业化）；各渠道有独立开发者后台与上架材料流程。
- 流程概要：注册渠道开发者账号 → 提交资质（营业执照/软著/版号）→ 传包（渠道可能有加固/签名要求）→ 渠道审核 → 首发/联运配置。
- TapTap（https://developer.taptap.cn/ ）：含 PC 分发与社区运营；好游快爆（https://open.3839.com/ ）：侧重测试与预约。

## 6. 小游戏平台

### 6.1 微信小游戏（规则最细，以官方为准）

- 主体：个人主体可发布**免费**小游戏（广告变现）；**付费游戏仅企业主体**。
- 资质：**开通虚拟支付（IAP）需提交版号（网络游戏出版物号核发单）+ 软著 + 授权书**；不开通支付的免费游戏不需要版号（平台统一协助接入实名系统）。
- 接入防沉迷：开通虚拟支付的企业须在中宣部实名认证系统（https://wlc.nppa.gov.cn/fcm_company/index.html ）完成企业注册、添加游戏、渠道绑定，并同步信息至微信平台（指引：https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iap.html ）。
- 审核要点：类目选择（游戏类目不可改）、内容合规、不得绕开虚拟支付（不得引导外部支付）。
- 发布流程：开发者工具上传 → 提审 → 发布；支持测试版/体验版分流。

### 6.2 抖音小游戏

- 字节开放平台（https://developer.open-douyin.com/ ）注册 → 小游戏类目资质 → 接入实名与防沉迷 → 提审发布；分发依赖短视频+直播挂载，运营打法与微信不同。

### 6.3 快手 / 华为 / OPPO / vivo / 小米 / 百度

- 均为开放平台注册 → 资质提交 → 提审发布；资质要求与微信类似（软著为底，支付类需版号）；各平台流量特征不同，建议按"1 主 + 1 辅"集中运营。

## 7. 网络游戏专项（国内，重点）

### 7.1 网游与单机：上架合规差异

| 事项 | 单机（国内渠道） | 网络游戏 / 含内购 |
| --- | --- | --- |
| 软著 | 需要 | 需要 |
| 版号（ISBN） | 国内正式渠道需要 | **需要，且收费运营必须** |
| ICP 备案 / 许可证 | 一般网站备案 | 运营机构需 ICP 证（申报版号材料之一） |
| 防沉迷 / 实名 | 联网即需 | **强制**（接入中宣部系统） |
| 概率公示 | 如含抽卡 | **强制公示概率与保底** |
| 内容自审 | 自行把关 | 需自审制度与自查报告 |

### 7.2 版号申请全流程（网络游戏出版物号）

**前置条件**：

1. 著作权：软著登记证书（或符合要求的著作权文件）；**著作权人须为中国公民或内资企业**。
2. 运营机构：营业执照 + **ICP 证**（电信与信息服务业务经营许可证）；出版单位须具网络出版服务资质（通常通过有资质的出版社/代理申报）。
3. 游戏完成度足够：可运行版本、稳定服务器、完整内容。
4. 内容合规：不得含违规内容（政治/宗教/色情/赌博等红线），备好**中文脚本全文 + 屏蔽词库**。

**申报流程**：准备材料 → 提交至**省级出版管理部门** → 省级审核同意后报**国家新闻出版署** → 审批 → 批文与版号下发。（进口游戏另走"境外著作权人授权"通道，材料含国家版权局著作权合同登记批复等。）

**主要材料清单**（以官方最新要求为准）：省级请示文件、出版申请书/申请表、审读报告、著作权证明、营业执照 + ICP 证、游戏截图（≥10 张含主界面）、中文脚本全文与屏蔽词库、防沉迷系统设置说明、审查测试账号（高/中/低等级）、演示视频（含健康游戏忠告、战斗展示等）、客户端/安装包等。

**时限与节奏**：法定审批时限自受理起 **80 个工作日**（省级环节另有审核时间），实际从准备到拿号通常按月计（审批结果按月公示：https://www.nppa.gov.cn/bsfw/jggs/yxspjg/ ）。**提前 6-12 个月规划版号**。

**注意**：一款游戏一份申报；版本重大变更需变更申报；上线运营后按规定时间向属地报告运营信息。

### 7.3 防沉迷与实名认证（强制）

- **接入系统**：中宣部（国家新闻出版署）**网络游戏防沉迷实名认证系统**：https://wlc.nppa.gov.cn/fcm_company/index.html ——企业注册 → 添加游戏（名称/批文号/ISBN）→ 渠道绑定 → 游戏内接入实名与数据上报。
- **未成年人保护规则**（成年人不受限）：仅可在**周五、周六、周日及法定节假日 20:00-21:00** 游玩 1 小时；**充值限额**：未满 8 岁不可充值；8-16 岁单次 ≤50 元、每月 ≤200 元；16-18 岁单次 ≤100 元、每月 ≤400 元；不得提供游客模式的付费与充值。
- 无版号/未接入系统的收费运营属于明确违规（见《避坑大全》§8）。

### 7.4 其他运营资质

- **ICP 备案/许可证**：网站与服务器域名备案；收费运营需 ICP 许可证（版号材料之一）。
- **网络安全等级保护（等保 2.0）**：含用户数据与联网服务的系统，按当地要求完成定级备案与测评（尤其较大体量产品）。
- **网络文化经营许可证（文网文）**：游戏相关审批历经改革，**是否办理以属地文化和旅游主管部门最新口径为准**。
- **支付合规**：内购走微信支付/支付宝/应用商店 IAP；不得绕开平台支付体系（小游戏明确规定）。

### 7.5 无版号期间可以做什么

- 可以：免费测试（不涉及任何付费）、预约/愿望单运营、参展/媒体曝光、买量前测（按平台规则）。
- 不可以：任何形式的收费（虚拟支付/道具销售/会员）；小游戏虚拟支付需版号；"卖测试激活码"同样存在合规风险（以监管口径为准）。
- 稳妥策略：国内走"免费测试 → 拿号后商业化"，同时评估**出海先行**（海外平台不要求中国版号）。

### 7.6 出海版流程

- 海外平台全流程见本手册 §3-§5；无中国版号要求，但需：目标市场年龄分级（IARC/ESRB/PEGI）、隐私合规（GDPR/CCPA/COPPA）、税务（W-8BEN/VAT）、商店本地化。

## 8. 上架后：更新、热修与停服

| 事项 | 要点 |
| --- | --- |
| PC 更新 | Steam 即时发布（beta 分支预验证）；Epic/GOG 各自后台 |
| 主机补丁 | 每个补丁需走认证（预留 1-3 周） |
| 移动更新 | 每次更新重新审核（预留 1-7 天）；热更新注意平台禁止条款 |
| 小游戏更新 | 平台审核（通常 1-3 天） |
| 停服预案 | 提前公告期（国外部分司法辖区有判例要求，国内按平台要求）+ 补偿方案 + 玩家数据导出选项 |

## 9. 常见拒审原因与对策

| 平台 | 典型拒因 | 对策 |
| --- | --- | --- |
| App Store | 4.3 换皮/重复、2.1 完成度、3.1 绕 IAP、5.1 隐私 | 提供差异化说明；完成度达标再提交；全量使用 IAP |
| Google Play | 数据安全表单不符、目标 API 过低、权限 | 按数据流重填表单；升级目标 API |
| Steam | 内容调查缺失（AI）、素材规格 | 如实填写；按规格制作素材 |
| 微信小游戏 | 类目/资质不符、绕开虚拟支付 | 备齐软著/版号；支付只走虚拟支付 |
| 通用 | 素材侵权（字体/音乐/图标） | 素材台账 + 授权凭证（第 ⑦ 轮 §2） |

## 10. 上架检查清单（最终版）

- **资质**：软著 ✓ 版号（国内）✓ ICP（网游）✓ 商标（建议）✓ 分级问卷 ✓
- **文件**：用户协议 ✓ 隐私政策 ✓（与 SDK 数据流一致）内容自审报告（国内）✓
- **商店**：胶囊图/截图/预告/文案全语言 ✓ 定价与折扣 ✓ 发售日缓冲 ✓
- **技术**：成就/云存档/手柄 ✓ 崩溃监控 ✓ 热修流程演练 ✓ 设备矩阵测试 ✓
- **防沉迷**：实名系统接入 ✓ 未成年人限制 ✓ 概率公示（如适用）✓
- **应急**：首日热修预案 ✓ 客服通道 ✓ 社区公告模板 ✓
