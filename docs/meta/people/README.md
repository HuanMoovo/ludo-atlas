## 6. 如何"跟人学"（行动清单）

1. **读一手材料**：访谈、GDC 演讲、开发日志，优先于二手总结（入口见《资源大全》§3-§4）。
2. **玩代表作**：每个开发者挑 1 款玩 1 小时，带着问题玩："他为什么这么做？"
3. **找"风格签名"**：同一作者的不同作品对比（作者论拆解法）——美术签名、系统偏好、叙事母题。
4. **跟动态**：关注其社媒/博客/Discord；看他们"当下在纠结什么"，比看履历更有用。
5. **建自己的谱系图**：把喜欢的作品按"师承关系"连线（谁影响了谁），你会看到清晰的设计流派。
6. **别忘了厂商的另一面**：公告、财报、诉讼与失败案例，与作品同样有信息量（参照⑦、⑭）。
