> **迭代第 ⑭ 轮**。定位：一份"知道我们从哪来"的速览：电子游戏发展简史、中国游戏简史、游戏技术发展简史，以及各时代的代表性作品。

## 2. 六个时代详解与代表作品

### 2.1 拓荒期（1958-1977）

实验室里的示波器与大学机房孕育了交互娱乐：从网球模拟到太空对战，从硬币街机到第一台家用机。这一时代的遗产是：**游戏首先是"可交互的规则系统"**。

| 作品 | 年份 | 为什么重要 |
| --- | --- | --- |
| Tennis for Two | 1958 | 公认最早的交互式电子游戏之一（示波器网球） |
| Spacewar! | 1962 | 第一批影响深远的电子游戏；直接启发了后来的街机创业 |
| Computer Space | 1971 | 第一台商用投币街机（Nolan Bushnell 与 Nutting） |
| Pong | 1972 | 电子游戏商业化的起点（Atari） |
| Magnavox Odyssey | 1972 | 第一台家用游戏机 |
| Colossal Cave Adventure | 1976/77 | 文字冒险鼻祖，奠定"探索叙事"的交互传统 |

### 2.2 街机黄金与家用机革命（1978-1990）

街机厅成为流行文化中心；日本厂商崛起；家用机经历"雅达利大崩溃"后，由 FC/NES 重建秩序，**内容品质与平台授权制度**从此成为行业基石。

| 作品 | 年份 | 为什么重要 |
| --- | --- | --- |
| Space Invaders | 1978 | 街机高峰起点，引爆日本市场 |
| Asteroids | 1979 | 矢量显示经典 |
| Pac-Man | 1980 | 第一个大众级游戏偶像；营销与授权先河 |
| Donkey Kong | 1981 | 平台跳跃雏形；宫本茂成名作 |
| Dragon's Lair | 1983 | 激光光盘动画街机，预演"电影化" |
| Tetris | 1984 | 简单规则 × 无限深度；跨阵营传播的传奇 |
| Super Mario Bros. | 1985 | 平台跳跃类型定型；"游戏设计教科书" |
| 塞尔达传说（初代） | 1986 | 探索型冒险与存档逻辑的开端 |
| 雅达利大崩溃 | 1983 | 行业教训：内容泛滥 = 市场崩盘（详见 §6） |
| Game Boy + 俄罗斯方块 | 1989 | 掌机+休闲组合拳，全球普及电子游戏 |

### 2.3 16 位与 PC 崛起（1990-1995）

主机性能翻倍，类型全面成熟；PC 平台凭 RTS、模拟与 FPS 找到自己的道路；分级制度在争议中诞生。

| 作品 | 年份 | 为什么重要 |
| --- | --- | --- |
| 刺猬索尼克 | 1991 | 主机大战的形象战争；速度感设计 |
| 街头霸王 II | 1991 | 格斗游戏定义之作；街机对战文化 |
| 真人快打 | 1992 | 分级制度（ESRB 1994）诞生的直接催化 |
| 模拟城市 | 1989 | 系统模拟品类的奠基 |
| 文明（初代） | 1991 | 4X 与"再来一回合"的原始配方 |
| DOOM | 1993 | FPS 范式确立 + 共享软件发行 + mod 文化 |
| Myst | 1993 | CD-ROM 容量红利；探索型叙事 |
| 超级银河战士 | 1994 | 银河城（Metroidvania）图式定型 |
| 时空之轮 | 1995 | JRPG 黄金时代的叙事标杆 |

### 2.4 3D 革命与网络黎明（1995-2003）

从多边形主机到 3D 加速卡，视角革命重构了几乎所有类型；引擎开始被授权与复用；网络对战从局域网走向互联网，MMO 萌芽。

| 作品 | 年份 | 为什么重要 |
| --- | --- | --- |
| 超级马力欧 64 | 1996 | 3D 平台的操作与镜头范式 |
| 最终幻想 VII | 1997 | JRPG 全球化 + 电影化叙事 + CG 工业 |
| 星际争霸 | 1998 | RTS 竞技巅峰；韩国电竞产业起点 |
| 半衰期 | 1998 | 无缝叙事 FPS；mod 生态（CS 由此而来） |
| 合金装备索利德 | 1998 | 电影化潜入；叙事演出标杆 |
| 塞尔达传说：时之笛 | 1998 | 3D 冒险的锁定视角标杆 |
| 星际争霸/母巢之战、暗黑破坏神 II | 1998/2000 | 刷宝循环与战网生态 |
| 莎木 | 1999 | 开放世界雏形（商业教训同样经典） |
| 模拟人生 | 2000 | 大众市场模拟；"数字玩具屋"设计 |
| GTA III | 2001 | 开放世界都市范式 |
| Halo：战斗进化 | 2001 | 主机 FPS 手感标准 + Xbox Live 前奏 |
| 反恐精英 | 2000 | mod→商业产品的典范 |

### 2.5 在线与全球化（2003-2012）

数字分发重塑渠道；MMO 与 MOBA 定义"服务型游戏"；体感打开泛用户；iPhone 开启手游纪元；独立游戏从缝隙长成森林。

| 作品 | 年份 | 为什么重要 |
| --- | --- | --- |

| 魔兽世界 | 2004 | MMO 全民化；订阅制服务型游戏标杆 |
| 半衰期 2 / 反恐精英：起源 | 2004 | Source 引擎时代 |
| 英雄联盟 | 2009 | MOBA 规模化 + F2P 电竞生态 |
| Wii Sports / 体感世代 | 2006 | 泛用户市场；"玩游戏的人"重新定义 |
| 愤怒的小鸟 / 水果忍者 / 神庙逃亡 | 2009-2011 | 触屏玩法的原生语言；手游大众化 |
| FarmVille | 2009 | 社交游戏与 F2P 运营原型 |
| Minecraft | 2009-2011 | 沙盒创造 + 早期访问模式 + 全球现象 |
| 时空幻境 Braid | 2008 | 独立游戏的"成年礼"；作者论设计 |
| 超级食肉男孩 / 以撒的结合 | 2010-2011 | 硬核独立 + 肉鸽浪潮 |
| FTL：超越光速 | 2012 | Kickstarter 时代；系统叙事 |
| 旅途 Journey | 2012 | 情感体验的"游戏作为艺术"论战焦点 |
| 黑暗之魂 | 2011 | 高难度设计的现代谱系起点 |

### 2.6 移动、独立与当代（2012-至今）

手机成为最大游戏平台；独立高品质化（Hades/极乐迪斯科/Balatro）；大逃杀与社交玩法轮动；CRPG 复兴；中国厂商进入全球头部；AI 生产工具冲击全行业。

## 3. 中国游戏发展简史

| 阶段 | 时间 | 标志 | 代表作/事件 |
| --- | --- | --- | --- |
| 启蒙期 | 1980s-1990s | 街机厅、小霸王学习机、台湾厂商 | 大宇《仙剑奇侠传》(1995)；智冠、汉堂等 |
| 单机与挫折 | 1990s 末 | 大陆开始自研单机 | 西山居《剑侠情缘》(1997)；《血狮》(1997) 成为被广泛讨论的失败案例 |
| 端游时代 | 2001-2010 | 代理+自研网游爆发 | 《传奇》(2001, 盛大)；网易《大话西游》《梦幻西游》；完美世界；《征途》(2006, 巨人) |
| 页游与社交 | 2008-2013 | 页游买量与社交游戏 | 4399 生态；QQ 农场 (2009) |
| 手游时代 | 2013-2019 | 智能手机普及与渠道驱动 | 《刀塔传奇》(2014, 莉莉丝)；《王者荣耀》(2015)；《阴阳师》(2016)；《明日方舟》(2019) |
| 品质与出海 | 2017-2021 | 精品化 + 全球化 + 独立崛起 | 《原神》(2020)；《光·遇》(2019, 陈星汉)；《太吾绘卷》(2018)；《戴森球计划》(2021)；《鬼谷八荒》(2021) |
| 当代 | 2022-至今 | 3A 突破、小游戏生态、AI 应用 | 《黑神话：悟空》(2024)；微信小游戏生态；《绝区零》(2024) |
| 监管节点 | 2000s-至今 | 影响行业节奏的关键节点 | 网游监管体系建立；2018 年版号审批暂停与恢复；2021 年防沉迷新规（时长/充值限制）；详见《全平台上架手册》§7 |

> 中国游戏的特征线索：**渠道迭代快**（端游→页游→手游→小游戏）、**运营驱动强**（买量、联运、社交裂变）、**出海成为第二增长曲线**；独立开发者则在 2017 年后借 Steam/WeGame 生态形成稳定通路。

## 4. 游戏技术发展简史

### 4.1 硬件与显示

| 时期 | 技术 | 影响 |
| --- | --- | --- |
| 1970s | 矢量显示（Asteroids） | 线条锐利但无法画实心场景 |
| 1978+ | 光栅显示 + 硬件精灵 | 精灵（Sprite）+ 滚屏成为 2D 语言 |
| 1980s | 声卡与专用音源芯片（PSG/FM） | 音乐成为硬件能力（SID、YM 系列） |
| 1990s | CD-ROM、SGI 工作站、3D 加速卡（Voodoo 等） | 容量与 3D 算力双重爆炸 |
| 2000s | 可编程着色器 GPU（GeForce 3 世代起） | 渲染从"固定管线"转向"程序员自由定义" |
| 2010s | 光追硬件（RTX 2018）、移动 SoC 性能飞升 | 电影级光照实时化；手游画质逼近主机 |
| 2020s | 光追普及、云渲染与串流、WebGPU 落地 | 渲染无处不在；平台边界淡化 |

### 4.2 图形与渲染技术线

2D 精灵与瓦片（Tile）→ 伪 3D（Wolfenstein 3D / DOOM 的射线与 BSP）→ 多边形光栅化（PS1 无 Z-buffer 的手工排序 → N64 硬件 Z-buffer）→ 纹理映射与光照贴图 → 可编程 Shader（GLSL/HLSL）→ 基于物理的渲染（PBR）→ 全局光照（烘焙 Lightmap → 实时 GI）→ 光线追踪与降噪（DLSS/FSR 类超分）→ 现代引擎内置管线（UE5 Lumen/Nanite 类技术将"高级渲染"变成默认能力）。

### 4.3 引擎与工具演化

- **自研时代**（1980s-1990s）：每个公司造轮子；引擎是内部资产。
- **引擎商品化**（1990s 末起）：Quake/Unreal 的授权模式让"引擎"成为生意；RenderWare 等中间件服务大批工作室。
- **引擎民主化**（2005-2015）：Unity（2005）降低门槛；UE4 转向免费+分成（2014）；Godot 等开源引擎（2014 起）提供第三条路。
- **当代**：UE5（2022）、Godot 4（2023）代际更新；自研引擎集中在超大厂与特殊需求；**"引擎选择"成为立项战略**（见《技术实现手册》§8 对照表）。
- 工具链同步演化：关卡编辑器从硬编码 → 通用编辑器（Tiled/LDtk 生态）→ 引擎内置关卡工具；美术工具从像素软件 → Blender 全流程开源化。

### 4.4 声音技术简史

蜂鸣器与方波（1970s 末期）→ 可编程音源芯片与 FM 合成（1980s）→ PCM 采样与 CD 音质（1990s）→ 流式压缩音频（2000s）→ 音频中间件（FMOD/Wwise 一类将混音、参数、自适应做成系统）→ 空间音频与动态混音（当代，见《美术与音频手册》§7-§9）。

### 4.5 输入设备简史

旋钮与按钮（街机初代）→ 摇杆+多按键（街机黄金期）→ 十字键（1980s，任天堂确立标准）→ 类比摇杆+震动（N64/PS1 世代）→ 触屏（2007 起，触屏原生玩法）→ 体感与摄像头（Wii/Kinect 世代）→ 触摸板/背键/自适应扳机（当代主机）→ VR 手柄与手部追踪。**输入方式的革命往往伴随一批新类型**（体感之于聚会游戏、触屏之于休闲手游）。

### 4.6 网络技术简史

局域网联机（1990s 初）→ 互联网对战（QuakeWorld 等降低延迟感知；暴雪战网）→ MMO 与持久世界（1997-2004）→ 客户端-服务器与 P2P 混合体系 → 现代对抗游戏的预测/回滚/延迟补偿 → 云游戏与串流（实验性）→ 联机即服务（托管后端、匹配服务）。深潜见《技术实现手册》§5。

### 4.7 分发与商业模式的演化

街机投币 → 卡带买断（80s）→ PC 盒装/共享软件（90s）→ 在线发行与网吧生态（中国市场特征）→ 数字商店（2003+）→ F2P + 内购（2008+ 社交/手游）→ 战斗通行证与赛季（2010s）→ 订阅制（Game Pass 类）→ 独立订阅型众筹（Patreon 模式，如矮人要塞）→ 小游戏广告变现（微信/抖音生态）。**渠道每一次迁移，都重排一次行业座次。**

### 4.8 游戏 AI 与当代前沿

脚本化 AI（寻路/状态机，1980s 起）→ 行为树与 GOAP（2000s）→ 机器学习辅助（DDA、匹配、反作弊 2010s）→ 生成式 AI 进入生产（2022 起：图像/音频/代码/文本）→ AI NPC 与运行时生成（实验期）→ 编码代理与引擎 MCP（工作流级影响）。合规与披露见设计文档 §14.9。

## 6. 历史的启示（写给当代开发者）

1. **平台迁移期是破局窗口**：街机→家用机→PC→移动→小游戏，每次迁移都诞生新王；下一窗在 AI/XR 之间。
2. **品质把关是平台繁荣的底线**：雅达利大崩溃的直接教训：没有内容审核的制度，市场会被劣质品淹没（对照今日商店的刷量治理）。
3. **技术革命先改变"能做什么"，再改变"怎么做"**：光栅、3D、网络、移动、AI，每一次都先是工具，后是新类型与新商业模式。
4. **长尾与可持续发展靠生态**：Steam/独立发行商/众筹/小游戏生态证明："小团队可持续"是制度化产物，不是运气。
5. **模仿浪潮总在原创之后 2-3 年**：追热点者众、成事者少；组合创新与垂直深耕反复被验证更稳（见⑦§7）。
6. **中国路径的独特性**：渠道与运营驱动 + 快速迭代；出海口在不依赖单一渠道的精品与垂类。
7. **保存历史就是积累方法**：每个时代的失败模式在换皮后反复出现，《避坑大全》里一半的坑都是历史作业。
