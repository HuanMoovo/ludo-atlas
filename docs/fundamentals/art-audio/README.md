# Ludo Atlas · 美术与音频手册

> 定位：让画面"能看"、声音"能打"的生产手册，覆盖美术方向与规范、2D/3D/UI 管线、技术美术入门、音频设计与实现、交付规格。
> 配套：《游戏设计手册》（手感与反馈）·《制作管理手册》（外包流程）·《资源大全》（工具/素材站，§2.2-2.6、§5）·《避坑大全》（美术/音频章节）。
> 适用：非美术出身但要做完整游戏的开发者、小团队美术负责人；不替代系统美术课程，重"管线与规范"。

---

## 1. 美术方向与 Art Bible（开工前必做）

- **风格板（Mood Board）**：收集 8-15 张参考（色彩/构图/笔触/光照），圈出"要什么/不要什么"；产出 1-2 张"目标样图"（可请美术或亲自画到能看）。
- **Art Bible 最小集**：色板（主色/辅色/语义色）· 线条与笔触规则 · 光照与明度层级 · 分辨率与规格表 · 命名规范 · 参考图库（含"反例"区）。
- **风格 = 约束的组合**：限制调色板、统一描边、统一光照方向。"克制"比"堆细节"更显专业。
- **可执行性检查**：每个风格决策问"单张资产要多久？100 张呢？"，因为风格必须是可量产的（见《避坑大全》美术工作量坑）。

## 2. 2D 管线

### 2.1 三种 2D 风格与规格

| 风格 | 关键规格 | 工具 | 注意 |
| --- | --- | --- | --- |
| 像素风 | 固定内部分辨率（如 320×180）；PPU（每单位像素数）统一；调色板限制；像素完美相机 | Aseprite/Pixelorama/LibreSprite | 非整数倍缩放会糊；旋转/缩放尽量用整数步进 |
| 手绘/卡通 | 统一描边与笔刷；分层（线稿/底色/阴影/特效） | Krita/Photoshop/Procreate | 图层规范与导出（PSD → 引擎分层导入） |
| 矢量/扁平 | SVG/素材以形与色为主；描边统一 | Inkscape/Affinity/Illustrator | 导入引擎常需栅格化，提前定分辨率档 |

### 2.2 2D 动画

- **帧动画**：帧数规范（8/12/24fps 常见）、循环与非循环分离、变形（squash & stretch）关键帧。
- **骨骼动画**：Spine/DragonBones（→《资源大全》§2.4）；换皮/换部件成本低，适合量产角色；与引擎的骨骼导入流程要固化。
- **程序化辅助**：位移/缩放/倾斜参数动画（tween）大量替代手绘中间帧，省钱且可调。
- 动画验收：逐帧播放 + 游戏内实机播放**两个都要看**（切图掩盖问题）。

### 2.3 切图与导入

- 图集（Atlas）规划：按场景/功能分组、预留后缀规范（`_n`法线 `_e`自发光）；透明边缘防溢出（padding 2-4px 防采样毛边）。
- 命名规范示例：`char_hero_idle_01.png`（类别_主体_动作_序号）；导入设置（过滤/压缩/锚点）脚本化。

## 3. 3D 管线

### 3.1 建模规范（程序友好的硬约束）

| 项 | 规范示例 | 为什么 |
| --- | --- | --- |
| 单位与朝向 | 1 单位=1 米；面向 +Z（按引擎约定） | 物理与动画兼容 |
| 面数预算 | 角色 5k-30k tris（按平台分档）；场景模块化 | 性能预算（《技术实现手册》§3.1） |
| UV | 无重叠、留边距、统一朝向 | 烘焙与贴图复用 |
| 命名 | SM_/SK_/M_/T_ 前缀（静态网格/骨骼/材质/贴图） | 批量化与自动化检索 |
| 枢轴（Pivot） | 底部中心（角色/道具） | 生成与摆放效率 |

### 3.2 贴图与材质（PBR 最小概念）

- PBR 通道：Albedo（无光照信息）· Roughness（粗糙度）· Metallic（金属度）· Normal（法线）· AO（可选）。
- 纹理规格：尺寸为 2 的幂（512/1024/2048）；按平台压缩（桌面 BC/ASTC、移动 ASTC/ETC2）；贴图集与通道打包（如 Metallic-Smoothness 合并）。
- 材质数量控制：种类越少越易优化；用参数化主材质（Master Material）+ 实例。

### 3.3 动画与重定向

- 3D 动画基础：关键帧动画（少量动作）vs 骨骼动画；Mixamo 快速原型（→《资源大全》§2.3）。
- 重定向（Retarget）：不同骨架共享动作时的规范（命名约定、T-Pose、比例），先定骨架再量产动作。
- 动画状态机（引擎侧）与美术交付对齐：动作列表（Idle/Walk/Run/Turn/Jump/Fall/Attack×N/Hit/Death…）+ 循环/事件点（步点/打击帧）。

### 3.4 关卡/环境美术

- 模块化（Modular Kit）：标准网格（墙/地板/角件）组合出场景；贴图 45° 朝向复用技巧。
- 光照与大气：Lightmap/实时 GI 取舍；雾/天空盒/后处理（Bloom/色调映射）统一风味。
- 性能：遮挡剔除（Occlusion）、LOD 链（LOD0-3）、远处替代物（Impostor）。

## 4. UI 与图形设计

- **9-slice（九宫格）**：按钮/面板按拉伸区导出；状态（normal/hover/pressed/disabled）四态齐全。
- **图标系统**：统一网格（如 24/32/48），线性/面性选一种；导出 SVG + 多倍图。
- **字体与排版**：标题/正文/数字字体分工；中文与西文混排、行高、描边与阴影对比规则；最小可读字号（移动端 ≥ 12sp 常规）。
- **分辨率策略**：锚点（边缘元素贴边、弹窗居中）+ 比例缩放（核心区等比）+ 超宽/窄屏适配清单；UI 与 3D 世界观感统一（色调/圆角/材质）。

## 5. 技术美术入门（程序与美术的桥）

- **Shader 心智模型**：顶点着色器（位置/变形）→ 光栅化 → 片元着色器（颜色/光照）；先学会"改参数"（材质实例），再学"写逻辑"。
- **常用特效**：粒子系统（发射/生命周期/曲线）、序列帧特效、拖尾（Trail）、溶解/边缘光（常见 Shader 预制）。
- **效果性能**：Overdraw 排名（全屏后处理 > 大粒子 > 半透明 UI）；特效分级（低配关闭后处理、降粒子密度）。
- **资产规范守护**：导入校验脚本（尺寸超限/命名错误/材质类型不对 → CI 警告）；TA 的产出不是特效，是"让美术量产不翻车的管道"。

## 6. 美术外包与素材使用（流程）

1. **需求包**：参考图 + 规格表（尺寸/格式/分层/命名）+ 交付格式 + 验收标准（可量化：如"三视图比例一致，色板符合 Art Bible"）。
2. **试单**：先一张试做（付费），风格与沟通过关再批量。
3. **里程碑与验收**：分批交付（草稿→线稿→上色→终稿），每阶段确认再继续；源文件（PSD/Blender）必须交付。
4. **归档**：资产台账（来源/作者/授权/修改记录），含 AI 生成记录（见《法务、专利与竞争手册》/《避坑大全》）。

- 素材站使用（Kenney/爱给等）→《资源大全》§5；**每个素材核对许可并留存凭证**。

## 7. 音频设计（声音设计师视角）

- **反馈层级**（先分层，再做声音）：

  | 层级 | 例子 | 原则 |
  | --- | --- | --- |
  | 核心反馈 | 跳跃/命中/拾取/受击 | 必须清晰、独特、低延迟；最高优先级 |
  | 状态提示 | 血量低/技能就绪/倒计时 | 可循环但克制，避免疲劳 |
  | 环境氛围 | 风/水/人群/机器 | 建立空间与情绪，音量最低层 |
  | UI 音 | 点击/确认/错误 | 短、轻、统一音色家族 |
  | 音乐 | BGM/动态音乐 | 情绪载体（§8） |

- **动态混音**：总线结构（Master→Music/SFX/Voice/UI）；侧链/Ducking（对话时音乐自动降低）；优先级与并发上限（《技术实现手册》§2.7）。
- **空间感**：2D 游戏简化（左右声像）；3D 用距离衰减 + 混响区（室内/洞穴切换）。

## 8. 音乐设计

- **结构**：循环段（Loop，首尾无缝）· 过渡段（Stinger，事件触发）· 分层（Layers：基础/紧张/战斗叠加）。
- **自适应音乐三模式**：垂直分层（同曲叠加）、水平重排（段落顺序切换）、过渡桥（切入切出点）；先做最简单的分层，验证后再复杂化。
- **与玩法联动**：音乐强度跟随战斗/探索状态（参数化，非硬切）；Boss 音乐预留"阶段切换"段落。
- **制作方案对比**：定制作曲（质量与契合最高）· 免版税库（快、便宜、易撞曲）· AI 生成（快，注意授权与披露，见《法务、专利与竞争手册》）。**授权范围必须覆盖：全球/永久/商用/可剪辑**。

## 9. 音频实现（程序与音频的接口）

- **事件化播放**：游戏代码发出语义事件（`footstep_grass`、`ui_confirm`），音频侧决定具体样本与随机化，解耦且利于音频独立迭代。
- **中间件概念**（FMOD/Wwise，见《资源大全》§2.6）：事件（Event）· 参数（Parameter：强度/环境）· 快照（Snapshot：状态切换）· 总线（Bus）。
- **实现清单**：音频池与并发上限、流式加载（长音乐）、暂停/切场景处理、跨场景常驻音乐、设置项（主音量/分类音量/静音切换默认值）。
- **性能注意**：解码开销（压缩格式解码 CPU）、内存（音频缓存）、移动端后台音频行为。

## 10. 交付规格与检查清单

### 10.1 规范表（开工前与美术/音频对齐）

| 资产类 | 规格项 | 示例标准 |
| --- | --- | --- |
| 2D 图 | 尺寸/格式/PPU/命名 | PNG，2 倍图@PPU 100，`ui_icon_sword@2x.png` |
| 3D 模型 | 单位/面数/UV/命名/枢轴 | 米制，角色 ≤15k tris，SM_ 前缀 |
| 贴图 | 尺寸/通道/压缩 | 1024 幂次，Albedo+Normal+RMA 打包 |
| 音频 | 格式/响度/采样率/循环 | OGG（音乐）/WAV(短音效)，目标响度统一（LUFS 标准），循环点无缝 |
| 字体 | 授权/子集化/回退 | 免费商用许可留档；按语言子集化减体积 |

### 10.2 上线前检查清单

- [ ] Art Bible 全资产一致性抽查（色板/风格/尺寸）

- [ ] 图集/材质/音频分类预算未超（《技术实现手册》§3.1）
- [ ] 音频响度统一、循环无缝、设置项可用
- [ ] 素材与 AI 资产台账完整（许可凭证 + 修改记录）
- [ ] 低配/移动端降级路径验证（特效/后处理/纹理档位）
- [ ] UI 全分辨率 + 多语言溢出测试
