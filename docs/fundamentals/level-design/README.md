# Ludo Atlas · 关卡设计手册

> **迭代第 ㉑ 轮**。从"会摆场景"到"会设计体验"：度量的建立、无文字引导、节奏控制、白盒工作流，以及十个经典关卡的拆解。
> 面向 2D 与 3D 通用。配套：《游戏设计手册》（⑨，系统层）·《技术实现手册》（⑩）·《美术与音频手册》（⑪）·《制作管理手册》（⑫）。
> 本文刻意不放链接。关卡设计的手感来自观察与练习，读十篇文章不如白盒一个房间。

## 1. 关卡设计师在做什么

关卡设计师是"把系统变成体验"的人。系统提供跳跃、射击、建造这些动作，关卡决定这些动作在什么空间、什么节奏、什么压力下发生。

与合作方的三组接口：

- 与策划：拿到目标体验（紧张？探索？爽快？）和目标时长，把它翻译成路径与遭遇。
- 与美术：定义空间的功能需求（视线、地标、可读性），美术再决定它长什么样。
- 与程序：确认机制边界（哪些能改、哪些是死的），再动手设计。

文档习惯：每个关卡一张一页纸说明，写清目标情绪、预计时长、首次登场的新元素、检查点位置、依赖的资源清单。没有这张纸的关卡，做一半必然返工。

## 2. 度量：用时间和步数设计空间

新手凭感觉摆平台，老手用数字摆。方法只有一个：给自己的项目建一张"单位表"，然后在灰盒里实测校准。

需要先量出来的数字：

| 指标 | 怎么量 | 用途 |
| --- | --- | --- |
| 角色移动速度 | 每秒走多少米/格 | 换算所有距离 |
| 跳跃水平距离 | 起跳到落地的最远水平位移 | 平台间距分级 |
| 跳跃高度 | 全按跳能到多高 | 垂直关卡层高 |
| 滞空时间 | 从起跳到落地几秒 | 空中动作与危险窗 |
| 门与通道宽度 | 角色身体的多少倍 | 通过舒适度 |
| 视线距离 | 一屏能看到多远 | 引导与预告范围 |

关键的换算思路：**距离用时间表达**。两段平台的距离等于跳跃滞空时间乘以水平速度，那么"跳得过去吗"就变成"需要几个滞空"：0.8 倍滞空是舒适距离，1 倍是标准挑战，1.2 倍是极限操作。三级间距制让难度可以精确调节，而不是靠试。

三个节奏尺度也要在表里定下来：3 秒一次小刺激（跳跃、开火、拾取），30 秒一次中等事件（遭遇、发现、转折），3 分钟一次大节奏（区域高潮、场景切换）。钩子太稀玩家无聊，太密玩家疲劳。

## 3. 引导：不写字教会玩家

玩家不会读说明书，只会读环境。无文字引导的可用手法：

1. **光与对比**：玩家天然走向更亮、更彩、更动的东西。走廊尽头放一盏暖色灯，比任何箭头管用。
2. **构图与视线**：用墙壁、悬崖、镜头朝向把视线压到目标上。进入房间的第一帧就决定了玩家看向哪里。
3. **面包屑**：沿途的小奖励或小事件带路。
4. **断桥法**：先让玩家看见想去的地方，再让直达路塌掉，逼出另一条路。玩家自己找到的路，体验远好于你铺好的路。
5. **安全教学**：教新机制的房间不设死亡惩罚，让玩家随便试。
6. **危险预告**：用颜色、挂饰、声音提前提示"这里有坑"。看不见的死亡是差评重灾区。

教学序列的公式是"展示、使用、变奏、组合"：先让玩家看见（安全环境里展示一次），再让他自己用（低压场景），然后变奏（改变条件，比如加上时间压力），最后组合（和旧机制连用）。一次只教一个新东西。

引导检查表（每个新房间过一遍）：玩家进门会看向哪？目标物在不在视野里？走错路 5 秒内能不能察觉？死角里有没有藏东西？第一次死亡的原因能不能理解？

## 4. 节奏与强度曲线

把一段关卡的紧张程度画成一条线，就是强度曲线（有些团队叫心跳图）。健康的曲线是波峰波谷交替：紧张、释放、再紧张，且整体爬升。一条平线（一直紧张或一直平缓）都是灾难。

管理曲线的三个工具：

- **新元素投放表**：列出每个新机制第一次出现的房间，确保间隔均匀、一次一个。
- **检查点图**：检查点的间隔对应"重来时跑的路"。惩罚跑路超过 20 秒，挫败感就开始盖过挑战欲。
- **难度锯齿**：整体难度爬升，但局部要有回落。长爬升之后必须给一个轻松段落，这是呼吸。

## 5. 空间语言

玩家需要在半秒内读出空间的含义：这里能过、那里是墙、这个箱子能推、那个悬崖是死路。

- **可读性靠对比**：可行走区域与装饰、前景与背景，在形状和颜色上要能区分。模糊的美术边界是迷路的根源。
- **留白与压迫交替**：开阔空间放松，狭窄通道收紧，这是免费的节奏工具。
- **回环结构**：单向门、电梯、打通的捷径，让地图在玩家脑中长出立体感。"原来这里通到那里"的惊喜，是探索类游戏的核心快感。
- **地标导航**：大区域里放 1 到 2 个远处可见的地标，配上颜色分区，玩家不用看地图也能报出自己在哪。

## 6. 关卡工作流：从白盒到成品

正确的顺序只有一条，反着做必翻车：

1. **纸面**：草图与流程图。目标、路径、遭遇、情绪高点，先想清楚再动手。
2. **灰盒**：只用基础几何体搭出全部空间。用占位符验证三个指标：能通吗（功能）、想通吗（欲望）、记得住吗（记忆点）。这一步丑是应该的。
3. **试玩迭代**：找人玩，观察，修改，再玩。作者的直觉在第三轮会失效，必须换人。
4. **装扮**：美术进场，优先保功能。装扮后必须重跑一遍，检查视线、引导、性能有没有被堵死。
5. **打磨**：特效、音效、镜头、节奏微调。最后阶段调的是 0.1 秒级的东西：镜头时长、提示延迟、震屏幅度。

灰盒阶段最常见的错误是"装修太早"：怕团队看着丑没信心，于是提前贴图，结果玩法一改，贴图全废，还不敢大改结构了。

## 7. 常见类型的要点

| 类型 | 空间设计核心 | 特别提醒 |
| --- | --- | --- |
| 平台跳跃 | 跳跃半径表与安全网 | 惩罚放在节奏变化处，不放在纯操作处 |
| 银河城 | 能力门锁：锁、钥匙、回访 | 每个新能力都要有"回访理由" |
| 射击/竞技场 | 掩体、视野线、出入通道 | 战斗空间先定尺寸再定装饰 |
| 潜行 | 巡逻路径、视野锥、告警层级 | 要留"被发现了也能玩下去"的通道 |
| 解谜 | 元素数量克制、教学顺序 | 一房间一个核心概念，不叠概念 |
| 开放世界 | 兴趣点间隔与密度 | 用视线和地标串路，不靠任务列表指路 |
| 恐怖 | 资源节奏、安全屋、声音线索 | 吓点靠铺垫与预期违背，不靠廉价跳吓 |

## 8. 十个经典拆解

以下都是业内反复被分析的案例，建议亲自玩一遍再读分析。

1. **超级马里奥兄弟 1-1**：教材级的第一关。按顺序教了移动、顶砖、蘑菇、水管、隐藏奖励，全程零文字。可迁移：把教学物品放在玩家必经的动线上。
2. **塞尔达传说：时之笛 德库树**：第一个 3D 迷宫解决了"如何在三维空间里指路"。跟镜头、看纹理、试交互。可迁移：3D 引导从限制视角开始。
3. **传送门 前十个测试房**：一间教一个规则，教完立刻用新规则考试，最后综合。可迁移：解谜关卡的"教-考-合"三段式。
4. **半条命 2 莱温霍姆**：强度曲线的教科书。全程高压但从中穿插喘息点（安全屋、对话、灯光变化）。可迁移：恐怖段落要有呼吸，不然玩家会麻木。
5. **黑暗之魂 不死镇及教区**：立体回环的范本。电梯、捷径、单向门把三个区域缝成一体，死亡跑图路线随捷径解锁不断缩短。可迁移：捷径是给重试玩家的奖励。
6. **蔚蓝 第一章**：无惩罚教学加草莓（自选难度）。主线教基础，草莓给挑战型玩家，A/B 面分流人群。可迁移：难度做成可选项而不是门槛。
7. **见证者 起始区**：一个字的说明都没有，纯靠谜题序列本身教学。每块黑板都在教一条新规则。可迁移：规则教学可以完全交给玩家的试错与反馈。
8. **Inside 开场**：无声开场，用光照、狗、追车把"逃跑"刻进玩家肌肉记忆。可迁移：开场 5 分钟决定玩家信不信你的世界。
9. **生化奇兵 开场（欢迎来到销魂城）**：超长脚本段落作为世界介绍，玩家几乎不操作但全程紧张。可迁移：可控的"夺权"段落能换来更强的情感投入，但一生只能用一两次。
10. **战神（2018）开场陌生人战**：教学、叙事、情绪、演出四合一。战斗教学藏在剧情冲突里，打完玩家既会了系统又记住了人物。可迁移：教学不必是说明会，让它成为剧情的一部分。

## 9. 工具与文档

- 白盒工具：引擎自带的几何体与建模模式够用；专注时用专用工具（Tiled、LDtk 这类 2D 关卡编辑器，入口见《资源大全》§2）。
- 一页纸关卡文档模板：编号与名称、目标情绪、预计时长、首次登场元素、检查点、情绪曲线草图、依赖资源表、验收标准（"玩家应能在不死亡的情况下学会滑铲"这种可观察的句子）。
- 试玩观察法：让玩家玩，你不说话、不提示、不辩解。记录三件事：死亡点（哪里卡）、停顿点（哪里懵）、异常路径（哪里绕了远路或走了老路）。这比问卷有效十倍。

## 10. 常见错误清单

1. 先装修后玩法（顺序反了，改不动）。
2. 只测自己（作者滤镜会骗你到上线）。
3. 大而空：长通道里没有事件、没有决策、没有景。
4. 难度忽难忽易，曲线像过山车。
5. 教一次就考试，没有低压练习段。
6. 全图对称与重复，玩家失去方向参照。
7. 引导靠文字弹窗和贴脸箭头。
8. 检查点离死亡点太远，重试变成跑图。
9. 看不见的坑与无预兆的死亡。
10. 相机死角，玩家看不到威胁来源。
11. 重要目标被装饰物遮挡（装扮阶段新引入的问题）。
12. 灰盒期不看性能，后期砍内容拆结构。

## 11. 练习与自测

给自己排的作业，从易到难：

1. **复刻**：用自己项目的机制复刻马里奥 1-1 或传送门的第一间测试房。
2. **洋葱**：同一个房间做简单/标准/极难三个版本，条件只允许改布局与间距，不改变量。
3. **灰盒冲刺**：30 分钟搭一个"有一个教学、一个遭遇、一个奖励"的最小关卡。
4. **观察作业**：玩任意一款游戏，记录一段 10 分钟的强度曲线与所有引导手法。

自测十问：进门视线落在哪？新东西教过吗？失败代价是什么？节奏有呼吸吗？地标能找到吗？三分钟内有几个钩子？走错路有反馈吗？玩家能不能玩出你没设计过但成立的路线（这是好事）？
