# GameDev Atlas · 运营与增长手册

> **迭代第 ⑬ 轮**（复盘后的收官轮）。定位：从"游戏上架"到"被玩到、被讨论、能持续"的运营手册——增长漏斗、发售前中后节奏、数据指标、平台机制、社区与危机、变现伦理、出海增长。
> 配套：《全平台上架手册》（⑧，上架流程）·《法务、专利与竞争手册》（⑦，竞争分析）·《制作管理手册》（⑫）·《资源大全》（工具与数据站，§4、§8.3）。
> 提醒：营销数字（转化率/销量倍数）皆为**行业经验区间**，品类差异极大——一切以你自己的数据仪表盘为准。

## 1. 增长漏斗总览（先看全图，再拧每一环）

```
曝光（平台推荐/媒体/社媒/搜索）
  → 商店页访问（capsule 点击率决定）
    → 愿望单/试玩（转化决定）
      → 购买（定价/口碑/时机决定）
        → 留存与传播（好评/直播/口口相传 → 反哺曝光）
```

- 每一环都有输入与转化率；**只优化最漏的那一环**（psst：多数独立游戏的漏斗底是"曝光"，不是"定价"）。
- PC 核心资产是**愿望单**；移动核心资产是**留存与 LTV**；小游戏核心是**分享率与广告 eCPM**。

## 2. 发售前运营（6 个月倒计时）

| 时间 | 动作 |
| --- | --- |
| T-6 个月 | 商店页上线（先于一切）；确定主 capsule 与预告片方向；建社群阵地（Discord/QQ/B站/微博选一二） |
| T-4 个月 | 持续内容更新（gif/短视频/开发日志，每 1-2 周）；媒体与创作者名单收集（press kit 就绪） |
| T-2 个月 | 参与平台节日（Steam Next Fest 等）；Demo 发布；预约/愿望单冲刺 |
| T-2 周 | 媒体与创作者推送（个性化邮件，附 key）；直播排期确认 |
| T-1 周 | 首发内容备齐（公告/更新说明/FAQ/客服话术）；发布日清单演练 |

- **Press Kit 模板**：游戏介绍（50/100/300 字三版）· 卖点 3 条 · 团队信息 · 高清素材包（logo/截图/gif/预告）· 联系方式。参考 dopresskit 风格（https://dopresskit.com/ ）。
- **capcpsule 图是最大单一杠杆**：在商店页和列表里与竞品并排做 A/B 对比（自己找 10 款竞品拼图对比）；不合格就重做（这钱最值）。
- 营销方法论长期跟踪：How To Market A Game（https://howtomarketagame.com/ ，Steam 生态一手经验）。
- 邮件三原则：个性化（提一句对方具体内容）· 短（5 行内）· 一图一链接。

## 3. 发售周作战

- **首周是算法窗口**：发售前 24h 起推荐位与榜单权重最高——所有弹药集中在首周。
- 首发折扣（10-15% 常规）+ 首发公告 + 媒体/创作者同步 + 社群活动（抽奖/直播/挑战）。
- 数据监控表：愿望单转化、退款率、评测速度与均分、各区域销量、异常崩溃率（联动⑩）。
- 客服节奏：首周 4-8 小时内响应一线问题；重大 bug 走热修流程（⑧§8）。
- 心态：**首日不是终局**——Steam 长尾由节日、折扣、口碑驱动（见 §5）。

## 4. 发售后 90 天

| 阶段 | 重点 |
| --- | --- |
| 第 1-2 周 | 热修与稳定性（评分保卫战）；致谢与补丁说明（补丁说明也是营销内容） |
| 第 3-6 周 | 首个内容更新预告（保持曝光）；收集社群反馈进入路线图 |
| 第 6-12 周 | 首次打折（参考平台节奏与同类）；参加平台节日；社区活动 |
| 90 天复盘 | 漏斗复盘（曝光/转化/留存/口碑），定长期路线图 |

- **评测管理**：绝不买评/刷评（平台严打）；对差评"回复一次、简洁客观、不辩论"；引导满意玩家留言（在游戏内温和提醒，不诱导）。
- 评分档位意识（Steam 为例）：好评率约 80%+ 为"特别好评"区间、95%+ 为"好评如潮"（含最低评测数要求，以平台规则为准）——档位影响推荐权重与转化。

## 5. 长期运营（6 个月后）

- **更新节奏**：只承诺可持续的（小更新也算更新）；大版本年度 1-2 次 + 小补丁月度；每次更新=一次小型营销窗口。
- **内容资产复用**：更新预告/攻略/回放合辑持续产出社媒素材；UGC（创意工坊/挑战赛）是免费增长引擎。
- **DLC/资料片**：本体口碑稳定后再做；金矿评估 = 本体销量 × 存量玩家活跃度。
- **跨作品规划**：续作/同世界观新作吃老玩家转化（系列页互链、捆绑包）。
- 移动端：赛季/活动节奏（不逼氪）、长线数值随版本迭代、软启动到买量放量（见 §7）。

## 6. 数据指标手册

### 6.1 通用漏斗指标

| 环节 | 指标 | 健康信号（经验值） |
| --- | --- | --- |
| 曝光→访问 | 商店页访问量 | 跟随曝光同步波动 |
| 访问→愿望单 | 愿望单转化率 | 因品类而异；<1% 检查 capsule/标签 |
| 愿望单→购买 | 首周转化率 | 行业区间约 10-25%（差异大，用同品类对标） |
| 购买→满意 | 评测均分/退款率 | 退款率显著高于同类 = 问题信号 |

### 6.2 PC（Steam）专项

- 愿望单总量与**日增速度**（发售前 30 天速度=热度信号）；Steam Next Fest 表现（试玩量/愿望单增量）。
- 销售转化：评价数、在线峰值、区域分布（定价与本地化决策输入）。

### 6.3 移动专项（概念速查）

| 指标 | 含义 | 用途 |
| --- | --- | --- |
| D1/D7/D30 留存 | 第 N 日回访比例 | 产品健康核心（休闲 D1 经验区间 ~30-40%） |
| CPI | 获客成本 | 买量经济学分母 |
| LTV | 用户生命周期价值 | 必须 > CPI 才可持续 |
| ROAS | 广告回报率 | 买量放量/停量的开关 |
| ARPDAU | 日活人均收入 | 变现效率 |

- 买量入门：先小预算测素材（3-5 组）→ 看 CPI/ROAS → 数据过关才放量；素材制作见《资源大全》§8.3 工具。

## 7. 平台机制与算法（概览级）

- **Steam 曝光机制（社区共识）**：愿望单与首周转化是核心信号；节日/主题特卖是最大免费窗口；标签决定推荐人群（标签选错=向错误人群曝光）。策略：标签瞄准细分受众、积极参与官方节日、保持更新频率。
- **移动商店**：榜单与编辑推荐受留存/评分/更新活跃度影响；ASO（标题/副标题/关键词/截图）持续迭代（工具《资源大全》§4.4）。
- **小游戏平台**：微信以社交流量与分享裂变为王（分享激励设计有平台红线）；抖音以短视频挂载为核心分发（素材即买量）；逐平台打法单独规划。
- 所有"机制"都可能变——**跟着平台官方公告走，不信玄学**。

## 8. 社区与危机公关

- **阵地策略**：主阵地 1 个（Discord 或 QQ/微信群）+ 内容阵地 1-2 个（B站/微博/X/YouTube/Reddit）；宁可少而精，不要注册完就荒废。
- **内容节奏**：开发日志（周/双周）· 幕后花絮 · 玩家创作转发 · 里程碑庆祝——"在场感"积累信任。
- **危机处理 SOP**：
  1. 停：不情绪化回复；2. 查：确认事实与范围；3. 说：公开、具体、有时限（"我们已定位，48 小时内出补丁"）；4. 做：兑现承诺并跟进公布；5. 复盘：写入流程防复发。
- 红线清单：不与玩家对线、不删负评（可申诉违规评）、不甩锅平台/玩家、不承诺做不到的事（见⑥）。

## 9. 出海与本地化增长

- **先定市场**：语言支持优先级 = 现有销量区域 × 目标品类受众；简中/繁中、英、俄、西、葡、日、韩、法、德、意 为常见排序参考。
- **本地化不只是翻译**：商店页文案本地化、节日活动本地化（农历新年/圣诞/本地节日）、定价按区域购买力（平台区域定价建议价±）。
- **区域渠道**：中国（TapTap/WeGame/小游戏，合规前置见⑦⑧）；日本（媒体/CERO）；欧美（Reddit/Discord/创作者）；拉美（葡萄牙语优先）。区域差异大，按区域单独做"发布小结"。

## 10. 变现伦理与可持续

- **原则**：变现设计与游戏乐趣同向（"为热爱付费"而非"为焦虑付费"）；抽卡概率公示与保底透明（合规底线，见⑦）；广告不打断核心体验（激励式 > 强制式）。
- **玩家信任 = 长期资产**：一次恶意变现（陷阱 UI/暗改数值/诱导充值）可持续透支十年口碑。
- 财务可持续：预留运营成本（服务器/更新/客服）；收入波动预期管理（首月占比往往极高，勿按首月线规划全年成本）。

## 11. 复盘与下一作

- 发布 90 天复盘模板：漏斗数据（§6）→ 内容与运营做对了什么 → 浪费了什么 → 下一作/下一版的三条改进项。
- 把每次发布的经验写进 `docs/postmortems/`；团队知识复利是独立开发者唯一稳定的"护城河"。
- 下一个循环：回到《游戏设计手册》⑨——带着数据与经验，做更准的下一枪。
