# Ludo Atlas · 电竞与竞技设计手册

> **迭代第 ㉗ 轮**。竞技性设计、观战系统、平衡方法论、赛事生态判断，以及中国办赛的实际口径。
> 配套：《联机与后端深入手册》（㉖，匹配与反作弊）·《运营与增长手册》（⑬）·《法务、专利与竞争手册》（⑦）·《全平台上架手册》（⑧）。
> 一句话前提：电竞会放大成功的游戏，但它不能把不成功的游戏变成功。

---

## 1. 先分清三件事

"做电竞"其实是三种完全不同的活：

1. **做一款有竞技性的游戏**：设计层面的活，本文 §2 到 §4。
2. **运营官方赛事**：商业与营销层面的活，是成本中心或营销工具，不是收入线（对游戏方而言）。
3. **接入第三方赛事生态**：社区与授权层面的活，最轻，也最依赖你的游戏自己够火。

判断顺序永远是：玩法先立住 → 竞技人口自然形成 → 再考虑赛事。跳过前两步硬办赛，办的是寂寞。

## 2. 竞技性设计

竞技游戏的底层是四个词：

- **公平**：对称对抗最稳（同角色同规则）；非对称（不同角色不同能力）更有个性，但平衡难度成倍上升，要做就准备好长期调校。
- **深度**：决策空间要"易上手难精通"。深度来自系统之间的交互，不是来自操作门槛。靠操作速度堆出的深度，会把观众和多数玩家一起挡在门外。
- **清晰**：观众能在 3 秒内看懂正在发生什么。信息表达（特效、声音、UI）要能让外行看清"谁占优、谁要死、谁在秀"。这是观赏性的第一关。
- **悬念**：翻盘可能性的存在。雪球滚得越死，观赏性越差；给弱势方留反制路径，比赛才有人看。

版本稳定性是隐含的第五个词：电竞选手的肌肉记忆和战术库是按版本积累的，赛季内大改是大忌。调整集中在本赛季结束到下一赛季开始之间的窗口。

## 3. 观战系统：工程清单

观战不是"再加个摄像机"，它是一整套产品：

- **观察者视角**：自由镜头、跟随选手、第一人称/战术视角切换、多路画中画。导播需要"能随时切到任何一场正在发生的战斗"。
- **导演系统**：自动导播（按规则或算法选焦点）加人工干预。大规模赛事的刚需，不然导播看不过来。
- **观众信息层**：血量、经济、技能冷却、胜率曲线的"观众版"显示。选手看不到的信息，观众要能看到，这是转播的价值。
- **回放体系**：完整回放、关键帧跳转、片段导出。回放同时是训练工具和内容生产工具（集锦、复盘、教学全是它养出来的）。
- **数据接口**：实时数据流输出给转播方（计分板、图表）。职业转播的要求，提前留 API。
- **观察延迟**：反作弊（防窥屏）与直播延迟的平衡，方案要提前定。
- **技术选型影响回放**：帧同步（确定性）做回放容易；状态同步要靠快照与输入重演。**回放能力要在架构期就留，后期补的成本极高。**

## 4. 平衡方法论

- **数据驱动**：胜率、出场率、禁用率、段位分布都要看。小心小样本（新版本头三天的数据基本是噪音）和幸存者偏差（高段位数据不代表大众体验）。
- **平衡哲学**：绝对平衡不存在，也不该追求。目标是"多样的元游戏"：尽可能多的打法都有一席之地。你觉得"无趣但平衡"的方案，职业选手会教你怎么拆。
- **调整顺序**：优先改数值，慎改手感。数值改动可以回滚，手感的肌肉记忆重练成本高，职业层面尤其。
- **渠道与透明**：高段位玩家与职业选手的反馈通道要有；改动理由公告要写清楚。"策划教你玩游戏"的观感往往来自只改不说。
- **版本冻结**：大赛前锁定版本，这是对选手和赛事的基本尊重。

## 5. 赛事生态

- **天梯是根基**：赛事选手全部从排位里长出来（见 ㉖ 的匹配与分段设计）。天梯不健康，生态是空中楼阁。
- **官方赛事**：奖金池、赛制（联赛/杯赛/邀请制）、线上与线下、场馆、转播制作。全流程是活动运营加转播工业，钱和人都不便宜。
- **第三方赛事与授权**：办赛方需要你的授权（赛事内容授权协议）。授权尺度是战略选择题：全开放授权（生态快速生长，质量参差）对严格控制（质量可控，生长慢）。多数厂商走"分级授权+官方平台申请"的中间路线。
- **俱乐部与选手**：合同、转会、青训、薪资结构的法律要点多（见 ⑦），账号与内容的 IP 归属尤其容易出纠纷（选手社交媒体账号的权属是行业高频争议点）。
- **转播与平台**：直播平台合作是触达主渠道；转播权、二创授权条款提前定。

## 6. 中国的实际情况（口径核实于 2026-10，办事前以主管部门要求为准）

- **身份**：电竞在 2023 年杭州亚运会首次成为正式竞赛项目，中国队以 4 金收官（新华社报道）；行业的公共形象与政策环境整体转正。
- **赛事监管**：由国家体育总局体育信息中心主办或合办的国际性电竞赛事需按程序报批；其他赛事的审批/备案要求**按举办地体育主管部门规定执行**（各地不一，有的城市要求申报审批，有的只需备案，有的不作专门要求）,办赛前必查当地口径。
- **演出与大型活动**：线下赛事具有演出性质，办赛主体通常需要《营业性演出许可证》等资质，并按当地要求办理文化、消防、公安等许可；观众规模达到大型活动标准的（如千人以上）还需公安安全许可。
- **赛事用游戏**：国内正式比赛使用的游戏应为已获版号、可合法运营的产品；电竞内容的运营主体资质（网络出版、ICP 等）与游戏运营同一套体系（见 ⑧）。
- **选手与俱乐部**：体育系统赛事要求选手年满 18 周岁；俱乐部与选手存在注册体系（自愿注册，但注册方可参加体育系统批准举办的赛事）。
- **直播合规**：选手、主播的言行受平台规则、行业规范（如《电子竞技主播行为规范》类文件）与法律的多层约束。

## 7. 什么时候不该做电竞

- 日活人口撑不起排位匹配（匹配都要等五分钟，谈何赛事）。
- 观赏性差：观众看不懂、看不到、不想看。
- 团队没有活动运营与转播制作的能力，也没有预算外包。
- 把电竞当作救命稻草：它只会放大结果，不能创造结果。

## 8. 常见坑

1. 玩法还没立住就开始规划赛事。
2. 回放系统没有在架构期预留，想办赛了补不上。
3. 导播工具缺失，赛事转播靠人肉横切镜头。
4. 赛季内大改版本，选手集体心态爆炸。
5. 只按职业数据平衡，大众体验崩坏。
6. 授权政策一言堂，第三方赛事生态长不出来。
7. 线下赛资质与许可没办，活动被叫停。
8. 选手合同潦草，账号与内容归属留雷。
9. 反作弊不给力，天梯顶端全是挂（见 ㉖）。
10. 把赛事预算当营销预算的零头，办出四不像。
