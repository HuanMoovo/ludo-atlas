# Ludo Atlas · 入门 · 岗位与技能地图

> **入门区**（第 ㉛ 轮扩展）。这一页按八条线拆开游戏开发的岗位：每条线做什么、核心技能、日常产出、怎么起步。适合考虑入行、组队，或者想弄清「我现在该练什么」的人。

## 1. 程序线

把设计与内容变成能运行、流畅、不崩的软件。

| 岗位 | 做什么 | 核心技能 | 起步做什么 |
| --- | --- | --- | --- |
| 玩法程序 | 实现战斗、技能、交互、关卡机制 | 一种引擎的脚本语言、状态机、设计模式 | 用引擎做三个小玩法原型 |
| 引擎/系统程序 | 渲染、物理、内存、工具链 | C++/Rust、数据结构、图形学基础 | 读开源源码，写小引擎模块 |
| 工具程序 | 给策划美术造编辑器与流水线 | 编辑器扩展、UI 框架、自动化 | 给引擎写一个关卡编辑插件 |
| 服务端程序 | 联机同步、账号、匹配、反作弊 | 网络协议、并发、数据库 | 做一个联机小游戏后端 |
| 图形/技术美术 | 渲染效果、性能优化、美术管线 | 着色器、渲染管线、美术工具 | 复刻经典着色器效果 |

深入路线见[技术实现手册](../fundamentals/programming/README.md)（⑩）、[引擎源码阅读路线](../fundamentals/engine-internals/README.md)（㉘）。

## 2. 设计线

决定「玩什么」与「为什么好玩」。设计不是写文档，是不断做出可验证的决策。

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 系统策划 | 核心循环、成长、经济系统 | 系统拆解、表格与数值建模 |
| 数值策划 | 战斗公式、掉落、经济平衡 | 数学、Excel/Python 建模、概率直觉 |
| 关卡策划 | 空间、节奏、教学、挑战 | 关卡编辑器、节奏设计、白盒 |
| 战斗策划 | 手感、技能、敌人与 Boss | 动作原理、帧数据、博弈分析 |
| 叙事策划 | 世界观、剧情、对话、任务 | 写作、分支结构、演出设计 |

起步方式：拆 3 个你喜欢的游戏的核心循环，写成文档；再做 3 个你自己的小玩法原型。见[游戏设计手册](../fundamentals/game-design/README.md)（⑨）与[关卡设计手册](../fundamentals/level-design/README.md)（㉑）。

## 3. 美术线

决定游戏看到的一切。

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 原画/概念 | 定风格、出设定 | 造型、色彩、剪影设计 |
| 2D 美术 | 角色、场景、UI、图标 | 像素/矢量/绘制管线、图集规范 |
| 3D 美术 | 建模、UV、贴图、绑定 | 建模软件、拓扑、PBR 流程 |
| 动画师 | 角色动画、特效动画 | 关键帧、曲线、动作原理 |
| 特效（VFX） | 打击、爆炸、氛围特效 | 粒子系统、材质、节奏 |
| UI 美术 | 界面视觉与交互稿 | 排版、组件规范、动效 |
| 技术美术 TA | 美术与程序之间的桥 | 着色器、脚本、管线工具 |

作品集比学历重要：3-5 个完整作品，每个能讲清「目标、做法、结果」。AI 辅助工具的用法见 [AI 工作流手册](../ai/README.md)（⑲）。

## 4. 音频线

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 音效设计 | 打击感、环境音、拟音 | 录音、合成、音频处理 |
| 作曲 | 主题曲、动态配乐 | 乐理、和声、情绪设计 |
| 音频实现 | 把音效接进引擎、混音控制 | 中间件、脚本触发、混音总线 |

半路出家可行：先给免费素材库做正确的实现与混音，也是有效练习。见[美术与音频手册](../fundamentals/art-audio/README.md)（⑪）。

## 5. 制作线

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 制作人 | 定方向、管风险、对上对外 | 判断力、沟通、砍需求 |
| 项目经理 | 排期、协调、跟进阻塞 | 任务拆解、工具（看板/文档）、预测 |

见[制作管理手册](../fundamentals/production/README.md)（⑫）。独立开发者建议每周花半天做「制作人时间」：看进度、砍范围、重排优先级。

## 6. 测试线（QA）

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 功能测试 | 按用例验证功能与回归 | 用例设计、边界思维 |
| 兼容性测试 | 设备、分辨率、性能矩阵 | 设备管理、性能工具 |
| 自动化测试 | 脚本化回归、录制回放 | 脚本语言、CI 集成 |

QA 是理解产品全局最快的岗位之一，常由此转入设计或制作方向。

## 7. 发行线（市场与商务）

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 市场/宣发 | 商店页、预告片、社群、KOL | 内容策划、渠道理解、数据复盘 |
| 商务 | 平台关系、发行签约、展会 | 谈判、人脉、合同常识 |
| 发行运营 | 愿望单、上线节奏、促销 | 平台后台、数据指标 |

独立开发者的「发行」就是自己：愿望单运营与商店页打磨见[全平台上架手册](../../playbooks/platform-launch/README.md)（⑧）。

## 8. 运营线

| 岗位 | 做什么 | 核心技能 |
| --- | --- | --- |
| 社区运营 | 玩家沟通、活动、反馈闭环 | 内容、共情、危机处理 |

## 9. 怎么选、怎么练

三个自测问题：

1. 你连续几个小时做着不烦的事是什么？（写代码 / 画画 / 拆解规则 / 写字 / 组织协调）
2. 你更愿意「从零创造」还是「把已有的打磨到极致」？
3. 你现在能每周稳定投入几小时？

对应练习方式：

| 倾向 | 主修 | 第一件事 |
| --- | --- | --- |
| 逻辑与系统 | 程序 / 数值 | 用引擎完成三个机制原型 |
| 审美与表达 | 美术 / 叙事 | 完成一套主题统一的作品 |
| 拆解与共情 | 设计 / QA | 拆解三个游戏的完整循环文档 |
| 组织与推进 | 制作 / 发行 | 组织一次游戏开发活动或发布 |

小团队身兼多职的常见组合：程序 + 美术 + 设计三角；音效与测试常外包。相关经验见[独立开发者档案](../meta/people/indie/README.md)（⑰）与[独立开发生存手册](../../playbooks/indie-survival/README.md)（⑱）。
