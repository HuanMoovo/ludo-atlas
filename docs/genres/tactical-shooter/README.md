# Ludo Atlas · 类型手册 · 战术射击（Tactical Shooter）

> **类型手册 P3 批次**（第 ㊵ 轮扩展）。定位：把「交火之前的准备」做成主要胜负手的团队竞技类型。低容错让每一枪都很贵，信息博弈让「谁先知道」比「谁打得准」更早决定结果，回合经济让每个回合都在为下一个回合下注。
> 配套：《游戏设计手册》（⑨，循环与数值）·《技术实现手册》（⑩，数据驱动与性能）·《联机与后端深入手册》（㉖，同步、匹配与反作弊）·《电竞与竞技设计手册》（㉗，平衡、观战与赛事）。
> 本文不放外链；标杆只列大众熟知作品，数字为常见量级，按自己项目实测校准。

## 1. 定位与核心循环

一句话定位：战术射击是**把「交火之前的准备」做成胜负手**的团队竞技射击类型。低容错（几枪定生死、狙击一枪毙命）逼玩家认真对待每一次暴露；信息博弈（谁先看到谁、谁先架住谁）决定交火天平往哪边倾；回合经济（买什么、攒什么、什么时候拼）把单局胜负串成一条预算链。

家族位置：射击家族里把竞技对抗推到制度层面的一支。枪感与命中反馈与 FPS 同源（见《类型手册 · FPS》），但它在枪感之上加了回合制、经济与信息三套规则，把「一枪的代价」从一条数值调成一套制度。

核心循环用动词环写：

`侦查与架点 → 交换情报与计划 → 道具开道与进入 → 短促交火 → 下包、拆包或残局处理 → 回合结算 → 经济重整 → 下一回合`

环里有两层时间尺度：秒级（架枪、拉枪、道具落点）与回合级（经济、比分、半场）。它成立的前提有三条：命中判定可信（每发子弹的去向可解释），信息规则自洽（声音、视野与报点值得信赖），经济闭环（赢有奖励、输有希望）。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 第一人称射击（FPS） | FPS 是枪感与空间语言的底座；战术射击在其上加回合、经济与信息三套规则，把单发子弹的价值放大成制度。 |
| 英雄射击 | 英雄射击用更长的 TTK、技能与重生窗口把交火拉长成拉扯与翻盘；战术射击反过来走，把 TTK 压到全类型最低、技能退成辅助道具，胜负提前到交火之前。 |
| 撤离射击 | 撤离射击把风险带去局外（带得出去才算数）；战术射击的风险按回合结算，装备每局重买，输赢当场清零再重来。 |
| 大逃杀 | 大逃杀一局一条命，资源靠搜刮；战术射击多回合重开，把资源竞争做成买枪经济学。 |
| 硬核模拟射击 | 拟真射击（军事模拟一类）追求战场的真实复杂度；战术射击是竞技抽象版，砍掉无关手续、收敛变量，只为对抗公平服务。 |

一个自检问题：把回合制、经济与信息规则全部拿掉，若剩下的只是一款普通 FPS，你做的就还不是战术射击。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **死得明白**：低容错的前提是公平感；每次阵亡都要能复盘到「谁在哪个角度先手」。死得不明不白，学习曲线就断了。
2. **信息即优势**：脚步、开镜、道具声与报点构成一本可经营的情报账本；耳朵与判断和枪法一样值钱。
3. **经济的心跳**：存钱、强起、满买，每个回合的决定都牵动下一个回合的底气。
4. **协同兑现**：道具配合、交叉火力、残局喊话；个人能力之外另有一条团队进步曲线。
5. **残局名场面**：1v3 拆包、翻盘与加时，是这类游戏最容易被复述和传播的时刻。

标杆作品（建议亲手玩过再拆；低容错的手感与压力在手上，不在视频里）：

| 作品 | 拆什么 |
| --- | --- |
| 反恐精英系列 | 类型基准：回合经济、爆点地图与「枪法定生死」的竞技标尺 |
| 无畏契约 | 战术骨架加英雄技能：技能负责信息与地图控制，枪法仍然定生死 |
| 彩虹六号：围攻 | 准备阶段、可破坏场景与信息道具：把「交火前」扩成整回合的内容 |
| 穿越火线 | 国内大众化样本：节奏更快、门槛更低与庞大的网吧人口 |

## 3. 设计要点

### 3.1 低容错与信息博弈

TTK 是第一个旋钮。常见量级：步枪三到五发毙命、爆头一到两发、狙击一枪一条命；护甲与穿透是主调节杆。调 TTK 的纪律：让「先手命中」有压倒性收益，但不让「擦到一下」就等于死亡，否则挫败感会压过学习欲望。

低容错要成立，靠三件事：

- **死得明白**：击杀回放、受击方向指示与命中音效是基础配置；判定的透明度就是信任。
- **先手有价，但可以破**：预瞄与架枪有优势，进攻方要靠道具、角度与人数把优势换回来；先手固定到无解，回合就变成开盲盒。
- **出生线逐条测**：谁能在开局看到谁的出生点，是地图平衡的一部分，与其他数值一样进表管理。

信息博弈的底子：声音是最廉价的信息通道，脚步、开镜、换弹、道具落地都要有距离衰减与材质区分；视觉信息（缝隙、影子、道具边缘）决定架枪与拉枪的价码。报点语言要标准化，点位名先定、再谈战术；同一句话队友能画出同一张图，协同才有起点。

### 3.2 回合经济与装备购买

经济系统是这个类型的第二张平衡表。它的目标不是攒钱，而是让每个回合都有人在核算：这一局拼，还是存。

经济来源与常见量级：

| 来源 | 常见量级 | 设计意图 |
| --- | --- | --- |
| 回合胜方奖励 | 三千上下 | 领先方的基本盘，同时防止雪球滚死 |
| 连败补偿 | 一千四起逐级升到三千四一类 | 给败方看得见的希望，反雪球的核心阀 |
| 击杀奖励 | 一百到九百，按武器区分 | 冲锋枪与霰弹枪给高、狙击给低，奖励以弱胜强 |
| 下包与拆包奖励 | 全队各得数百 | 给目标动作定价，鼓励做事而不是躲着 |
| 金钱上限 | 一万六一类 | 防止无限积累，优势不能跨越太多回合 |

购买菜单按层级停靠：手枪、冲锋枪与霰弹枪、步枪、狙击、护甲与拆弹器、道具；价格表要保证「每上一层多一分胜算、也多一分破产风险」，买枪才是真决策。回合决策的四种基本盘：满买（全队全装求稳）、强起（半装硬拼，赌对面的经济节奏）、纯存（全队不买只保枪）、半买（几把重枪带几把短枪），四种都要有「输得起、赢得值」的清晰核算，玩家才会真心研究经济。

团队纪律三条：经济与买枪信息全队可见；存钱局要全队共识（一个人偷偷买枪，毁的是全队节奏）；指挥要读对面经济（连败第几局、会不会强起，是残局之外的第二个棋盘）。反雪球靠三件套：差异化的击杀奖励、逐级递增的连败补偿、金额上限与换边重置；缺任何一件，优势方会一路满买到终场，经济变成装饰品。

### 3.3 战术道具与团队配合

道具是「不靠枪法也能改变局面」的第二套武器。主流四件套各有分工：

| 道具 | 作用 | 典型用法 | 反制 |
| --- | --- | --- | --- |
| 烟雾 | 阻断视线，划临时边界 | 封枪线、封拆包角度、伪造进攻方向 | 补烟、听声辨位、穿烟预判 |
| 闪光 | 剥夺视觉窗口 | 进入前糊点、反清架点 | 背闪、卡视角、数时间 |
| 燃烧物 | 封路与逼位 | 清角落、封锁拆包、拖时间 | 等烧完、换角度 |
| 破片雷 | 伤害与破甲 | 逼走位、探点、压低资源 | 移动规避、听拉环声 |

道具设计三条纪律：可预测（同投掷点、同结果，训练才有价值，随机性只能出现在无关紧要处）；可反制（烟能补、闪能背、火能等，任何「无解道具」都会毁掉回合设计）；有代价（价格与携带上限构成取舍，道具不能是免费的全能解）。

配合的最小单元是「一个人给另一个人铺路」：烟为突破手封枪线、闪帮第二个人进入、火点掉守方的退路。再往上是全队结构：突破手开角度、辅助保证进入、狙击盯长视距、指挥读经济与节奏。职责是分工，不是职业限制。

「默认」与「执行」是同一张图上的两种节奏：默认控图、逼信息、等对面犯错；执行把全部道具压在一分钟以内打一个点。两种节奏都要成立，局才有变化。

残局是个人能力与信息管理的高光地带：报点压住对面的信息、留道具、拖时间、记对面经济；设计上要给残局「可讲的故事」（拆包倒计时与 1vN 的经济代价），让败方也有掌声。交流基建不能省：点位名表、快捷信号、回合内的信息纪律（报「谁、在哪、几血、什么装备」）；语音之外要有一条能走通的信息通道，这是给所有玩家而不是只给开麦玩家的。

### 3.4 地图设计：对称与爆点结构

两种传统并行：对称竞技图（反恐精英与无畏契约一脉：两端出生、两张爆点加一条中路）与可破坏空间图（彩虹六号一脉：楼层、破坏面与信息道具让「地图形状」可变）。第一步都是画拓扑：先定连通与距离，再摆掩体、道具位与角度。

爆点结构的四件套：

- **两条进入路线加一条中路**：每个点位至少两条真入口；中路是信息与转点的总线，控中路的一边先拿到残局节奏。
- **出生点到点位的距离差**：决定回防与转点时间，攻守双方的时间表要在同一量级。
- **角度经济学**：每个架枪角度都要有代价（暴露窗口、退路）；交叉火力点与可穿墙点（按材质单独列表）是地图的第二语言。
- **时间刻度**：开局到首接触、下包、拆包、加时；先定这些数字，地图围着它们长。

对称性的落实不是美术对称，而是机会对称：两张点位的进入成本、道具收益与回防时间要在一个量级；攻防胜率按地图与点位拆开看，偏差过大先查地图（路宽、掩体、道具收益），别先怪武器。引导与可读性同样归入地图设计：出生点、路标与音景区分（听声辨位）是地图的第一课，三条路各自通向哪、哪条有道具位，要让新玩家在几局内自己画得出来。

### 3.5 匹配、竞技体系与反作弊

竞技体系一条链：匹配决定每天的体验，段位与赛季决定目标感，赛事与平台生态决定人口与内容的天花板。

- **匹配**：隐藏分与展示段位分离，给新手池与回流缓冲；组队与单排的池子规则先写清。战术射击的匹配对沟通质量尤其敏感，语音与信息纪律的差异会在低分段放大（做法见《联机与后端深入手册》（㉖）§4）。
- **排位与段位**：赛季制、晋级与掉段、定级与跳级规则要讲得清楚；玩家对段位的信任是这个类型长线的一部分。
- **赛事生态**：从社区赛、第三方平台到官方联赛；观战与转播是放大器，先自查「比赛是否看得懂」（道具、残局与经济的表达），再谈办赛（《电竞与竞技设计手册》（㉗）§5、§7）。版本稳定性是底线：选手的战术库与肌肉记忆按版本积累，赛季内大改是大忌（㉗ §2）。
- **反作弊**：短 TTK 下作弊收益极高（一枪即一命、一次判定改写一个回合），客户端检测、服务端行为统计与举报人工复核三层缺一不可；回放是复核与观战的共同底座（㉖ §7）。反作弊是持续的军备竞赛，要写进长期账单，不是上线前的一个插件。
- **公平红线**：外观与数值解耦，重要比赛前冻结版本；「什么时候可以大改」写成制度，而不是临时决定。

## 4. 技术要点

工程难点集中在四处：服务器权威的低容错判定、道具系统的确定性、回放观战基建、服务器与运维账。以下与引擎无关；同步与匹配的完整展开见《联机与后端深入手册》（㉖），数据驱动与性能见《技术实现手册》（⑩）。

### 4.1 服务器权威与射击判定

- 伤害与命中全部服务器计算，客户端只做输入采集与表现预测。低 TTK 把判定错误的代价放大到极致：本地看着命中的一枪没算，背后可能就是一个回合。能服务器判的都不交给客户端，这是竞技底线，不是性能选项。
- 延迟补偿（命中回溯）是必需品：服务器按玩家当时的画面重放判定，回溯窗口要有上限并公开口径；不做回溯，高延迟玩家被系统性淘汰，不设上限，低延迟玩家觉得被「隔墙打死」。
- 更新率与判定频率解耦：服务器更新率（64 或 128 一类的传统口径）之外，新一代做法把射击判定绑定到输入时刻，不再等下一帧服务器帧。无论哪种，客户端预测都要克制：移动先走，命中以服务器为准，偏差在表现层平滑修正。
- 探身优势是网络与地图的合谋：插值与延迟让拉出掩体的人先看到架枪的人。别指望网络层修死它，在关卡里用地形、掩体深度与角度消化它。

### 4.2 道具系统的工程实现

- 烟、闪、火各是一套实体与判定模型：烟是体积与视线遮挡，闪是视线可见性判定，火是区域与时间场。三套都要跨局一致（同点同结果），否则训练价值归零。
- 投掷物先做物理表现、以服务器为准：轨迹可以客户端预测，落点与效果由服务器仲裁；灭火、补烟与可摧毁道具的交互同样服务端计算。
- 材质表合并管理：可穿（子弹）、不可穿、单向（挡人不挡子弹）与道具遮挡放进同一张表，判定与视觉用同一份数据，杜绝「看着封住了其实没封」。

### 4.3 回放、观战与反作弊基建

- 回放录制从原型期就做：复盘、举报复核、观战与内容创作共用同一套设施，晚做等于重做（㉗ §3）。
- 观战系统预备导演视角、慢放与信息面板；直播延迟用来隔离信息（防偷看），在设计期定档。
- 数据探针：每回合记录经济、道具消耗、首杀时间与点位维度，平衡工作靠账本而不是感觉（⑩）。
- 训练与自定义房是长期基建：练枪、练道具线与社区活动都从它开始。

### 4.4 服务器与运维账

- 延迟与运维两本账：地区服选址、对局分池与跨区合并是体验参数（㉖ §8）；服务器、匹配与反作弊审核按月结算，行为治理（挂机、恶意破坏）直接吃留存，复核人力提前进预算。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。数字是尺子，用自己的团队速度校准。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 玩法原型 | 1 张灰盒图、1 种回合模式、房间制 | 小团队 3-6 个月 | 只验证「低容错加回合经济」的回合心跳是否成立 |
| 小型竞技作品 | 3-5 张图、基础排位与反作弊打底 | 小团队 1-2 年 | 平衡、服务器与反作弊是主要账单 |
| 商业级战术射击 | 多图、赛季运营与赛事生态 | 团队 3-5 年以上加持续运营 | 运营型产品，反作弊与地图是长期账单 |

账单拆解：

- **地图**：每张图吃几十到上百轮试玩；一改地形，全部道具投掷线重测。地图是这个类型最贵的单件资产，也是战术层的一半。
- **反作弊与安全**：持续军备竞赛、按月结算；举报复核与误封申诉的人力都要进预算，不能按一次性采购估算。
- **武器与道具**：每把枪的手感、伤害与价格要一轮轮调；每件道具与新地图的交互（哪里能封、哪里能烧）都在追加测试量。
- **经济调参**：牵一发动全身（改一个价格，全部战术重算），要有模拟与数据跑批工具才敢动。
- **小团队的现实路径**：把规模按比例缩小：1-2 张图、5v5 或 3v3、道具减到两三件、先做房间制与社区服，排位与赛事往后放。若你被「低容错的博弈」吸引，先验证一件事：一局打完，玩家是否想立刻再来一个回合。

## 6. 第一个原型怎么起步

目标：4-6 周做出一个灰盒回合制房间，验证「低容错加经济加道具」的回合心跳。不碰排位、不做皮肤、不写剧情。

1. （第 1 周）枪感与判定。白盒场地加一把步枪、一把手枪：服务器判定、命中反馈、击杀回放三件套到位，先让「死得明白」成立。
2. （第 2 周）回合制。攻防回合、下包与守点计时、回合与半场计分、换边；一种模式先做到闭环。
3. （第 3 周）经济。起始金额、回合奖励、连败补偿、击杀奖励与三到四档买枪菜单；经济数值全部进表、可热改。
4. （第 4 周）道具与地图。烟雾、闪光、燃烧物任选两件做完整；一张对称草图：两个点位加中路，站位与路线先用几何体。
5. （第 5-6 周）测试与复盘。5v5 内部连打三天，记录经济决策、道具使用与残局处理；只调数值与布局，不加新系统。

起步参数（可直接抄来改）：5v5；回合 100-120 秒一类；购买阶段 20-30 秒一类；起始金额 800 一类；半场先到 13 分一类；道具 2-3 种；图 1 张。

验收标准（全部可观察）：

- 拿掉全部美术与音效，测试者仍愿意反复打，单次 20 分钟以上。
- 测试者能说出上一回合输在「经济、信息还是枪法」，而不是只有「对面枪准」。
- 存钱局与强起局在复盘里被认真讨论（经济可读的最小证据）。
- 任意改一个价格或奖励数值，你能在一天内说清它对回合胜负的影响；说不清，说明工具还没就位。
- 测试者是主动想再打一个回合，而不是被请求再试一次。

## 7. 常见坑

1. **TTK 摇摆或判定不透明**：玩家无法建立预期，被秒了不知道为什么；伤害表与击杀回放先于其他打磨。
2. **经济失衡**：胜者恒满买、败者永不起枪，或者存钱局毫无意义；连败补偿、差异化击杀奖励与上限缺一不可（§3.2）。
3. **地图只做美术对称**：路线与时间不对称，攻守一边倒；先看地图胜率，再动武器数值（§3.4）。
4. **道具随机或过强**：同点位投出不同结果，训练价值归零；烟闪火的判定要可预测、可反制（§3.3）。
5. **信息规则含糊**：脚步音量、穿墙可见性、影子与光效没有定义，信息博弈退化成猜谜。
6. **反作弊晚做**：短 TTK 下自瞄与透视收益最高，天梯可能一夜被击穿（㉖ §7）。
7. **只做枪法，不做战术层**：没有地图与道具的配套，类型与普通 FPS 没有区别，竞技生态没有立脚点。
8. **匹配池过早细分**：新段位、多种模式与地区多层切池，人口被切碎，排队时长先于平衡杀死游戏（㉖ §4）。
9. **观赛与回放不预留**：赛事、内容与举报复核全卡在基础设施上（㉗ §3）。
10. **版本大改打断战术库**：赛季内大改手感与地图，选手积累全部作废（㉗ §2）。
11. **把「难」当卖点**：没有教学、训练场与新手池，能留住的只剩极少数硬核玩家。
12. **付费与强度耦合**：卖强度等于在天梯里自证不公平，竞技信任一次烧光。

## 延伸阅读

- 《游戏设计手册》（⑨）§2、§4：核心循环与数值表方法，第 3.2 节经济系统的底稿。
- 《技术实现手册》（⑩）：数据驱动、热更新与性能方法论，第 4 节的配套。
- 《联机与后端深入手册》（㉖）§2、§4、§7、§8：同步模型、匹配、反作弊与成本运维，第 3.5 与 4 节的展开。
- 《电竞与竞技设计手册》（㉗）§2、§3、§5、§7：版本稳定性、观战系统、赛事生态与办赛自查。
- 《关卡设计手册》（㉑）：路线、掩体与道具位的度量与引导，第 3.4 节的展开。
- 《避坑大全》（⑥）与《独立开发生存手册》（⑱）：高频坑位与范围控制，与第 5、7 节互为补充。

练习：选一场公开的战术射击比赛录像，逐回合记录经济状况、道具消耗与首杀时间点，找出哪几个回合的经济决策改写了比赛；再自己打三局，写下每局「最贵的三个错误」。

战术射击看起来在卖枪法，实际卖的是「交火之前」的判断与积累；枪法是入场券，信息、经济与协同才是赢法。
