# Ludo Atlas · 类型手册 · 互动电影（FMV）

> **类型手册 · 第四辑**。定位：以真人拍摄的影像为第一素材的叙事类型。玩家的动作是看、选与检索；影像与表演负责说服力，分支与剪辑负责参与感，素材成本决定项目能不能活下来。本页覆盖素材成本结构、分支剪辑治理、交互设计与表演四块骨架。
> 配套：《游戏设计手册》（分支结构与叙事成本）·《美术与音频手册》（影像与录音规格）·《案例研究集》（拆解与复盘方法）·《独立开发生存手册》（范围控制与预算纪律）。
> 本文不放外链；标杆只用大众熟知的作品，数字均为常见量级，按自己项目的实测校准。

---

## 1. 定位与核心循环

一句话定位：互动电影是**把真人影像当第一内容**的叙事类型。玩家的全部动作发生在镜头之间的缝隙里：选一条路、搜一个词、点一处细节；画面停不停、玩家能想多久、选了有没有后果，就是这个类型的全部设计学问。它来自激光影碟时代的影像实验，在数字发行时代被《她的故事》一代作品带回主流；中文社区叫法不一（真人互动、全动态影像、互动式电影），今天它同时活在游戏平台与流媒体平台上。

核心循环用动词环写：

`观看一段影像 → 做选择或检索 → 看到后果 → 修正对故事的理解 → 想看下一段`

这个环的节奏由剪切点控制：玩家在一个片段里只能看，在片段交界处才能动。所以设计工作的一大半，是决定「哪里开门、门开多大」（§3.1、§3.2）。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 视觉小说 | 一句话分野：视觉小说把预算花在写手身上，互动电影把预算花在片场身上；分支治理同源，成本结构相反 |
| 叙事探索 | 推进权在脚步与目光；互动电影把推进权锁在片段交界处，玩家的动作是选与看 |
| 互动叙事剧（Telltale 式三维演出） | 都用对白与选择推进；对方烧的是动画与面捕管线，互动电影烧的是拍摄日 |
| 传统影视 | 观众只能看；玩家在关键节点有话语权。互动电影卖的就是这份话语权，影像质量是入场券 |

一个自检问题：把全部选择删掉、剪成一部成片，还看得下去吗？看不下去，说明素材不过关；如果删掉之后毫无损失，你拍的只是一部电影，还搭上了互动系统的钱。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **表演的说服力**：真人脸上的细节是动画与文字替代不了的；影像的「信」一旦崩（收音糊、表演假、灯光糙），后面全部设计跟着陪葬。
2. **选择的重量**：我的决定改变的是画面里真的发生的事，而不是一个数字；选择后最迟下个片段内要看到后果的苗头。
3. **观看的牵引**：每个片段交界处都欠着一个答案（接下来是谁、为什么、会怎样）；让人连看半小时不想停，是这个类型的节奏基本功。
4. **挖掘与分享**：多结局、隐藏线、可检索的素材库让「再看一遍」变成玩法；真人作品天然好截图、好讨论，对独立项目是性价比最高的一层传播动力。

反面感受（出现任意一条都是红灯）：选择没有后果；无信息量的片段堆时长；交互与影像脱节（在对话戏里插无关小操作）。

标杆作品（均大众熟知，建议亲手玩过再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 她的故事（2015） | 素材库检索的极限样本：零分支拍摄，把一部电影长度的素材切成 271 个片段，靠一个搜索框撑起完整玩法 |
| 不朽（2022） | 电影片段、幕后花絮、私密影像三类素材交织；匹配机制让「考古」成为核心循环 |
| 夜班（Late Shift，2016） | 全动态分支电影的制作样本：180 多个选择点、7 个结局；选择不暂停画面，考验限时交互的分寸 |
| 黑镜：潘达斯奈基（2018） | 主流长片平台的互动实验；对「伪选择」与节奏的争议是最好的复盘材料 |
| 隐形守护者（2019） | 国内真人影像互动的商业样本：影像加选择的组合与发行打法 |
| 完蛋！我被美女包围了（2023） | 真人恋爱互动的传播样本：受众定位与话题设计比制作规格更重要 |

## 3. 设计要点

### 3.1 分支结构：链式与素材库两种骨架

两种骨架对应两种成本模型与两套拍摄计划：

| 骨架 | 玩法 | 成本特征 | 代表作 |
| --- | --- | --- | --- |
| 链式分支 | 选择点直接指向不同的后续片段，分支汇合后继续 | 每个选择点都要真拍；成本随分支数近似线性叠加 | 夜班、隐形守护者 |
| 素材库检索 | 素材不预剪成分支，玩家用搜索与浏览决定看什么、按什么顺序看 | 拍摄一次、全部可用；成本压在素材量与标签体系上 | 她的故事、不朽 |

链式分支的三条治理规则（每条都能换算成钱）：

1. 收敛点先行：每开一个分岔，先把汇合位置写清楚。两条分支汇回同一场戏，成本是加法；不收敛的树，成本是乘法。
2. 关键选择克制：真正改变走向的硬选择控制在个位数到十几个；其余用轻差分实现（同一场戏换台词、换画面、换反应）。
3. 片段表是唯一事实来源：每个片段登记编号、时长、入边、出边、影响的旗标与拍摄状态；拍摄计划与剪辑进度都从这张表派生，未登记的片段在项目里不存在。

剪辑治理同样按三条纪律走：

- 片段独立可懂：玩家可能先看到任何一条分支，每个片段单独看都成立，指涉不依赖固定观看顺序。
- 重拍沿用同一镜头方案：同一场戏的多条分支用相同机位与景别拍摄，后期可以交叉组接与互相替换。
- 每接一条边就复看一次：加入新的入边或出边时，检查转场帧、音频交叉与时长衔接；接线错误在玩家那里就是「跳戏」。

片段图的收敛形状（示意）：`开场片段 → 选择点 → 分支一或分支二 → 收敛片段 → 下一选择点`。

### 3.2 交互设计：选择点、限时与小操作

交互工具箱按打断程度分三档，混着用才能既有参与感又不碎节奏：

| 档位 | 形式 | 频率量级 | 分寸 |
| --- | --- | --- | --- |
| 明选 | 画面暂停或落幕，等玩家选完再继续 | 全片几个到十几个 | 给足思考时间；选项要让玩家看出立场差异 |
| 限时选择 | 画面继续走，倒计时内作答，超时走默认项 | 常见每 1-3 分钟一个 | 默认项必须安全；时长按最慢的测试者定 |
| 小操作 | 点击线索、检索关键词、翻看物件 | 视玩法而定 | 必须与影像内容相关，不做打断观看的迷你游戏 |

- 后果可见性：选择后最迟在下一个片段里给出可感知的回应（台词、画面、状态提示）；玩家判断不了后果，就会开始乱选。
- 限时选择的分寸：夜班把「不暂停」做成卖点，代价是手慢的玩家被替做主。三段式兜底：关键抉择不限时；中等选择限时但给安全默认项；氛围向的小选择才允许「错过就是错过」。
- 小操作的取舍：检索式交互（关键词、匹配）天然适合这个类型，因为「看」与「动」是同一件事；QTE 只在影像本身就是动作段落时使用，且失败要导入分支，不做判负。
- 密度检验：把全片交互点标在时间轴上，任何一段连续观看超过 3-5 分钟没有一次可动的地方，就加一个检索点或环境交互点，或者把它拆短。

### 3.3 表演与剧本：为分支写戏

剧本按「可拍摄、可剪辑、可分支」三条标准写，不先写线性剧本再回头拆：

- 三件套同步：分场剧本、分支表（§3.1）、拍摄清单（机位、道具、演员、时长预算）一起写、一起冻结；剧本没冻结不开机。
- 台词短、方向明确：分支段落里演员的每个反应都可能变成素材，给执行方向而不是小作文；即兴只留给气氛段落。
- 每场戏留出接点：为可能的汇合准备两种收尾（不同情绪、不同信息量），这是线性剧本训练里没有的纪律。
- 选角与排练不是可选项：观众用影视标准审判真人表演，业余表演把整体档次拉低一格。常见做法：选角单列一周，剧本围读与排练一到两天，关键戏先走一遍调度。
- 表演密度低于影视：玩家会用不同路径反复经过同一批表演，哭戏与咆哮戏要吝啬使用，重看时它们会贬值。

### 3.4 拍摄成本结构：素材是最贵资产

成本分四块，权重先摆明：素材（拍摄）、后期（剪辑、调色、混音、字幕）、互动层（程序、UI、QA、平台适配）、前期（剧本、选角、场地勘察、排练）。

- 素材是唯一不可复用的资产：一场戏拍砸（收音、表演、灯光），后期救不回来，只能重拍；重拍的钱、档期、演员、场地、器材要全部再来一遍。素材质量就是项目的天花板。
- 拍摄日是最硬的约束：人员、场地、器材按天计价，超期即超支；天气、场地许可、演员状态这些变数按「预留缓冲日」写进计划，不靠运气。
- 钱花在镜头内能被感知的地方：剧本打磨、选角、现场收音、基础补光，四项边际收益最高；器材堆料与花哨运镜最低。
- 素材系数先算账：拍摄总量 ÷ 成片总量，线性短片常见 3-8 倍；分支作品每个选择都真拍，总量按分支数叠加（治理办法回到 §3.1 的收敛点）。素材库式接近「拍多少全能用」，但成本转移到了素材量与标签体系的维护上。
- 边拍边粗剪：每个片段拍完就进片段表粗剪一遍，确认它能独立看懂、能接上所有入边与出边；拍摄现场不欠账，是最便宜的返工保险。

## 4. 技术要点

工程难点集中在四处：播放器与分支引擎、素材管线、分支状态、跨平台包体。

**播放器与分支引擎**

- 把片段图当数据：节点是片段（时长、字幕轨、缩略图、旗标），边是选择与条件，播放器只是执行器、结构管理全部在表里；片段交界处就是体验底线，黑帧、卡顿与音量跳变会立刻戳破「这是一部片子」的错觉，转场帧、预加载与音频交叉按每个交界点逐点审核。
- 引擎两条路：通用引擎路线（夜班即 Unity 项目，视频与平台适配成熟）与自研播放器路线（Web 或原生，适合轻量作品与网页分发）；共性要求是硬件解码、前后缓冲、跳过与回看。

**素材管线**

- 素材表管两套规格：每个片段一个稳定 ID 加元数据，代理素材（低码率）用于剪辑与开发期预览，成片按平台规格表进包（分辨率、码率、编码、音频轨道、响度）；剪辑、程序、QA 共用同一张表对账，多语言以字幕轨外挂分发、不重压视频。
- 备份纪律：拍摄现场双备份（卡加盘），素材进剪辑系统即按片段表归档；「素材找不到」是独立团队最常见的致命事故。

**分支状态与存档**

- 旗标集中登记：谁见过了什么、知道了什么、手里有什么，全部进一张状态表；选择只改表，剪辑只读表；调试命令支持直接置旗标跳片段，测分支不用从头看。
- 回看与存档纪律：已看片段可回放、新片段高亮，用结局列表与收集进度化解「我漏了什么」的焦虑；存档存「旗标与已看集合」而不是片段指针，指针型存档一遇结构更新就报错，更新前用旧档实测（同《视觉小说》的存档纪律）。

**平台与包体**

- 影像体积是转化的隐形门槛：1080p 高码率影像每小时约 3.5-7 GB（按 8-15 Mbps 计），几小时全片直接顶到平台的下载心理线。策略：按章节分包、清晰度分档（低码率先玩、高清随进度下载）或流式播放（网络与授权兜得住才用）。
- 触屏适配单列测试：选择按钮命中面积、横竖屏、误触防护；限时选择在触屏上要额外宽容。

## 5. 内容量与工作量参考

成本公式：

```text
总成本 ≈ 成片时长 × 分支倍数 × 单位成片拍摄成本 + 后期 + 互动层 + 前期
```

分支倍数 = 全部可用素材 ÷ 单次通关时长。链式分支常见 2-4 倍；素材库式可以接近 1 倍，但素材绝对量大，靠搜索与排名组织（她的故事即三百段上下的片段库）。

体量档（量级参考，不构成承诺）：

| 形态 | 成片与素材量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 原型短片 | 10-20 分钟成片，素材 1-2 小时 | 4-8 周 | 一条链三个选择点；验证拍摄到可玩的全流程 |
| 小型完成品 | 40-90 分钟成片 | 3-6 个月 | 单地点群、两三条主分支；夜班体量的简化版 |
| 商业长片 | 90-150 分钟成片，分支素材合计数小时 | 12-24 个月 | 影视级摄制管线，专业制片与后期班底 |
| 素材库式 | 素材数小时，靠检索组织 | 视拍摄规模 | 无分支剪辑，成本压在素材拍摄量与标签体系 |

三个单件锚点：

- 拍摄日产出（量级）：低成本剧组一天完成素材 5-15 分钟；除以素材系数（§3.4）就是它贡献的成片时长，重拍与保险方案另留日数。
- 剪辑工作量：分支剪辑不是线性剪辑的加法；每条入边与出边都要接线与复看，工时常见是成片时长的数倍，按片段数乘每条边的接线成本估算。
- 文本与字幕：台词、字幕、结局说明、平台文案全列清单；多语言从第一天按「要翻译」组织（口径沿用《视觉小说》）。

排期锚点：从零到 10 分钟可玩原型 4-8 周；到垂直切片（15-20 分钟、一条完整分支链、发行级画质）常见 2-4 个月；商业体量按年计。

## 6. 第一个原型怎么起步

目标：6-8 周做一段 10 分钟的「一条链三个选择点」，跑通「写、拍、剪、玩、测」全流程。不碰多结局，不碰特效，不上专业器材。

1. 第 1-2 周：剧本与片段表。写 10 分钟成片：3 个选择点、2 条并行分支（各 1-2 分钟）、2 个收敛点；同步出片段表与拍摄清单。剧本不冻结，不开机。
2. 第 3 周：集中拍摄。一台机器、自然光加基础补光、强制现场收音（领夹麦胜过事后配音）；先拍收敛场再拍分支，每个片段拍足收尾用的保险镜头。
3. 第 4-5 周：粗剪与接线。按片段表把每个片段剪到独立可懂，再按选择关系接成片段图；转场帧、音频交叉、字幕一次到位。
4. 第 6-8 周：互动壳与外部测试。播放器加选择点加载（先不考虑美观），找 5 个陌生人测试：记录中途退出的位置、选择后的反应、有没有人主动想看另一条分支；同时记录真实工时，作为下个项目的估算底稿。

成功标准（全部可观察）：

- 陌生人无提示看完全片，且能说出至少一次「我的选择导致了……」。
- 5 人里至少 2 人主动重开，想看另一条分支的后果。
- 全流程跑通且素材系数有真实数字：片段表对得上素材，剪辑对得上分支，播放器对得上选择点，下一次预算不靠猜。

## 7. 常见坑

1. **剧本未冻结就开机**：一句台词的改动连锁重拍，预算翻倍。规避：剧本、分支表、拍摄清单一起冻结再开机（§3.3）。
2. **素材系数失控**：每个选择都真拍、不设收敛点，剪辑间堆着数小时用不上的素材。规避：先写收敛点再写分支，把系数写进预算（§3.1、§3.4）。
3. **假选择**：选完毫无感知，玩家两次之后就不再认真。规避：要么给真差分，要么删掉选择（§3.2）。
4. **制作降级**：收音糊、灯光平、表演业余，观众三分钟内给全片判刑。规避：钱投在收音、补光、选角与排练，器材从简（§3.3、§3.4）。
5. **交互失灵**：限时选择的默认项总是最怂的那个，手慢的玩家被替做主；或在对话戏里硬插动作 QTE，玩与看互相拆台。规避：默认项安全化，重要抉择不限时；交互形式跟着影像段落选（§3.2）。
6. **回看与已看标记缺失**：分支作品没有「刚才错过了什么」的补救，重玩成本高到劝退。规避：回看、已看标记、结局列表从第一天进设计（§4）。
7. **素材管理与备份缺失**：现场单卡单盘、命名混乱，丢素材或对不上号。规避：现场双备份，按片段 ID 命名归档（§4）。
8. **包体失控**：高码率全片下载把移动端用户挡在门外。规避：分档、分包、流式按平台选（§4）。
9. **授权与合同埋伏**：音乐、场地、演员肖像的授权范围不清，出事在发行前夜。规避：每项授权留凭证，演员合同写明肖像使用范围与二次剪辑权。
