# Ludo Atlas · 类型手册 · 模拟驾驶（Vehicle Sim）

> **类型手册 P2 批次**（第 ㊳ 轮扩展）。定位：把「驾驶与运输」本身做成第一乐趣的品类。车辆物理与路况是立身之本，职业循环与地图探索提供长期目标，玩家在驾驶舱里经营自己的一份生活。
> 配套：《游戏设计手册》（⑨，核心循环与经济数值）·《技术实现手册》（⑩，车辆物理、流式加载与性能）·《美术与音频手册》（⑪，地景、引擎声与电台）·《独立开发生存手册》（⑱，范围控制与排期）。
> 本文不放外链；标杆只列大众熟知的作品，文中数字为常见量级，按自己项目的实测校准。

## 1. 定位与核心循环

一句话定位：模拟驾驶是**以操作载具、完成运输为第一乐趣**的类型。玩家在重量、惯性与路况的交互里建立对机械的掌控感，在路网与职业目标里获得「经营自己那份生活」的代入；开车不是赶路的手段，开车本身就是内容。

核心循环用动词环写：

`接单或自选目的地 → 规划路线 → 装载准备 → 长距离驾驶 → 应对路况与天气 → 送达结算 → 升级载具与解锁新区域 → 再接一单`

这个环以「趟」计量，一趟几分钟到数小时。它成立的前提只有两条：驾驶反馈要可信（§3.1），任务回报要看得见（§3.3）。

模拟方向的分野（三个方向共用一副骨架，物理与循环的权重不同）：

| 方向 | 第一乐趣 | 物理权重 | 大众标杆 |
| --- | --- | --- | --- |
| 拟真 | 还原度与操作流程本身 | 高，行为接近真车 | 微软模拟飞行 |
| 街机 | 即时爽感与可读反馈 | 低，手感优先 | 极限竞速：地平线系列 |
| 职业模拟 | 经营目标与地图征服 | 中，够用即可 | 欧洲卡车模拟 2 |

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 竞速 | 竞速的胜负是圈速与名次；模拟驾驶的胜负是准时送达与不出事故 |
| 模拟经营 | 经营里载具是一行数值；模拟驾驶里操作是第一现场，数值是辅助 |
| 生存建造 | 两者都用载具赶路；生存的载具是工具，模拟驾驶的载具是主角 |
| 开放世界动作 | 驾驶只是移动手段；模拟驾驶里运输与路况就是全部玩法 |

一个自检问题：拿掉对手与圈速，只剩路网、天气与运输目标，游戏还成立吗？答案若为「成立」，你做的就是模拟驾驶。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **机械掌控感**：重量、惯性、挡位与刹车距离都能被预判，每次剐蹭都能解释成自己的操作。
2. **旅程感**：出发、路况、天气、到站串成完整的一段叙事；路是内容，不是连通两点的管道。
3. **氛围沉浸**：长途里的风景、电台与独处时间，是这类作品独有的情绪价值，也是与其他驾驶类型的最大差异。
4. **经营回报**：收入、解锁与车库成长让每一趟都有账面进度，长期目标清晰。
5. **低压失败**：剐蹭与超时要罚得有分寸，但别毁掉数小时的回程；可续接、可回滚。

标杆作品（建议亲手玩过再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 欧洲卡车模拟 2 | 职业循环与地图尺度的组合，长途节奏与电台氛围的运营 |
| 微软模拟飞行 | 拟真操作的门槛分层，真实地理数据带来的观光价值 |
| 雪地奔驰 | 地形与路面交互的深度，慢节奏的救援式乐趣 |
| 模拟农场系列 | 载具与经营循环的耦合，任务与农务的日程编排 |
| 美国卡车模拟 | 区域文化差异如何落在路网与地标设计上 |
| 极限竞速：地平线系列 | 街机化驾驶的大众化包装，开放世界兜风 |

## 3. 设计要点

### 3.1 车辆物理与手感：把「重」翻译成直觉

手感纪律与竞速同源（可预测优先于正确），但气质相反：载具更重、加速更慢、刹车更长，玩家与车的关系是合作，不是压榨极限；爽点来自「开得稳」，不是「开得快」。

| 直觉 | 对应参数 | 调坏的后果 |
| --- | --- | --- |
| 重量感 | 车重、重心高度、悬挂软硬、转向阻尼 | 太轻像纸片；太重像开船，无法建立信任 |
| 惯性 | 加减速曲线、空气阻力与滚阻 | 缺失则每次操作都被立刻切断，车像悬浮 |
| 传动 | 挡位逻辑、转速与牵引力的耦合 | 自动挡调不顺，手动挡变成纯负担 |
| 抓地 | 轮胎与各路面之间的摩擦系数表 | 全路面同一个手感，路面与天气系统白做 |

三条通用做法：

- 重载低速是日常动作：窄路掉头、泊位、挂车倒库的精度比高速极限更重要，先在低速段把手感立起来。
- 两套视点都要成立：驾驶舱视点承担沉浸，第三人称承担日常驾驶与泊车；倒车配后视镜与引导线一类的辅助。
- 还原与宽容显式取舍：手动挡、离合、弱辅助服务拟真玩家；默认档位提供自动挡与宽容档，两套体验都要完整可玩。

调参纪律：手感参数集中进数值表并支持热改；在固定路线、固定起点上跑同一段，比较行车数据与逐帧录屏，每次只动一组参数。验收标准：找 5 个人各开 20 分钟，「意外失控」每人不超过 2 次，且失控后能说出自己错在哪。

### 3.2 路面与天气系统：给「路」做分层

路况是这类游戏仅次于车辆的第二内容源，按三层拆开做：

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| 路面材质 | 柏油、水泥、碎石、泥地、雪地、沙地 | 摩擦、颠簸与噪声的差异直接喂给物理 |
| 天气与时间 | 晴、雨、雾、雪、昼夜 | 能见度与抓地随环境变化，把熟路变成新挑战 |
| 路况事件 | 堵车、施工、封路、事故 | 制造路线决策，打断长途的单调节奏 |

三条纪律：

- 区分装饰天气与玩法天气：雨滴与湿反射是氛围；让抓地与制动距离真的变化才是玩法。玩法天气必须可预判，出发前给出天气预报，惩罚才公平。
- 天气要有梯度：小雨、暴雨、雨夜对抓地的影响各不相同才有意义；直接「晴转暴雪」是偷懒。
- 车损、油量与休息（做疲劳系统时）构成一条可见的压力链：加油、修车、休息都是路线规划的一部分，三者叠加不要超过玩家的管理带宽。

### 3.3 职业循环：任务、经济、解锁

职业循环是长期留存的发动机，三层各管一段：任务发放内容，经济定义节奏，解锁控制地图的打开顺序。

任务结构：一单等于起点、终点、货物、时限、报酬五个字段，按三档定价：

| 任务档 | 例子 | 设计作用 |
| --- | --- | --- |
| 短途 | 同城或临近城市配送 | 稳定收入、练手、失败成本低 |
| 长途 | 跨区域运输 | 高报酬换高时间投入，主干进度靠它 |
| 特殊 | 重载、易碎、超限 | 用操作门槛换溢价，给熟练玩家的挑战 |

任务模板要能程序化拼装（起点、货物、时限抽取组合），否则内容量会被手写任务吃光。

经济曲线：收入由运费基数、距离、货物系数与准点无损奖励构成；支出由油、维修、罚单与雇员（做车队时）构成。校验方式只有一条：在真实时长里跑一遍前期曲线，确认第 2 小时、第 10 小时、第 30 小时的玩家分别买得起什么。太紧留不住人，太松一天买满车库。

解锁节奏：车库扩容、新载具、地图区域、技能（长途、重载、易碎运输等）。解锁是发内容的闸门：每开一块地图，旧任务得到新目的地，老路获得新理由。把地图解锁与进度绑定，不要初始全开；全开的地图对新手是迷宫，不是自由。

惩戒设计：超速罚单、货损赔付、疲劳驾驶这类机制是提醒，不是追杀，罚到疼即可；翻车与事故的惩罚落在报酬与耗时上，不清空进度。

### 3.4 地图与地景：成本大头的规矩

地图是这类项目的最大支出项，开工之前先立规矩：

- 尺度决策先行：定「真实里程压缩比」。地面载具很少按 1:1 制作，常见做法是保留路网拓扑与地标、压缩两点之间的距离，把省出的时间换成地图覆盖；压缩比是产品决策，改晚了等于全图返工。
- 模块化三层建库：路段构件（直道、弯道、匝道、桥隧、收费站）、区域主题（草原、山地、海岸、工业区）、地标建筑分开管理；城市与工业区细节密度最高、成本最重，用建筑簇与远景贴片控制。
- 记忆点密度：玩家能容忍路段重复，前提是每隔几分钟有一个可记忆的地标；一条没有任何地标的百公里路线，第二天就想不起来走过。
- 引导系统是地图的另一半：导航、路牌、里程标、加油站与休息站的位置，决定玩家能不能读懂你的路网；靠背板记路的模拟驾驶不合格。

### 3.5 外设生态：从键盘到方向盘的阶梯

这个类型有罕见的硬件生态：玩家会为它买方向盘、踏板、排挡与多屏。外设不是加分项，是内容的一部分，按阶梯设计：

| 档位 | 设备 | 体验目标 |
| --- | --- | --- |
| 最低门槛 | 键盘、手柄 | 顺畅完成长途与倒车，不因输入方式受罚 |
| 进阶 | 带力反馈的方向盘 | 路面、载荷与打滑通过方向盘传出来 |
| 全套 | 方向盘加排挡、离合、手刹 | 还原操作流程本身，玩「过程」而不是「结果」 |

三条纪律：

- 最低门槛的「能玩」优先于外设的「好玩」：多数玩家只有手柄，最低档不顺等于把大头受众拒之门外。
- 力反馈是物理的翻译层：路面信息、轮胎打滑、碰撞冲击都要有对应的反馈，别把一切做成同一种抖动；主流品牌与型号要做兼容矩阵，逐台测。
- 设置菜单是外设体验的一部分：灵敏度、死区、力反馈强度、挡位模式可调并给预设；玩家之间会互相分享配置，这是低成本的运营资产。

## 4. 技术要点

工程难点集中在四处：车辆物理、大地图与流式加载、天气与音频的全局联动、外设适配；以下与引擎无关，方法细节见《技术实现手册》（⑩）。

**车辆物理**

- 从单刚体加轮胎近似模型出发（与竞速同路线），拟真方向再加每轮受力、悬挂与传动求解；重载还要处理挂车铰接、多轴与侧翻边界。
- 物理固定步长并与渲染解耦；重型载具对低速精度更敏感，倒车与泊车要在固定步长下单独验证。
- 载具参数做成可继承的底盘模板：同底盘换车身、内饰与声浪即可派生新载具，这是最有效的降本手段（§5）。

**大地图与流式加载**

- 路段按空间分块流式加载与卸载，远景用低模与贴片；预算按「看得清路边」规划，而不是「看得远」。
- 导航与路网共用一份数据：同一份路网图供给寻路、导航播报与任务生成，避免三套数据各说各话。
- 时间流速是一个全局旋钮：昼夜循环、任务时限、疲劳与油耗读同一个时钟；昼夜要能随时提前切换，否则夜路问题会拖到收尾才暴露。

**天气与音频**

- 天气是全局状态机：云、雨雪粒子、路面湿滑贴图、水雾与灯光联动切换；湿滑从视觉到物理用同一条参数链，别做成两层皮。
- 引擎声是这个类型的半条命：分层采样（怠速、低载、高转、回火）随转速与负载映射，驾驶舱内外两套听感；轮胎、风噪与挂车声补齐信息层。
- 电台是长途的氛围核心：内置歌曲涉及授权成本，常见做法是支持玩家自备音乐或网络电台，避免为歌单谈判。

**外设与设置**

- 外设走设备抽象层：方向盘的转向、力反馈、踏板与挡位抽象成统一接口，再逐设备做配置；输入逻辑不要散落在各处。
- 每类设备给默认配置与校准流程（转角、踏板行程、挡位映射），设置持久化到玩家档案。
- 键位重映射、辅助开关、HUD 布局都算技术需求，不是收尾补丁；这类玩家对设置项的期待高于大多数类型。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 手感原型 | 一条测试路线加一辆车 | 2-4 周 | 只验证驾驶、路况与一趟任务 |
| 小型完整作品 | 1 座城市及周边路网，3-5 辆载具 | 3-9 个月 | 公路网与地景是主体成本 |
| 常见独立规模 | 1 个区域（跨多城路网），6-10 辆载具 | 1-2 年 | 地图与地景通常是预算最大单项 |
| 大型作品与持续运营 | 多国路网，几十辆载具 | 3 年以上 | 地图扩展包是主要追加内容 |

成本拆解：一公里「达到发行质量」的道路等于路面与标线、路侧设施、地标、交通与事件逻辑，再加昼夜与天气变体；地图与地景是预算最大单项。载具的成本拆解：外观模型加驾驶舱内饰（如做）、引擎声与整车声浪、动力与手感参数集、涂装与获取方式；同底盘派生可以显著降本，但内饰与声浪仍是一车一套。

排期锚点：从零做出垂直切片（一小块地图加一趟完整的职业任务链路）通常 2-4 个月；之后按「地图面积乘打磨系数」外推。地图是返工最贵的内容：凡是可以晚做，都不早做。

## 6. 第一个原型怎么起步

第一个原型只做一条路线、一辆车、一趟完整任务，2-4 周完成，不碰大地图，不碰经济之外的系统。

**第 1 周：车与一条路线。** 一段有起点终点、有弯道与起伏的路线，一辆车，基础物理加驾驶舱与追尾两套相机，起点放一个计时器。这个阶段丑是应该的。

**第 2 周：一趟完整的任务链路。** 接单、导航、驾驶、送达、结算五步跑通；报酬先给一个粗暴公式，重点是链路完整，不是数值精算。

**第 3 周：路况与天气各加一层。** 路面材质与一种玩法天气（如雨）进物理，路上放几辆简单交通车；找 3-5 个没玩过的人，观察他们什么时候走神、什么时候骂人、什么时候想再跑一趟。

**第 4 周：调参与验收。** 逐帧录屏调手感，跑一遍前期经济曲线，只改参数与路线，不加新系统。

成功标准（全部可观察）：

- 拿掉全部美术与音效，测试者仍愿意反复跑这条线，单次通常 15 分钟以上。
- 5 名测试者中至少 4 人无口头指导完成一趟任务；「这车有毛病」类抱怨每人不超过 1 次。
- 任意改一个物理参数，你能在 5 分钟内量化它对驾驶的影响。
- 测试者能说出事故错在哪；有人主动要求再跑一趟，而不是被请求再试一次。

手感与任务链路不通过，就不要开始铺地图；地图是这个类型最贵的地基，返工一次伤筋动骨。

## 7. 常见坑

1. **地图先铺大，玩法未验证**：地景是成本大头，核心循环没冷冻就开工，改一次玩法等于全图返工。
2. **把物理正确当目标**：真车物理在游戏里往往难开；玩家要的是可预测，拟真是候选手段而不是目的。
3. **空旷的路线**：没有交通、没有事件、没有地标，长途变成罚站；先解决「路上发生什么」，再谈地图规模。
4. **天气只是贴图**：下雨不改变抓地与制动，玩家把它当装饰，随后不再信任任何天气预告。
5. **经济曲线失速**：前 10 小时买不起第二辆车，或 2 小时买满车库；经济曲线就是留存曲线（§3.3）。
6. **外设体验断层**：键盘凑合能开、方向盘毫无手感，两头都得罪；最低门槛与高阶回报要同时成立（§3.5）。
7. **地图复制粘贴**：无地标、无区域主题差异，玩家记不住走过的路，地图越大越心虚。
8. **惩戒喧宾夺主**：罚单、油量、疲劳叠成三层，驾驶室变成仪表盘考场；压力链要留管理带宽。
9. **长任务没有存档弹性**：一小时的车程中断即清零，玩家不会原谅第二次；断点续接属于底线需求。
10. **范围对标大厂**：直接照抄大厂的地图与车辆表，是这个类型最经典的翻车点（§5）。

## 延伸阅读

- 《游戏设计手册》（⑨）：核心循环、经济数值与体验目标的写法，本文第 2、3 节的底稿。
- 《技术实现手册》（⑩）：固定步长、流式加载与性能预算的细节。
- 《美术与音频手册》（⑪）：地景资产、引擎声与电台音频的工程做法。
- 《独立开发生存手册》（⑱）：范围控制与排期，与第 5 节对照使用。
- 作业：用灰盒做一条十分钟的路线加一趟完整任务，写清它的路况事件与报酬公式；再挑一款你熟悉的载具模拟，记录它把「操作、路况、经济」各占几成，以及它怎样预报天气、怎样结算报酬。

模拟驾驶卖的不是速度，是「在路上的生活」：路修得可信，出车就有理由；回报算得清楚，就值得再跑一趟。
