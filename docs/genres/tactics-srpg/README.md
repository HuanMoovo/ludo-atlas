# Ludo Atlas · 类型手册 · 战棋（Tactics / SRPG）

> **类型手册 P3 批次**（第 ㊵ 轮扩展）。定位：把「排兵布阵」做成第一乐趣，在格子上用行动力、行动顺序与概率把每一次出手变成可复盘的选择。本页覆盖行动系统、职业与克制、命中率的体感、关卡与增援、永久死亡与宽容度，以及小团队的量级参考。

## 1. 定位与核心循环

一句话定位：战棋（Tactics / SRPG）是**把位置与行动顺序本身做成核心资源的回合制战术类型**。每次出手都消耗行动，每次走位都改变下一回合的选项；乐趣来自「预判、执行、兑现」的闭环，而不是手速或操作精度。

家族内部两派，底层骨架同源：以火焰纹章、超级机器人大战、最终幻想战略版为代表的 SRPG 派，长线动力在角色养成与叙事；以 XCOM、高级战争、陷阵之志为代表的战术派，考验集中在单张地图的解题深度。两派共用同一套底座：格子、行动、概率、结算。

核心循环用动词环写：

`侦察敌情与地形 → 读解目标与限制 → 排兵布阵 → 出手与结算（命中、反击、击杀） → 敌方回合 → 评估战损与增援 → 修正计划`

节奏由玩家掌握：稳的玩家先立稳阵型再推进，快的玩家用机动单位直取目标；好设计让两种打法都有生存空间，但都不免费。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| JRPG | 回合制战斗是技能与资源的交换，站位通常抽象；战棋把位置本身变成主要变量。 |
| 自走棋 | 自走棋布置完自动结算；战棋的每一手都要玩家亲自执行与应变。 |
| RTS | RTS 的实时压力是本体；战棋允许慢慢想，考验运筹而非手速。 |
| 4X 与大战略 | 战略层经营归 4X；战棋的棋盘是一张关卡，规模以小队为单位。 |

一个自检问题：如果把战斗改成全自动结算、玩家只能排兵然后观看，游戏还成立吗？若仍然成立，你做的是自走棋或放置类；战棋的乐趣必须落在每一手的手动决策里。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **运筹的掌控感**：胜负能追溯到具体的排兵与取舍，输了知道自己错在哪一手，重开时带着明确的复盘结论。
2. **关键判定的戏剧性**：绝境下的一击命中、关键 miss 的悬念，是回合制独有的情绪高点；前提是概率诚实（§3.3）。
3. **单元的归属感**：单位会积累经验、转职、换装，玩家对「自己养出来的一队人」负责，这是 SRPG 的长线动力。
4. **以少胜多的爽感**：靠地形、克制与配合翻盘，是战术游戏最经典的高光场景。
5. **可复盘的失败**：败因看得见、说得清，重开的动机来自「我知道怎么改」，而不是不服气。

标杆作品（建议至少完整打通一作再拆，战场张力只能上手体会）：

| 作品 | 可学的点 |
| --- | --- |
| 火焰纹章系列（风花雪月等） | 角色养成与战场绑定、章节制关卡、永久死亡与悔棋选项的搭配、支援对话体系 |
| XCOM 2 | 命中概率与掩体、双行动点制、永久死亡与难度自定义、战术层与经营层的双循环 |
| 超级机器人大战系列 | 演出与收藏驱动、精神指令、低上手门槛与系列化内容运营 |
| 最终幻想战略版 / 皇家骑士团 | 高度差、朝向、职业树与转职、叙事与战场的深度结合 |
| 高级战争 | 无养成的纯战术：兵种克制、占领与生产、把地图做成谜题 |
| 梦幻模拟战 | 指挥官与佣兵制、系列认知的长期积累（含手游化的延续） |
| 陷阵之志 | 确定性的另一极：信息全公开、无命中率、敌人意图全预览，把「读盘」换成「解题」 |

## 3. 设计要点

### 3.1 格子与行动系统：移动力、行动顺序、反击

棋盘、行动、结算是一切的底座，先定死再谈职业与关卡；新项目建议从方形四邻或八邻起步。

格型选型（先定拓扑，再谈手感）：

| 格型 | 距离算法 | 优点 | 代价 |
| --- | --- | --- | --- |
| 方形四邻 | 曼哈顿距离 | 规则最直观，移动范围成菱形，寻路与预览都好做 | 斜向不可走位，机动感偏硬 |
| 方形八邻 | 切比雪夫距离，或斜向加价 | 走位更自然，机动单位的空间感更强 | 斜向不加价时直线路径失去意义，规则要先讲清 |
| 六角格 | 轴坐标六向距离 | 六向等距、没有斜线争议，战场最均匀 | UI 与美术适配成本高，教学要多花力气 |

行动系统三种主流做法，选一种做透：

| 做法 | 结构 | 代表 | 后果 |
| --- | --- | --- | --- |
| 阵营回合制 | 我方全体行动，然后敌方全体行动 | 火焰纹章、机战 | 节奏清晰、演出好排；先动方容易滚雪球 |
| 速度序 | 按速度属性排序逐个行动 | 最终幻想战略版、皇家骑士团 | 速度成为核心属性、张力强；行动顺序显示是硬需求 |
| 行动点制 | 每单位每回合少量行动点（移动加出手） | XCOM | 每手都是取舍；规则翻译到 UI 的成本高 |

- 移动力 4-6 格是常见起点，地形进入消耗（平地 1、草丛 2 之类）先问「它教玩家什么」，答不出就删；移动与攻击范围要能同屏预览，范围计算直接用寻路结果。
- 反击是调节先手税的核心工具：常见规则是防守方在武器射程内反击，近战对远程的劣势、弓箭的安全位都从这条长出来；先手优势要定价，出手前能看见反击伤害，「先出手但要吃反击」成立，先手税才成立。

### 3.2 职业、技能树与克制关系

职业的本质是「把一组功能装进一个格子上的棋子」：先定职能，再定数值。

| 职能 | 战场角色 | 怕什么 | 关键参数 |
| --- | --- | --- | --- |
| 重甲 / 前排 | 堵口、承伤、掩护后排 | 破甲与魔法、被绕后 | 防御、血量、偏低的移动力 |
| 近战输出 | 突破与收割，贴身处理关键单位 | 反击链、被集火 | 攻击、速度、过载型技能 |
| 远程 / 法师 | 安全距离输出、越过前排点名 | 近身缠斗、机动单位突袭 | 射程、命中、近身惩罚 |
| 治疗 / 支援 | 续航、解状态、让关键单位多动一次 | 自身脆弱、被优先切 | 治疗量、行动经济 |
| 机动 / 骚扰 | 抢点、切后排、运送与牵制 | 阵地火力网、反击 | 移动力、闪避、脱离能力 |

转职与技能树的两条纪律：

- 树要窄而深，高级职业不做纯上位替代：每个职业给 1-2 个招牌能力，换成长线要有代价，线性升级树很快会让选择消失。
- 每个职业一句「非它不可」：写不出「什么局面必须带它」的职业，删掉或重做；六个职业里三个是数值换皮，是新手项目的常见死法。

克制关系（兵种或武器三角）的两条纪律：

- 倍率要有上限：常见做法是 ±20% 到 ±40% 的伤害差，而不是三五倍；差距过大时走位与配合失去意义。
- 克制要能被看见，也要先对称后不对称：伤害预告里直接体现倍率；初始版本用同一套职业骨架跑通，专属职业与不对称平衡放到后面。

### 3.3 命中率与概率的直觉（体感公平）

概率是最容易被玩家记恨的一环：人对 90% 的失败记忆远强于成功。目标不是数学公平，而是体感可解释。

- 显示值与判定必须一致，或使用可解释的修正（两次随机取平均是经典做法）：别静默改概率，被抓到一次，信任就没了。
- 避开「猜拳区间」：把 60%-80% 的关键判定当成败开关，迟早被骂；胜负手给必中手段（必杀、指令、道具）或落进确定性设计，暴击（3%-15%）留在调味层，别配着永久死亡当裁决者。
- 战斗预告面板是信任的载体：命中、伤害、反击伤害、暴击、是否致死同屏显示；预告与结算必须共用同一条计算管线（§4）。
- 保底与随机源都要可查：连续失手后的小幅补偿可以存在，但要在内部可查、经得起拆包；随机数走可复现的种子体系，读档控制与平衡验证都依赖「同输入同结果」。

验收标准：找 5 名测试者用 70%-90% 命中的攻击各打 20 次，事后问他们漏了几次；体感偏差超过实际 2 次以上的人过半，先查预告与结算的一致性，再查失败代价是否过重。

### 3.4 关卡设计：地形、增援与隐藏目标

一张地图就是一个谜题加一段节奏；SRPG 的关卡同时承担战术考验与叙事演出，两个目的不能互相拆台。

- 地形要能读，每张图给一个主题机制：高低差、掩体、地形加成（防御、闪避、回复）必须画在图上；主题机制（隘口、可破坏的桥、要塞攻坚、渡河）要第一眼可懂，几回合后还能玩出花。
- 胜利与失败条件都要花心思：占领、防守 N 回合、护送、撤退、刺杀，每种条件是一次节奏换挡；主线失败条件（全员阵亡、超时）必须明确，隐藏目标（宝箱、NPC 存活、回合内达成）给熟练玩家加餐且不与主线冲突。
- 增援要预告或可读：无预告的增援是惩罚不是考验；用回合数、区域触发或剧情文本给线索，让增援成为「该提速或该后撤」的提示。
- 关卡要有呼吸：开场侦察、遭遇、中段压力、高潮与收尾各留呼吸位；单关首次通关 20-40 分钟为常见区间，超长单关配永久死亡就是挫败工厂。

每张图过一遍验收问题：玩家第一眼看到的目标是什么？有没有一条「稳赢但无聊」的解法（有就削弱）？第一次失败的原因说不说得清？重开一次要付多少分钟？

### 3.5 永久死亡与难度设计（悔棋与存档宽容度）

永久死亡（阵亡不复生）是 SRPG 的经典设定，也最容易被当成硬核勋章滥用。它的真正作用是让每个单位有分量，前提是损失可避免、失败可承受。

- 永久死亡会把玩家行为推向保守：没有宽容度时，玩家龟缩、拖延、疯狂读档；先想清楚要的是「有重量的选择」还是「高压筛选」，再决定开关。
- 宽容度三件套至少给一件：悔棋（有限次数的行动回溯或回合回退）、中断存档（随时退出续玩）、难度与模式选项（阵亡复活与阵亡退场由玩家选）；火焰纹章近几作与多款同类作品都提供了悔棋，值得优先考虑。
- 存档分层与读档信号：单局中断存档与战役存档分开、自动轮转三到五个槽位；玩家反复读档刷命中说明概率或容错有一环不合格，与其堵存档，不如给可控随机或必中手段（§3.3）。
- 难度来自压力组合，不在数值堆叠：回合限制、增援、资源稀缺、目标冲突四条压力源取两条用透；难度显式可选、中途可降，最硬模式作为可选亮点，不当默认地狱。
- 阵亡单位的处理先写规则：经验与装备是否回收、剧情对话是否留位、替补席位够不够；「人没救回来但剧本还在喊他」是低成本项目的高频穿帮。

## 4. 技术要点

工程命题一句话：**难点不在实时性，而在结算的一致性、AI 的可读性与存档的健壮性**。以下与引擎无关，任何引擎都能落地。

**棋盘与范围计算**

- 棋盘是「格子数据结构加覆盖层」：通行性、进入消耗、地形加成、占据单位各一张表，层间分离，改一个机制不动其他层。
- 移动范围用带权寻路（Dijkstra 或 A*，代价取地形消耗），攻击范围等于移动范围合成武器射程，每回合缓存、行动后局部重算；单位阻挡与不可通行分开建模，对敌阻挡、对友可穿的规则统一写死。

**回合与结算管线**

- 回合管理器按阶段状态机实现：我方阶段、敌方阶段、事件与增援结算、胜负检查；顺序写进规格并保持稳定，顺序一变存档就对不上。
- 战斗预告与结算强制共用一条管线：同一组输入、同一条伤害公式、同一组随机调用顺序；两套代码是「预告不准」的唯一来源。
- 伤害公式做成加法链（攻击、防御、地形、克制、暴击各一段，全部进表、逐段可开关）；随机数走可复现的种子体系、判定顺序固定，是悔棋与「同存档同结果」调试的地基。

**AI**

- 战棋 AI 的主流解法是「枚举候选行动加评分」：对每个单位枚举移动点与目标，按伤害、威胁、目标权重打分取优；不追「像人」，追可读、可对抗、有性格。
- 行为要可解释，难度档先调行为再调参数：集火最脆的单位、优先占点、血线低就撤，玩家观察两三回合就能学会规则；低难度让 AI 少算一步、不追杀，高难度让它会算预告、会保关键单位，作弊只作最高档的诚实选项并明示。
- AI 是免费测试员：批量模拟同一张地图的多种阵容与难度，统计胜率与通关回合数，是关卡平衡的现实手段。

**存档、回放与工具链**

- 中断存档必须能在战斗中途保存完整状态（回合、单位坐标与血量、随机源进度、事件触发器可序列化，带版本号与迁移函数）；悔棋用快照栈或指令日志重放实现，原型期用快照。
- 地图编辑器与调试命令越早越好：编辑器至少支持改地形、放单位与增援、设胜负条件、一键试玩；调试命令覆盖跳关、加单位、改经验、控随机、强制触发。
- 战斗动画必须可跳过、可加速、可关闭；默认值要克制，一关打几十场战斗的节奏等不了长动画。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 系统原型 | 1 张白盒地图、4-6 个单位、2-3 个职业 | 单人 1-2 个月 | 移动、结算、AI 三件套跑通 |
| 小型完整作品 | 10-15 关、8-10 个职业、完整战斗系统 | 小团队 1-2 年 | 关卡与叙事是主成本 |
| 常见独立 SRPG | 20-30 关、职业树与转职、支援与剧情文本 | 小团队 2-4 年 | 文本与立绘随角色数翻倍 |

美术量级：每个可玩单位常见 1-2 张立绘（含表情差分）加战场形象；若做传统 2D 逐帧战斗动画，单角色几十到上百帧，十个角色就是沉重账单，替代路径是 3D 通用骨骼加武器挂点、或轻量位移加特效。地图按主题做 tileset，一块主题几十到几百块，先够白盒用再逐步替换；技能与状态图标按数量计价，每个都要有可读的小尺寸版本。

关卡量级与排期：白盒一两天、打磨三到五天，时间比通常 1:3 到 1:5；SRPG 关卡还要附加多轮通关测试（不同阵容与难度各跑一遍）与剧情演出排列。从零到「一关打十分钟不烦躁」通常 1-2 个月，到垂直切片（完整战斗系统加 3-5 关发行质量）通常 3-6 个月，之后按「关卡数与文本量相乘再加打磨系数」外推；范围失控的主要死因是角色与职业数量，每加一个角色都是立绘、动画、数值、文本、平衡五条账。

## 6. 第一个原型怎么起步

第一个原型只验证一件事：一张地图上的「移动、出手、结算」好不好玩。范围锁定：1 张 20x15 到 25x20 的白盒地图、4-6 名我方单位、2-3 个职业、敌方 6-8 个单位、一种主胜利条件（歼灭）加一个变体（防守回合）。不做剧情、不做存档、不做转职、不碰正式美术。

- **第 1-2 周：棋盘与结算。** 格子、寻路、移动范围显示；命中、伤害、反击、死亡与预告面板；目标：预告与结算完全一致。
- **第 3 周：回合与 AI。** 阵营回合状态机、评分式敌方 AI；目标：能打完一整关。
- **第 4-6 周：一张图调节奏。** 地形加成、增援、第二种胜利条件、悔棋或中断存档二选一；找 3-5 人测试并数数据。

起步参数（可直接抄来改）：

- 地图 20x15 到 25x20 方格；移动力 4-6 格；武器射程：近战 1 格、远程 2-3 格；基础命中 70%-90%。
- 伤害公式用「攻击减防御」起步，先不加乘数链；单位血量 20-40；一关 10-20 回合、15-30 分钟，双方单位 4-8 个；经验与成长先做两级，够验证即可。

成功标准（全部可观察）：

- 5 名测试者中至少 3 人没玩过同类型、无口头指导完成地图；每人「看不懂为什么打不中或为什么死」的时刻不超过 1 次。
- 测试者能说清上一个阵亡单位错在哪一手，且至少 2 人主动重开第二局、动机是「换个打法」而不是不服气；若过半答案指向运气，回去改概率或宽容度（§3.3、§3.5）。
- 你能在 5 分钟内改完一张地图的数值并热更验证；改不动，先把编辑器补上（§4）。

## 7. 常见坑

1. **预告与结算两套代码**：数字对不上，玩家按预告做的决策全部失去意义；预告、结算、AI 评分共用一条管线，是本类型第一条纪律。
2. **概率区间成为成败开关**：关键胜负手压在 60%-80% 的猜拳区，赢输都是运气；给必中手段或确定性设计兜底。
3. **永久死亡配超长关卡且无中断存档**：一次失误损失四十分钟，玩家学会的是恐惧不是战术；宽容度三件套至少给一件，中断存档与自动轮转是底线工程。
4. **AI 行为不可读**：突然全军压上或集体发呆，玩家无法建立预期；宁可笨得稳定，不要聪明得随机。
5. **职业只有一种最优解**：数值换皮、上位替代、废物职业三连；先给每个职业写一句「非它不可」，写不出的重做。
6. **数值碾压掩盖战术**：练级两级就能平推，关卡变成走流程；用经验衰减、等级压制或成长节奏守住「战术是主要变量」。
7. **只有歼灭胜利条件**：二十关全是清场，中后期疲惫来自重复而非难度；胜利与失败条件是便宜的关卡调味料。
8. **增援变成无预告背刺**：玩家没有应对窗口，只剩读档；增援要有触发线索与撤退或提速的选项。
9. **战斗动画不可跳过**：长动画默认开启、一关几十场战斗，直接劝退；动画可选、可加速、可关闭。
10. **系统未冻结就铺角色与职业**：立绘、动画、平衡全部可能返工；先把 6-8 个职业与一张地图打磨到好玩。
11. **测试只用开发者自己的阵容**：最优解会掩盖关卡的全部弱点；平衡验证必须换阵容、换难度、换人。

## 延伸阅读

- 《游戏设计手册》（⑨）§4：数值表方法论与平衡工作流，本文克制矩阵与概率设计的上位方法。
- 《关卡设计手册》（㉑）：地图度量、节奏与白盒流程，§3.4 的完整展开。
- 《技术实现手册》（⑩）：回合制架构、寻路与 AI 预算、存档工程，对应本文第 4 节。
- 《独立开发生存手册》（⑱）：范围控制与排期，第 5 节账本的扩展版。
- 《避坑大全》（⑥）：设计侧与工程侧高频坑位，与第 7 节互为补充。
- 练习一：给 6 个职业写一张克制矩阵与一句职责，删掉写不出「非它不可」的职业。
- 练习二：用同一张白盒地图做三种胜利条件（歼灭、防守、护送），记录测试者的最优解是否随之改变。
- 练习三：统计一场测试中的读档与悔棋次数、原因与时刻，把清单变成难度与容错校准的输入。

战棋的胜负不只在棋盘上：行动、概率与宽容度三样调清楚之前，职业、剧情与演出都是后面的账。
