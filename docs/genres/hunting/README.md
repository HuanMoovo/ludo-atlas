# Ludo Atlas · 类型手册 · 狩猎（Hunting）

> **类型手册 · 第四辑**。定位：把「追踪、蹲守、一击」的耐心循环做成第一乐趣的类型。玩家读痕迹、算风向、等时机，多数时间在潜伏，全部张力集中在扣扳机的一瞬；本页覆盖追踪系统、拟真与街机的分野、装备成长、生态与表达边界，以及内容量的现实核算。
> 配套：《游戏设计手册》（核心循环与数值）·《技术实现手册》（感知 AI 与数据表）·《案例研究集》（拆解与复盘方法）·《独立开发生存手册》（范围控制与内容量核算）。
> 本文不放外链；标杆只用大众熟知的作品；真实狩猎的法规与伦理问题只在 §3.4 一句话带过。

---

## 1. 定位与核心循环

一句话定位：狩猎是**把耐心做成弹药**的类型。追踪、潜伏、等待、瞄准，一发定音；慢是主体，快是高潮，全部设计都在管理「暴露」与「时机」，**耐心必须是回报的一部分，而不是惩罚**。

核心循环用动词环写：

`侦查与读图 → 循迹追踪 → 风向与声响判断 → 蹲守伏击 → 瞄准一击 → 回收与结算 → 成长与换目标`

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 射击游戏（FPS/TPS） | 射击游戏的对象是敌人，会反击、会死；狩猎的对象是生态里的动物，多数时间它不知道你在，威胁感来自「暴露」而非「交火」 |
| 动作狩猎（怪物猎人式） | 动作狩猎把动物写成招式对手与素材来源，本质是 Boss 战；本类型的动物是行为模型与生态，胜负发生在一击之前 |
| 生存建造 | 在那边狩猎只是采集手段（食物与皮料），只占宿主系统的一小块；本类型把它扩成全部内容 |
| 潜行 | 潜行里暴露触发惩罚（警报、战斗）；狩猎里暴露多数只是机会溜走，失败要便宜 |
| 猎杀对决式 PvPvE | 把猎物做成目标点、把人做成主要威胁；狩猎在这里退化为触发器，对决发生在玩家之间 |

一个自检问题：把猎物换成不会动、没有痕迹的靶子，游戏还成立吗？答案若为「成立」，你做的是靶场；狩猎的工作量不在枪上，在「动物是一门生态」上。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **潜伏的紧张**：风吹草动都可能是暴露；蹲下、绕行、停步，移动本身就是决策。
2. **追踪的推理**：把一串痕迹读成一张地图：几时经过、去了哪里、还有多远；推理被证实或落空，都是核心快感。
3. **一击的仪式**：屏息、瞄准、扣下扳机；一击定成败，而准备发生在几十秒之前。
4. **收藏的刻度**：角与皮毛、尺寸记录、图鉴与陈列室，把重复猎获变成长期目标。
5. **野地的安顿**：环境声、光影与天气是慢节奏的兑现，安静本身要值得享受。

反面感受（出现任意一条都是红灯）：走一小时没有目标；发现即开火；命中毫无反馈；稀有度只活在概率表里。

标杆作品（均大众熟知，建议亲手玩过再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 猎人：荒野的召唤（theHunter: Call of the Wild） | 现代拟真狩猎的基准：需要区域（饮水、觅食、休息）、踪迹与叫声、风向与蹲守节奏 |
| Way of the Hunter | 拟真上限的对照样本：弹道与命中回放、群体行为、奖杯生成与剧情包装 |
| 狩猎模拟 2（Hunting Simulator 2） | 简化与拟真的中间档：犬只辅助、任务驱动的结构 |
| 荒野大镖客：救赎 2（狩猎子系统） | 狩猎嵌入开放世界与生态：皮毛质量、市场价格与制作系统互喂 |
| 猎杀：对决（Hunt: Showdown） | 猎获做成目标、玩家互为威胁的 PvPvE 变体，边界见第 1 节 |
| 怪物猎人（Monster Hunter） | 动作向的分支：狩猎词汇的另一条演化路径，动物被写成招式 |
| 打鸭子（Duck Hunt） | 街机祖先：一枪一回合的最短循环，瞄准即全部内容 |

## 3. 设计要点

### 3.1 追踪：痕迹、声音、风向三套信息系统

追踪是这个类型的发动机，由三套互相叠加的「读」构成，三套都要能被玩家看见：

| 系统 | 信息单元 | 玩家在算什么 |
| --- | --- | --- |
| 痕迹 | 足迹、粪便、血迹、吃剩的食物、蹭过的树干 | 方向、新鲜度、物种、是否受伤 |
| 声音 | 脚步（按地面材质与移动方式分档）、叫声、环境噪声 | 我有多吵；附近有什么；下次用什么声音引诱 |
| 风向 | 全局风向量与局部扰动 | 我从哪个方向来；猎物的鼻子朝哪；该从哪边接近 |

执行要点：

- **痕迹要有新旧分档**：新鲜、一般、陈旧三档起步，外观与信息都要区分，新鲜度随时间衰减，下雨加速消失；血迹按命中部位分三到四档，同时承担命中反馈与追踪线索两个职责。
- **感知优先级固定且可学**：拟真向惯例是嗅觉最远、听觉居中、视觉最近，三个半径写进动物配置，而不是神秘公式；玩家绕上风、压低脚步、借助掩体，三件事分别对应三个半径。
- **蹲守伏击是追踪的下游**：需要区域（饮水点、觅食地）与隘口是天然伏击位，地图要留出「蹲在正确的位置等它来」的地形；玩家算的是它几点来、从哪来、我站在哪。
- **信息可视化一次到位**：风向用飘动的毛、草叶与 HUD 罗盘重复表达，感知反馈用动物行为（抬头、竖耳、盯向你）给玩家读数，没有可视化的系统等于没做（见 §4）；工具可以给（高亮最近痕迹、望远镜标记），直线指路不能给，「我自己读出来的」是追踪的全部乐趣。

### 3.2 拟真与街机的分野

分野先于元素：同样是猎鹿，两端的产品在会话长度、弹道复杂度与信息量上是两种东西。先选生态位，再谈机制。

| 维度 | 拟真向 | 街机向 |
| --- | --- | --- |
| 会话长度 | 一次完整猎获 10-40 分钟 | 一局 1-5 分钟 |
| 弹道 | 下坠、风偏、屏息与归零 | 准星即命中 |
| 追踪 | 痕迹与风向是必修课 | 目标高亮、听声辨位、指示器 |
| 失败 | 猎物溜走，空手而归（成本是时间） | 掉一条命或重开一局（成本是分数） |
| 动物演出 | 生态作息与群体行为 | 靶子式出场与程序化移动 |
| 代表 | 猎人：荒野的召唤、Way of the Hunter | 打鸭子、街机光枪狩猎一脉 |

中间档（狩猎模拟 2 一类）同时要拟真的外观与街机的节奏，不是不能做，是两头受众都要得罪一部分；小团队直接选一头。一个自检：你的玩家第一次开枪前，愿意等多少分钟？答案决定你站在哪边。

### 3.3 装备与技能成长

- **装备按「能不能打到」组织，不按数字大小**：枪械按口径与用途分档（小型、中型、大型猎物），弓箭单独一条线；瞄具、弹药、服装（伪装与气味）、犬只或辅助工具各占一条。
- **技能线服务信息与操作**：追踪（更远的痕迹可见）、屏息（更长的稳定窗口）、潜行（更低的移动噪声）、动物学（物种提示与习性标记）。
- **解锁口按两类验收**：每件新装备解开一类此前打不了的猎物或距离；每个新技能减少一类信息噪声。两条都做不到，就是纯数值，砍掉。
- **消耗品与成长节奏**：弹药、诱饵、除味剂负责日常开销与出门理由，收益按「一次猎获赚多少、一小时几次」先算再调；拟真向的成长是长曲线小刻度，口径、镜、弹、衣、犬每样只改一小段，别让任何一件装备改变一切。

### 3.4 生态表现与表达边界

- **生态是三张表**：物种表（群居或独行、昼行或夜行、警觉度）、作息表（觅食、饮水、休息的区域与时段）、分布表（地图 × 生境 × 时间段）。玩家研究的是作息，设计者写的是表。
- **表现尺度一次定死**：血迹、倒地处理、是否展示解剖与猎获处理，与目标受众和发行平台的规则一起决定；中途改尺度，美术与动画全部返工。
- **别把动物写成敌人**：动物没有仇恨，不该主动围猎玩家；攻击性物种的威胁也要符合习性。把动物写成怪物，类型就滑向动作狩猎，那是另一个品类。
- **一句话边界**：现实狩猎受各地法规与动物伦理约束，本页只讨论游戏设计，不构成任何现实狩猎指引。

### 3.5 内容矩阵：物种 × 地图 × 装备

- **内容量是乘法**：物种数 × 地图数 × 装备件数，再乘上每物种的文本、声音与行为成本；先按「周/物种」给团队测产能，再定首发范围（见 §5）。
- **物种差异要写在行为上**：独行、群居、夜行、警觉度、是否领域性；两个物种如果只差数值与贴图，合并成一个。
- **地图即玩法**：生境组合（森林、草原、湿地、山地）决定物种表与接近路线；一张好地图要让「绕上风接近」与「远距离蹲守」都有可行地形。

## 4. 技术要点

工程难点集中在三处：动物感知与行为、痕迹与声音的世界状态、调试可视化。以下与引擎无关。

**动物 AI 与感知**

- 感知三通道：视觉（视锥加距离）、听觉（声音事件传播半径）、嗅觉（沿风向量传播的感知区）；三个通道各自独立出参数，宁可粗糙可读，不要精细玄学。
- 警戒状态机：平静、警觉、警戒、逃跑等若干状态，迁移由感知强度与阈值驱动；逃跑要可预期（往哪逃、逃多远、会不会回头），玩家的追击决策全靠它。
- 群体行为按模板起步：群居草食、独行草食、掠食者、水禽四大类模板覆盖大多数需求；个体差异用参数，不写新代码。
- 性能分层：远处低频决策（每秒一两次）、中距离简化感知、近处全速；数量上限与生成区域随玩家位置动态管理。

**痕迹与声音的世界状态**

- 痕迹是一类世界对象（位置、类型、新鲜度、朝向），持续生成与衰减；渲染与查询分开（玩家工具查询「最近的痕迹」），空间分区防止全图遍历。
- 声音与风：声音分玩家事件（脚步、枪声）与环境音（风、雨、鸟），引诱叫声按「播放声音事件加概率响应」实现，响应参数按物种与距离配置；风是全局向量加局部扰动，影响气味传播与痕迹衰减，雨影响痕迹与声音传播，既是掩护也是痕迹的橡皮擦。

**调试与验证**

- 第一件工具是感知可视化：三个半径、当前状态机状态、风向量同屏显示；没有它，这个类型的行为调参无法进行。
- 仿真测试与命中判定：用脚本让 AI 猎人在不同风向下直线接近猎物，记录被发现距离的分布，这是「感知半径是否可读」的量化尺子；命中按区域碰撞（致命区、减速区、无效区），拟真向再加弹道下坠与风偏，简单抛体模型就够。

**存档与数据**

- 物种、装备、感知参数全部外置为数据表，图鉴与尺寸记录从同一张物种表派生；猎获记录、图鉴进度、陈列室是长期数据，从第一天带版本号，场上的痕迹不必逐一持久化，先定义「哪些要存、哪些重新生成」。

## 5. 内容量与工作量参考

成本近似乘法：`总内容量 ≈ 物种数 × 每物种资产 + 地图数 × 每地图资产 + 装备件数 × 配置`。

| 体量档 | 物种数 | 地图数 | 装备规模 | 定位 |
| --- | --- | --- | --- | --- |
| 原型 | 1-2 | 1 张小图 | 1 枪 1 弓 | 验证追踪到射击的闭环 |
| 小型完成品 | 6-10 | 1-2 | 10-20 件 | 单人或小组 6-12 个月 |
| 常见独立作品 | 12-25 | 3-5 | 30-60 件（含消耗品） | 需要内容管线与工具 |
| 拟真向商业作品 | 30-80 | 4-8（含追加内容） | 百余件，长线更新 | 按年计，系列化摊成本 |

单件成本（量级参考，用于估算范围，不构成承诺）：

| 内容单元 | 单位成本 | 备注 |
| --- | --- | --- |
| 一种动物（3D） | 1-3 周 | 模型、动作组（待机、行走、奔跑、进食、嗅探、受击、倒地）、行为参数、声音、痕迹与图鉴文本 |
| 一张地图 | 1-3 个月 | 地形、植被、生境与需要区域、物种分布与作息、地标与路线 |
| 一件装备 | 0.5-2 人日 | 数值配置、模型与音效、获取链路 |

- 物种是第一个撞墙的成本项：玩家一周能玩掉几张图，产能按「周/物种」算，先做乘除法再立项。
- 排期锚点：追踪与射击的原型 3-6 周（比普通射击原型慢，动物与痕迹是额外的基础设施）；垂直切片（一张图、3-5 个物种、完整成长）2-4 个月；之后按内容量外推。
- 砍范围的顺序：砍物种安全，砍追踪危险；砍地图数量安全，砍生态深度危险。

## 6. 第一个原型怎么起步

第一个原型只做一张小图、两个物种、一把枪，3-6 周完成，不碰装备树与多地图，美术全白盒。

1. **第 1 周：动物与感知。** 一只草食猎物加一只掠食者，三通道感知、警戒状态机、逃跑与回头；感知可视化从第一天就在。
2. **第 2 周：痕迹与追踪。** 足迹、粪便、血迹三件套，带新鲜度分档与衰减；一个望远镜或高亮工具。
3. **第 3 周：射击与结算。** 枪感、命中部位判定、一击与追击、回收与结算界面；瞄准的屏息加进来。
4. **第 4-5 周：风向与声音进循环。** 风向量、声音传播、蹲行的噪声分档；地图上加一条「绕上风接近」和一条「下风蹲守」的路线，验证地形读不读得懂。
5. **第 6 周：外部测试。** 找 5 个没玩过的人各玩 30 分钟，记录三件事：会不会主动蹲下来；追踪时会不会说出「它往那边去了」；打空后是继续追还是重开。

成功标准（全部可观察）：

- 单次完整猎获落在 5-20 分钟，测试者能说清「这枪为什么中、为什么让它跑了」。
- 测试者主动使用风向与声音信息，而不是把它当装饰；问「你怎么知道它在这边」，答案里有痕迹、风向或声音。
- 一击失败后的行为是继续追踪，而不是放弃或重开。
- 改一个感知参数（如嗅觉半径），能在 10 分钟内量化它对猎获成功率的影响。

测试不过关先别铺物种：循环是这个类型的地基，物种只是砖。

## 7. 常见坑

1. **只有射击，没有追踪**：把类型缩成狙击靶场，生态与痕迹的半数内容不存在，玩家玩两局就腻。
2. **感知系统不可读**：风向、声音、嗅觉都做了，玩家看不见也学不会，等于没做（§3.1、§4）。
3. **空手而归的惩罚过重**：追一小时一无所获且没有次优目标，耐心变成怒气；给「顺手能打的目标」与信息留存。
4. **一击没有代价**：没有弹道、没有屏息、没有失败的余韵，张力归零；拟真向的核心就是把「一发」做贵。
5. **物种同质化**：十种动物行为只差数值，内容量堆叠不产生体验差异（§3.5）。
6. **地图是空的美景**：没有需要区域、没有接近路线、没有地标，追踪退化成碰运气。
7. **弹道拟真上头**：完整空气动力学与呼吸心跳模拟只会劝退多数玩家，抛体模型加风偏足够（§4）。
8. **表达尺度反复**：血腥与猎获处理的尺度边做边改，美术与动画返工；分级与平台规则要一次定死（§3.4）。
9. **内容账没算**：玩家一周玩掉几周的产出，更新节奏崩掉；按「周/物种」再乘地图与装备做乘法（§5）。
10. **教学缺位**：新手第一小时打不到东西又说不出原因；把「读懂三通道」做成分段教学与可查提示。
