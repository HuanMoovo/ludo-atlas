# Ludo Atlas · 类型手册 · 极限运动（Extreme Sports）

> **类型手册 · 第四辑**。定位：把「在立体场地里做动作」做成第一乐趣的类型。玩家的核心动词是助跑、腾空、做招、落地；得分由一套可背、可精进的评分系统裁定，场地由坡道、栏杆、雪包与崖壁写成分数表。本页覆盖运动手感与特技评分、场地结构（手工场地与程序生成雪山的取舍）、失败宽容与重试节奏、文化包装，以及小团队的量级核算。
> 配套：《游戏设计手册》（手感与数值表）·《关卡设计手册》（场地与线路结构）·《技术实现手册》（状态机、地形碰撞与回放）·《美术与音频手册》（音乐、镜头与文化包装）。
> 本文不放外链；标杆只用大众熟知的作品，数字均为常见量级，按自己项目的实测校准。

---

## 1. 定位与核心循环

一句话定位：极限运动是**把「做动作」本身做成第一乐趣**的类型。玩家在滑板、滑雪、小轮车、攀岩这些载体上，把速度与地形兑换成一串可评分的特技；招式不是赶路的副产品，招式就是内容，分数就是终点。

核心循环用动词环写：

`助跑蓄力 → 起跳 → 空中选招与修正 → 落地判定 → 连段确认或清零 → 冲更高分再跑一遍`

这个环以「一条线」「一轮」计量，一轮通常一到三分钟。它成立的前提只有两条：动作要可控（§3.1），摔倒要便宜（§3.4）。两条主干：公园式刷分（单个场地反复刷分，回合制计时）与线路式跑分（从起点到终点的一次性跑法，含检查点与主题线路）；骨架同源，本页覆盖两者共用的主干。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 竞速 | 竞速比谁先到线，胜负写在线速与名次里；极限运动比谁在这条线上得分更高、更险、更漂亮，评分系统才是主干 |
| 平台跳跃 | 跳跃是过关的手段；这里的腾空是内容本身，有独立的招式表与计分 |
| 体育游戏（球类） | 球类由赛制与对手裁定胜负；极限运动多是个人表演，裁判就是计分器与社群 |

一个自检问题：把分数系统拿掉，只留「到达终点」，游戏还成立吗？答案若为「不成立」，你做的就是极限运动。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **驭空感**：起跳、滞空、落地由同一套身体系统支撑；滞空里玩家有阅读、选择与修正的时间，落地瞬间能解释成败。
2. **风格表达**：同一地形容得下不同的招式与路线，评分奖励多样与险度；玩家愿意为「滑得漂亮」重跑一遍，而不是只认「刷得最多」。
3. **自我叫价的风险**：加难动作、贴着栏杆、贴着崖壁由玩家自选，越险分越高，摔的代价自己签；系统给风险定价，不给玩家下命令。
4. **低压重试**：摔倒是常态节拍，从摔到重来以秒计；摔倒后玩家想的是「这次要做完整」，而不是关机。
5. **文化归属**：音乐、服装、涂鸦与镜头语言让人相信这就是那块板、那座山、那群人；文化包装是这个类型的一半内容（§3.5）。

标杆作品（建议亲手玩过再拆，只看视频学不到滞空里的手感）：

| 作品 | 可学的点 |
| --- | --- |
| 托尼霍克职业滑板系列 | 特技评分系统（基础分、连段乘数、多样性）、时限回合结构与场地密度 |
| 极限国度 | 多运动共享一张地图、线路型内容的组织与大众化派对包装 |
| 极限巅峰 | 山体尺度的线路设计、探索感与回放挑战 |
| 特技摩托系列 | 物理驱动的平衡与翻车反馈、瞬时重试的关卡节奏 |

## 3. 设计要点

### 3.1 运动手感：把滑行、腾空与落地做成四段控制器

本类型的「角色」是人和载具的组合：板面、雪板、车轮或攀岩的身体。手感不是一个跳跃参数包，而是四段式；滞空时间是本类型的货币，起跳速度、坡面角度与重力共同决定它，场地尺度要从「一次最大腾空」反推（§3.3）；四段的旋钮全部进数值表、支持热改。

| 段落 | 核心旋钮 | 常见做法 | 调坏的后果 |
| --- | --- | --- | --- |
| 滑行 | 前进阻力、转向响应、压刃或压板的角度收益 | 速度按坡度与摩擦自然衰减；转向前段给精确微调，后段给大角度 | 滑行发飘或发死，玩家连直线都不信 |
| 起跳 | 蓄力窗、起跳输入缓冲、起跳面判定 | 缓冲 100-200ms 与平台跳跃同款；离开起跳面后仍保留一小段窗口 | 归零则十次起跳废三次；过大则有空中作弊感 |
| 滞空 | 旋转速度、姿态微调、抓板保持 | 旋转速度可调（点按慢转、长按快转）；给一个「展平身位」的修正键 | 滞空里无事可做，玩家从玩家变成观众 |
| 落地 | 落地判定角、平衡槽、挽救窗口 | 姿态角误差在宽容阈值内算稳落；失衡先给预警与一次挽救 | 判定与视觉不符，玩家把账记到游戏头上 |

验收标准：找 5 个人各做 20 次同一招，记录「明明按对却摔」的次数，每人 0 到 1 次为合格；摔倒之后，测试者能说出自己是姿态、时机还是路线选错。

### 3.2 特技系统：招式表、连段与评分

特技不是动画播片，是一张可查的招式表加一台可解释的计分器。招式表先立骨架：每个招式是一行数据，字段含输入序列、难度分、可衔接段与动画；招式量先求表达（同一翻体换抓板、换脚、换方向都是新行），后求数量。结算结构二选一：**连段结算制**（连段中断才清零，攀分上限高、观赏性好）或**分段确认制**（每落地一次即结算入账，更宽容，适合休闲路线）；选定一种为主，不为两种各维护一套平衡。

评分系统的最小结构是三件套：

| 组件 | 作用 | 常见做法 | 调坏后果 |
| --- | --- | --- | --- |
| 基础分 | 给每个招式定价 | 按旋转周数、翻体数、抓板难度分档 | 定价混乱，玩家不知道练什么 |
| 连段乘数 | 奖励「不停下来」 | 每接一招乘数递增；落地确认后结算，摔倒清零 | 乘数爆炸或频繁清零，都让中段失去选择 |
| 风格系数 | 奖励多样与危险 | 重复招式递减、贴近障碍与高度加成 | 单一套路打遍全场，表达空间消失 |

计分的三条口径：得分要能被玩家预算，上手十小时内玩家要能预判「这一跳大概值多少」；封顶与通胀控制做在前面，防「一招鲜刷到榜首」，刷分流水线和风格自由只能保一个大方向；大招槽的积攒与倍率单独入表，不要和连段乘数混在一条公式里调。

### 3.3 场地与关卡：手工场地是主内容，程序生成的雪山是补充

场地是本类型的「关卡」，写作单位是线路：一条主滑线穿过若干可玩物件（坡道、弧面、栏杆、台阶、雪包、树林、崖壁）。流程与竞速赛道同源：先有载体度量表（起跳速度、最大腾空、滞空时间、转弯半径），所有间距与高度从数字推导，再从白盒走到美术。

场地写作的三条纪律：

- 一条主滑线加等价支线：主线可读、可重复刷；支线藏在贴近处，给熟练玩家做表达；不许把唯一正确路线写死。
- 场地要会自己说话：可玩面用颜色、光照、涂鸦与磨损标记引导；入口在哪、往哪起跳、落点在哪，全部用视觉语言写。
- 教学、考试、变奏：新物件第一次在安全位置出现，第二次低压使用，第三次与旧物件组合（三段式细节见《关卡设计手册》）。

程序生成只在一种场景成立：长线路的角色，比如一条从山顶滑到山脚的雪道。它的纪律与无尽跑酷的片段拼接同源：手工设计片段（可玩编组）、规则拼接、难度预算、种子可复现，验收线是不可解性与不可读性。生成雪山的用途是每日挑战、长线流程与量级补充，不是主内容；玩家愿意反复刷的，仍然是手工场地。

| 维度 | 手工场地 | 程序生成雪山 |
| --- | --- | --- |
| 定位 | 主内容，反复刷分 | 长途线路与活动补充 |
| 成本 | 单点投入高，可精雕 | 生成器一次性投入 |
| 风险 | 场地不够多 | 重复、不可读、不可解 |
| 适合 | 公园、街区、室内场 | 滑降线路、每日挑战 |

### 3.4 失败宽容与重试节奏

在极限运动里，摔倒不是失败判定，是节拍本身：摔、起来、再来一次。这个循环拖长，爽感就开始漏水，宽容度设计就是回答一个问题：摔一次，玩家损失多少秒、多少分、多少进度。

| 损失项 | 需要控制的数值 | 常见做法 |
| --- | --- | --- |
| 时间 | 从摔到再滑起来 | 复位点放在摔倒处附近，公园式配一键重开本段 |
| 分数 | 连段是否清零 | 花式刷分断连清零；长途线路按段结算，或保留段内部分分 |
| 进度 | 长线路的检查点密度 | 检查点间距按「几十秒一段」布置，重走代价可控 |
| 情绪 | 归因是否清楚 | 摔倒给慢放或回放定格：压刃角度、起跳时机还是落点 |

三条通用做法：给「差一点」留救回窗口，落地失衡时先给可见的摇晃预警，再给一次挽救输入（扶正、压重心之类），救不回来才摔；重启按钮永远比退出按钮好找，一键重开本轮或本段放在固定按键上，结算页优先展示重试；宽容度分层，硬核档（严判定、无挽救、摔即重开）单独做成可选项，两拨玩家共用一套内容。

验收标准：观察测试者摔倒后的第一反应是按键还是叹气；连摔三次之后还愿不愿意再滑一次。愿意，宽容度就是够的。

### 3.5 文化包装：音乐、服装与镜头语言

极限运动卖的不只是玩法，是一整种生活方式：音乐、服装、涂鸦、赛事、镜头语言与社群语汇，缺一块就会露出「剧组没去过现场」的破绽。文化包装不是皮肤贴纸，是行为与语汇的一致性；音乐与镜头要当作玩法的一部分来排期，踩在节拍上的剪辑与慢放本身就是观赏性的一半。

| 载体 | 做法 | 纪律 |
| --- | --- | --- |
| 音乐 | 选曲或原创都要贴合运动气质；登场、剪辑节拍与慢放片段同步 | 真实乐队授权费用与周期早算；先用授权安全的素材跑流程 |
| 服装与皮肤 | 同骨架换件的复用管线；角色常驻屏幕，皮肤是最高价值展示位 | 辨识度优先，远景与暗光下也要认得出谁是谁 |
| 场景与镜头 | 涂鸦、海报、观众、赛事旗帜；广角跟拍、低机位、关键招式慢放 | 不堆符号；先定社群视角（谁的比赛、谁在看、镜头在哪） |
| 语汇与反馈 | 招式名、呼喊、庆祝与摔倒反应符合圈内习惯 | 不确定的语汇先考据再写进游戏，生造出来一眼假 |

## 4. 技术要点

工程难点集中在四处：载体控制、特技与评分的数据化、地形交互、回放与可复现性；以下与引擎无关，方法细节见《技术实现手册》。

**载体控制**

- 运动学方案是默认起点：自己算速度、沿地形法线滑行、坡度加速与摩擦减速，不要把人和板交给完整刚体物理；滑行、滞空、落地三段的姿态状态共用一份，切换条件写清楚。
- 落地判定比视觉更宽容：法线夹角、速度阈值、平衡槽三层组合，判定从宽，误差方向统一偏袒玩家。

**特技与评分的数据化**

- 招式表数据驱动：输入序列、难度分、前置条件、动画与音效字段化；评分引擎写成纯函数（状态序列进、分数出），连段乘数与风格系数分表管理、支持热改，切分与调平衡都不动代码，把「这一招值多少分」的调参效率排在动画精度前面。

**地形交互**

- 地形用高度图或样条加块面判定，可玩物件建一套统一的摩擦与反弹参数表；高速下滑做子步进或连续检测，栏杆与边缘逐段测，不许粘、不许弹飞、不许穿。

**回放、成绩与性能**

- 若做排行榜，物理与评分都要可复现：固定步长、可复现随机数、帧率无关；采样回放先落地、输入重放作为进阶，改手感就要重新评估既有成绩的可比性。
- 性能预算按最长线路与最大场面规划：流式加载、植被密度分级、雪花与速度线分级；生成器要配单步可视化，把拼接结果画在屏幕上。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 手感原型 | 1 个灰盒场地、10 个招式 | 2-4 周 | 只验证操作、滞空与落地 |
| 小型作品 | 2-4 个场地、一套评分系统 | 3-9 个月 | 场地与手感打磨占大头 |
| 常见独立作品 | 6-10 个场地、招式表与线路模式 | 1-2 年 | 音乐与场地迭代是持续成本 |
| 开放世界多运动 | 一张共享地图、多运动切换 | 3 年以上 | 队伍与预算量级显著不同 |

- 场地是最贵的内容单位：一个公园等于模块件、道具、照明、可玩线路与逐条试玩；场地规模参考载体度量表，不做「比真实场地大」这类没有验收标准的对比。
- 招式表是第二成本项：每个招式等于动画、输入、评分与音效；30 个手工招式不如 12 个招式加丰富的表达空间（换抓板、换方向、换衔接本就可复用）。动画骨架与半透明预览是省钱的关键。
- 排期锚点：从零做出「一个场地加一套评分系统」的垂直切片通常 2-4 个月；音乐、皮肤与活动按复用与授权两笔账估（皮肤走同骨架换件管线，一支曲子等于授权费、剪辑与适配三笔账，活动主题提前一个大版本锁定）；范围失控的典型死法是把开放世界、多运动、线上排行榜一起上。

## 6. 第一个原型怎么起步

第一个原型只做一块平地、一条坡道、一个弧面加一个箱体，2-4 周完成，不碰美术、音乐、生涯与在线。

**第 1 周：滑行与腾空。** 一个可滑行的角色，坡面加速、起跳、空中转一圈、落地判定接通；镜头跟随先做成可用水平，不追求风格。

**第 2 周：招式与评分。** 3 到 5 个招式进招式表，连段乘数与落地清零接通；所有手感与计分参数进数值表、支持热改。

**第 3 到 4 周：微型场地与内部测试。** 把一片小场地做出三条可玩线（一条主、两条支），计时回合、得分结算与一键重开闭环接通；找 3-5 个没玩过的人各玩 15 分钟，记录摔倒原因、抱怨点与「想再试」的瞬间，不提示、不解释，只观察。

成功标准（全部可观察）：

- 拿掉全部美术与音效，测试者仍愿意刷分，单次通常 10 分钟以上，且有人主动要求再滑一遍。
- 5 名测试者中至少 4 人无口头指导完成一次起跳、做招与落地；「明明按对却摔」类抱怨每人不超过 1 次。
- 任意改一个参数（滞空、落地宽容或某一招的基础分），你能在 5 分钟内量化它的影响；测试者的摔倒能自己解释成时机、姿态或路线。

手感与评分不通过，就不要开始铺场地；地基上的返工是这个类型最贵的一笔账。

## 7. 常见坑

1. **手感未冻结先铺场地**：场地按错误的起跳速度与滞空距离搭好，参数一动全部返工；先冻结操作，再量产场地。
2. **滞空里没有决策**：起跳后动作自动播完，玩家成了观众；旋转速度、姿态修正与提前落地要留下操作空间（§3.1）。
3. **评分不可解释、套路通吃**：分数结构和玩家理解不一致，玩半天说不清分从哪来；重复递减与难度定价要一起上，防「一招鲜刷到榜首」（§3.2）。
4. **落地判定与视觉不符**：看着落稳却摔了，看着要摔却救回来；判定向玩家方向统一倾斜，并给挽救窗口（§3.1、§3.4）。
5. **摔倒惩罚过重**：长线路没有检查点，一次失误几十秒重来；摔的成本超过十秒，爽感就开始漏水（§3.4）。
6. **程序生成雪山当主内容**：生成的路线不可读、不可解、重复三连；生成只适合长线路补充与活动（§3.3）。
7. **文化包装是贴纸不是生活方式**：音乐、服装、语汇各说各话，一眼假；先定社群视角再写符号，音乐权益与替换流程排进里程碑（§3.5）。
8. **回放与社群工具缺席**：极限运动的一半动力是「给别人看」；回放、幽灵与剪辑是留存的发动机，不是锦上添花。

极限运动看起来在卖分数，实际卖的是「刚才那一下差一点就成了」：动作可控、摔倒便宜、分数诚实，再来一次就永远值得。
