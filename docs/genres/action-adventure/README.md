# Ludo Atlas · 类型手册 · 动作冒险（Action-Adventure）

> **类型手册 P3 批次**（第 ㊴ 轮扩展）。定位：把「探索、战斗、解谜」三支柱编织成一段节奏可控的旅程，用手工空间与适度的电影化演出持续供给「发现」与「征服」。本页覆盖三支柱比例、箱庭结构、道具复用、演出成本与范围核算。
> 配套：《游戏设计手册》（⑨，核心循环与体验支柱）·《关卡设计手册》（㉑，箱庭、引导与节奏）·《技术实现手册》（⑩，相机与演出系统）·《案例研究集》（⑳，标杆拆解方法）。
> 本文不放外链；标杆只用大众熟知的作品，文中数字为常见量级，按自己项目的实测校准。

## 1. 定位与核心循环

一句话定位：动作冒险是**以探索为骨架、战斗与解谜为血肉**的类型。玩家在一个个手工分区的小世界里推进，发现新区域、闯过障碍、打穿战斗，最终抵达一场值得的决战。三个支柱缺一不可：只剩探索是步行模拟，只剩战斗是清版动作，只剩解谜是密室逃脱。

核心循环用动词环写：

`收到目标或好奇 → 进入新分区 → 解谜开路 → 战斗清场 → 获得新道具 → 回头解开旧障碍 / 打开新路 → 推进`

这个环以分钟计，一次「探索、解谜、战斗、收获」的往返通常 10-20 分钟。它成立的前提有两条：三个支柱轮换出现、互不拖累（§3.1）；新道具在十分钟内兑现用途（§3.3）。拉远到小时级，循环是「逐区推进 → 工具集扩张 → 世界重读」。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 开放世界（结构标签） | 动作冒险用分区箱庭控制节奏与成本，卖的是一段编好的旅程；开放世界卖自由漫游与大地图尺度，把箱庭简单放大不会变成开放世界，只会变成又大又空的箱庭 |
| 银河城 | 银河城把能力门锁铺满一张连续地图，回访与重读地图就是核心乐趣；动作冒险的区域相对独立、以线性推进为主，道具可以开门，但回头路不是主要玩法 |
| 动作 RPG | 动作 RPG 的成长写在装备与数值里，刷取与构筑撑起长期循环；动作冒险的成长写在新工具与新玩法里，数值克制，胜负更多交给理解与时机 |

一个自检问题：让测试者复述「去过哪、拿到了什么、用它做了什么」。说得出来，三支柱在协同；说不出来，探索段多半只是赶路。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **发现感**：每翻过一道山脊、转过一个弯，都有值得一看的东西；地图是内容，不是布景。
2. **掌控感**：战斗能读招、能反击，机关能看懂、能推理；成败归因到自己。
3. **节奏起伏**：战斗、解谜、演出、探索交替出现，紧张与松弛轮换，不让任何一段超时。
4. **成长兑现**：新道具同时改写解谜、战斗与路线，到手十分钟内就能用上。
5. **旅程记忆**：玩家最终记住的是一段旅程；地标、音乐与演出都在替旅程记账。

标杆作品（均为大众熟知的作品，建议亲手玩过再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 塞尔达传说：时之笛 | 三支柱的原始范本：以道具为中心的谜题语言、锁定式战斗与 3D 镜头基准、箱庭分区 |
| 塞尔达传说：旷野之息 | 探索自由与系统交互的上限：道具与环境规则的复用、好奇心驱动的地图 |
| 战神 | 演出与操作的无缝衔接、战斗手感与叙事并重、途中对话承担大量叙事 |
| 神秘海域系列 | 演出驱动的段落节奏：攀爬、解谜、枪战与过场轮换出现，追逐战当演出来做 |
| 古墓丽影（重启三部曲） | 环境解谜的视听引导、场景机关的层次、探索密度的控制 |
| 蝙蝠侠：阿卡姆疯人院 | 三支柱在一个箱庭里的编排：潜行、群战、谜题与信息反馈 |

## 3. 设计要点

### 3.1 三支柱与比例权衡

三支柱不是三份内容平均分，而是互相调节的三个声部：探索决定玩家去哪，战斗与解谜决定玩家在那儿做什么，轮换出现才形成节奏。常见配比（按体验时长的大致占比，量级参考）：

| 取向 | 探索 : 战斗 : 解谜 | 核心逻辑 | 主要风险 |
| --- | --- | --- | --- |
| 塞尔达式 | 4 : 3 : 3 | 解谜是探索的延伸，战斗是节拍器 | 解谜段拖慢战斗型玩家 |
| 战神式 | 3 : 5 : 2 | 战斗是主轴，解谜与攀爬做节奏缓冲 | 解谜沦为跑腿，玩家只想快进 |
| 神秘海域式 | 5 : 3 : 2 | 演出与攀爬驱动推进，战斗是段落高潮 | 玩法深度不足，靠演出撑场 |

比例是结果，不是目标——先写一节 30 分钟体验的分工表（玩家按什么顺序做什么），再回头统计占比。三条纪律：

- 一段场景一个主导支柱：解谜段不刷小怪，战斗段不塞机关题，混合只放在设计好的合成段。
- 单段时长设上限：解谜段 2-10 分钟、战斗遭遇 1-5 分钟、单段演出 30-90 秒（常见量级），超时就拆。
- 支柱互相借用：把敌人打进机关、用机关破敌人的霸体；解谜与战斗共用同一套道具语言，避免两张皮（§3.3）。

### 3.2 箱庭结构：分区的小世界与节奏

动作冒险的空间单位是**箱庭**：一个有边界、有主题、从入口到出口约 30-50 分钟的分区。整个世界由若干箱庭加一个枢纽拼接而成，而不是一整片连续大地图。分区带来三个好处：节奏可控、成本可控、每个区能讲一个完整的段落。结构词汇先定下来：

| 结构 | 定义 | 设计准则 |
| --- | --- | --- |
| 枢纽 | 连接各分区的中转空间（村子、营地、传送点） | 承担商店、存档与剧情推进，也是「回家」的情绪锚点 |
| 野区 | 探索与遭遇为主的开放段落 | 地标先行：每个野区 1-2 个远景地标，回答「我在哪」 |
| 迷宫区 | 解谜密度最高、结构最封闭的分区 | 一个区只教一个新机制，出口用该机制考察 |
| 门锁 | 道具或剧情造成的通过限制 | 可见、可记忆；同一种锁全图一个视觉语言，别在玩家没见过时锁死 |

单区节奏样板（一段约 45 分钟，超了就把区拆开；区与区之间留走廊、升降梯、观景点做呼吸段与加载掩护，相邻两区按谜题、战斗、演出轮换制造节奏差）：

| 阶段 | 内容 | 时长参考 |
| --- | --- | --- |
| 进入与观察 | 远景地标、区内目标可见、少量遭遇 | 3-5 分钟 |
| 教学 | 低压场景里教会本区的新工具或新敌人 | 5-10 分钟 |
| 发展 | 解谜与战斗交替升级，结合旧机制 | 15-20 分钟 |
| 高潮 | 结构最复杂的机关或 Boss 战 | 5-10 分钟 |
| 奖赏与出口 | 新道具、新捷径、下一区的预告 | 3-5 分钟 |

### 3.3 道具复用：一物三用

动作冒险的道具不能只当钥匙。设计规则：**每件道具在解谜、战斗、探索三类场景里各有至少两处应用**，玩家拿到后的十分钟内至少能用上一处。

| 道具 | 解谜用途 | 战斗用途 | 探索用途 |
| --- | --- | --- | --- |
| 炸弹类 | 炸开脆墙与裂缝 | 范围伤害、打断吟唱 | 炸出隐藏通道与收集品 |
| 钩索类 | 拉下远处机关、摆荡过沟 | 把敌人拉近或缴械 | 到达高台、跨过断崖 |
| 时停类 | 冻结机关的节奏 | 拖慢敌人、创造输出窗口 | 通过高速移动的平台 |
| 远程类（弓、枪） | 射中视线内的机关 | 点名脆皮与引怪 | 打下悬挂物、拉出绳路 |

名目可以自拟，检查标准是每一行三个用途格都填得出来。配套规则：

- 获得道具的四拍：展示（安全环境试一次）→ 使用（当场过一关）→ 回响（旧场景里至少两处因它解锁）→ 变奏（与旧道具组合出新花样）。缺了「回响」，道具就只是新规则。
- 每个道具维护一张用途清单（场景 × 用途 × 可达阶段），条目少于 3 的不立项；只开一扇门的道具降级为机关的一部分，不占道具栏。
- 组合检查：任意两件中后期道具，至少能合成一个新谜题或一套新打法；道具集越到后期越要有化学反应。

### 3.4 演出与镜头：电影化的成本

镜头分三套，职责分离：

| 相机模式 | 职责 | 要点 |
| --- | --- | --- |
| 探索相机 | 看路、看风景 | 跟随加前瞻、地形避障，让地标进画 |
| 战斗相机 | 看清敌我、控制空间 | 锁定、拉远、可控的顿帧；不遮操作信号 |
| 演出相机 | 讲故事、给情绪 | 独立轨道动画；可跳过、可回看 |

电影化叙事的成本要按分钟算（常见量级，不含配音与动捕）：一段 30-60 秒的引擎内脚本演出，从设计、动画、相机到音频与集成，约 5-15 人天；带面部表情与口型的上浮；精细动捕或预渲染的单秒成本还要再上一个量级。商业动作冒险里「少而精」是常态：关键节点用全演出，途中靠环境叙事与对白垫片过渡；单段过场控制在 1 分钟上下，连续多段之间留可玩段，可跳过是标配。降本清单：

- 把演出做成操作：镜头调度藏进可玩段（一镜到底的做法），避免反复切镜；代价是关卡与工具链要为镜头服务。
- 对白行进与环境叙事：对话放进走路、乘梯与划船的段落；前情用场景本身交代，动画成本为零（做法见《关卡设计手册》（㉑））。
- 演出预算表：每段必做演出标清时长、用途与能否跳过；不与玩法或情绪挂钩的过场直接砍。

### 3.5 引导与可读性

动作冒险常以「几乎没有任务标记」为卖点，但那是设计出来的：引导先做进空间（统一互动物记号、地标进画、光柱与色彩牵引视线、难度分层只考刚教过的东西），UI 标记只做兜底；每个谜题配两级提示（同伴低语、目标物发光），触发条件写进设计表。

检查表：找 5 个测试者，记录第一个迷路点、第一次卡关时长、主动重走的次数；卡关超过 10 分钟的点，逐个补引导。

## 4. 技术要点

技术难点集中在四处：相机、交互系统、演出管线与世界状态一致性。以下与引擎无关；这些系统用引擎现成模块拼装就能到及格线，真正要自研的是它们之间的状态管理层。

| 系统 | 关键点 | 常用做法 |
| --- | --- | --- |
| 相机 | 三套模式切换不穿帮 | 统一管理层：模式、优先级、过渡曲线；避障射线；演出相机独立轨道 |
| 交互系统 | 一件道具多种互动物 | 统一「互动物注册表」：类型、需要的道具、反馈；提示 UI 从注册表渲染，同屏提示以三处为上限 |
| 解谜对象 | 机关是状态机 | 触发器加状态位，可重置、可强制完成；每个机关有调试面板 |
| 演出管线 | 相机、动画、对白、音频同步 | 引擎的时间轴工具；整段可跳转、可跳过；演出状态与游戏状态解耦 |
| 存档 | 世界状态与角色状态分离 | 门、机关、收集品用 flags；检查点自动保存，回滚不撤销已解开的世界，版本升级不杀档 |
| 调试工具 | 传送、穿墙、无敌、全道具 | 第一天就做；没有它，全箱庭测一轮要花一天 |

关键细节：

- 相机是第一技术债：三套相机必须有统一管理层，否则「战斗中触发演出」「演出结束回到战斗」这类切换场景全是 bug。
- 演出与可玩段的衔接留缓冲：接管与交还操作的前后各留过渡，防止吞输入；演出中的输入策略要明确（多数做法：只允许跳过）。
- 解谜状态机必须可重置：玩家离开、卡死或顺序颠倒时能一键恢复，防止软锁；测试期用调试工具扫全图。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算与砍需求，不构成承诺。

| 档位 | 规模 | 周期参考 | 说明 |
| --- | --- | --- | --- |
| 原型 | 1 个箱庭、2 件道具、1 场 Boss | 2-4 周（单人） | 全灰盒，验证三支柱循环 |
| 小型作品 | 4-6 个分区、6-10 小时流程 | 6-12 个月（小团队） | 单工具集、低演出含量 |
| 常见商业体量 | 8-12 个分区、15-25 小时流程 | 2-4 年（数十人规模） | 电影化演出、外包与配音管线 |
| 大型商业体量 | 12+ 分区、25 小时以上流程 | 4-6 年（百人级） | 演出、动捕、配音全线拉满 |

单区拆分参考：一个 45 分钟的箱庭区，布局与通路 3-7 人天、解谜设计 5-10 人天、战斗遭遇 3-7 人天、美术与环境叙事 10-20 人天、测试打磨 5-10 人天，合计数十人天量级；演出单独建预算，把全流程演出分钟数乘 §3.4 的人天单价单列一块，20 小时流程配 60-90 分钟全演出已是常见商业体量。

砍内容顺序（进度落后时）：先砍收集品与可选谜题，再合并小分区（拆门锁、改线性段），再降级演出（全演出改对白行进），Boss 与主线结构是底线。外推的主锚点是「分区数 × 单区成本」，别用总时长倒推。

里程碑建议：三支柱原型（一个箱庭玩通，三支柱各有代表段落）→ 垂直切片（一个区到最终质量，含一段演出与一场 Boss 战）→ 主线全通（灰盒全连通、无软锁）→ 内容填充（美术、演出、配音、收集品就位）→ 打磨与送审。每步的通过标准都是可玩产物，不是完成百分比。

## 6. 第一个原型怎么起步

目标：验证「探索 → 解谜 → 战斗 → 拿道具 → 用道具」的最小三支柱循环。用一个箱庭区完成，全体占位美术，不碰剧情与菜单。

迷你规格（照抄即可）：1 个枢纽、1 个野区（约 10 分钟）、1 个迷宫区（3-5 个房间）、2 件道具（建议炸弹加钩索）、3 场标准战斗、1 场 Boss、1 段 15-30 秒的演出。

```text
[枢纽] → [野区：探索 + 战斗] → [迷宫：解谜] → [道具 2] → [Boss] → [演出收尾]
道具 1（炸弹）：野区拿到，炸开迷宫入口
道具 2（钩索）：迷宫中段拿到，Boss 战里直接可用
```

步骤（按序执行，每步都有可玩产物）：

1. 先做移动与相机：跑、跳、攀爬的最小集，探索相机跟手；灰盒一个野区，确认「光走路也愿意走」。
2. 加战斗：一种近战、一到两种敌人；锁定与非锁定两种相机策略都试，先冻结战斗相机。
3. 加解谜：从道具反向设计机关，先做炸弹的两处应用，一处显眼、一处隐蔽。
4. 串成一个区：按「进入、教学、发展、高潮、奖赏」把区串通，写死检查点与自动存档；顺手加一段演出，验证工具链与「可跳过」流程。
5. 找人测：3 个没玩过的人，不给提示，记录第一个卡点、第一次迷路、对道具「还想再用用」的时刻。

四周节奏参考：

| 周次 | 产出 | 验证 |
| --- | --- | --- |
| 第 1 周 | 移动与相机、灰盒野区 | 走路与镜头不别扭 |
| 第 2 周 | 战斗遭遇与一只小 Boss | 战斗愿意重打 |
| 第 3 周 | 两件道具与对应机关 | 道具到手十分钟内有用处 |
| 第 4 周 | 全区串通、一段演出、3 人试玩 | 三支柱循环成立，决定扩或砍 |

验收标准（全部可观察）：测试者能按「去过哪、拿到了什么、用它做了什么」复述流程；至少一人主动回头去找漏掉的机关用途；战斗与解谜的每次切换，空白等待不超过 5 秒；拿掉美术与音效，流程仍能玩通且有人愿意再走一遍。

三支柱有任意一根立不住（比如测试者跳着过解谜、或不想打第二场战斗），先修支柱，再铺内容。

## 7. 常见坑

1. **三支柱比例失衡**：解谜占掉大半时长，战斗型玩家中途弃坑。先用一节 30 分钟体验的分配表定比例，再铺内容。
2. **道具是一次性钥匙**：到手只开过一扇门，之后再没用过。立项标准：三类用途各两处，战斗里也找得到位置。
3. **箱庭之间没有节奏差**：连着三个区都是「打怪、开门、打怪」。分区要有主题差（谜题区、战斗区、演出区轮换），过渡段给呼吸。
4. **演出过量且不可跳过**：单段过场 2 分钟起，还连播三段。给演出设预算表，可跳过是底线。
5. **解谜与动作互相踩脚**：解谜时刷小怪、战斗时被机关硬控。一个场景一个主导支柱，混合只放在设计好的合成段。
6. **相机各自为政**：战斗切演出时镜头跳变、穿墙、丢目标。相机从第一天起做统一管理层（§4）。
7. **引导全靠任务标记**：空间里没有地标与视觉语言，探索乐趣被箭头替代。引导先做进空间（§3.5），UI 只做兜底。
8. **收集品变成清单清理**：与叙事、玩法、地图都不挂钩的收集品是负资产。每个收集品回答「拿了有什么用」。
9. **软锁**：机关顺序颠倒、道具卡在不可达处，玩家被存档锁死。机关可重置，测试期用调试工具扫全图。
10. **范围失控**：按 20 小时正片规划，做到一半砍区域、砍到主线断裂。先做「窄版全程」（一条主线从头走到尾），再横向加分区与支线。

## 延伸阅读

- 《游戏设计手册》（⑨）：核心循环、体验支柱与玩法规格表的底稿。
- 《关卡设计手册》（㉑）：度量、引导、节奏与白盒流程，本文第 3 节的完整展开。
- 《技术实现手册》（⑩）：相机、交互与演出系统的实现要点。
- 《案例研究集》（⑳）：标杆与失败案例的拆解方法，拆箱庭与演出时对照。
- 《独立开发生存手册》（⑱）：范围控制与排期，预算不够时按第 5 节的砍内容顺序执行。
- 《避坑大全》（⑥）：从立项到上线的全流程高频坑位。
