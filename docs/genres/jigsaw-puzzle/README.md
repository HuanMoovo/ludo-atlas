# Ludo Atlas · 类型手册 · 拼图类（Jigsaw Puzzle）

> **类型手册 · 第四辑**。定位：把「碎片复原成整图」做成第一乐趣的桌面品类数字化形态。玩家靠形状与图案两条线索归置碎片，无失败、无时限、随时可停；图库与手感是全部资产。本页覆盖拼图手感、图库生产与授权、难度与辅助功能、放松定位与移动端变现结构，以及协作与每日变体。
> 配套：《游戏设计手册》（核心循环与难度分层）·《美术与音频手册》（图库生产与外包管理）·《运营与增长手册》（广告、内购与长线内容节奏）·《法务、专利与竞争手册》（图库授权与用户内容合规）。
> 本文不放外链；数字为常见量级，落到项目里以实测为准。

## 1. 定位与核心循环

中文里「拼图」一词两用：广义泛指解谜（puzzle）家族，狭义专指 jigsaw（碎片拼合复原），本文只写后者；解谜设计以《解谜》（第一辑）页为准。拼图前身是十八世纪欧洲的教学用具（教地理的裁切地图），此后演变成桌游与休闲产品；数字形态保留了找片、归位、复原的全部动作，又补上桌游没有的便利：确定性吸附、自动分组、随时存档与近乎无限的图库。

一句话定位：拼图类是**以「复原」为第一乐趣**的类型。每一片有且只有一个正确位置，玩家的每一次放置都让画面更完整一分；设计工作围绕三件事：吸附手感（§3.1）、图库（§3.2）、难度与辅助的平衡（§3.3）。

核心循环用动词环写：`选图与档位 → 铺开碎片 → 挑边 → 分区聚合 → 吸附成组 → 补完 → 结算与收藏`。它分三个尺度：

| 尺度 | 循环 | 玩家得到什么 |
| --- | --- | --- |
| 一次放置（1-3 秒） | 找片 → 拖近 → 正确则吸附 | 一次确定的「对了」 |
| 一幅拼图（10 分钟到数小时） | 挑边 → 分区 → 聚合 → 补完 | 画面复原的可视进度 |
| 一部图库（数周到数月） | 完成一幅 → 结算收藏 → 挑下一幅 | 收藏累积与新鲜感 |

循环成立的三个前提：吸附必须确定（对就是对，不对不粘，没有模糊地带）；找片成本可控（时间大头花在找，工具决定占比）；进度随时存得住（品类会话高频被打断，退出再回来要原地继续）。与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 解谜（Puzzle） | 解谜的进度来自推理；拼图不做推理，答案已经全部给出，进度来自辨认与匹配 |
| 寻物找茬 | 同为视觉休闲：寻物考「找到」，拼图考「归位」，前者重扫视，后者重比对 |
| 三消 | 三消有步数预算与失败；拼图没有失败，时限最多作为可选模式存在 |
| 合成类 | 合成的乐趣是组合与数值成长；拼图的组合是复原，没有数值，只有完成度 |

自检问题：把画面换成纯色、只剩形状，游戏还成立吗？成立但乐趣掉档，说明图案与形状都是你的内容；再把吸附的确定感拿掉（拖到哪都不粘、放对了没反应），玩法立刻崩掉，说明手感是命门。

团队口径：轻工程、重内容，技术栈浅（拖放、吸附、存档、图库管理），没有物理、AI 与网络（联机变体除外）；买断与小体量发行常见，移动端长线形态靠更新节奏支撑，稀缺能力是图库的审美与采购。一句话结论：拼图卖的不是玩法，是图库与舒适感。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **确定的进展**：放对就有清晰回执，玩家永远知道「我做对了」，不需要规则说教。
2. **松弛**：无失败、无时限、随时可停；它的对手不是难度，是压力——拼图是少见的可以一边听播客一边玩的品类（§3.4）。
3. **手感的实感**：吸附的磁吸、音效与落定是核心爽点货币，要打磨到「忍不住想多放一片」（§3.1）。
4. **肉眼可见的进度**：边缘完成、区域接通、尾盘收束，画面本身就是进度条。
5. **低负担的辅助**：卡住有出口，且用辅助不被惩罚、不被羞辱（§3.3）。

反面感受（出现任意一条都是红灯）：找不到一片又找不到出口；拖到位没反应或莫名吸歪；中途退出进度清零；图库重复单调。标杆与产品形态（不必点名，按形态各拆一个样本，方法见《案例研究集》）：

| 形态 | 可学的点 |
| --- | --- |
| PC/网页经典拼图（买断合集） | 图库与片数档位就是内容本体；一张图配多档难度复用；界面模板化，把成本集中到图库 |
| 移动端放松向拼图 | 单手可玩、自动分组托盘、安静的视听包装；「随时合上再打开」的会话设计 |
| 每日拼图（全服同题） | 一天的仪式感换回访：固定时点的轻内容、连胜与分享；分享设计对照《文字游戏》（第三辑） |
| 协作多人拼图 | 把一家围坐拼图的居家活动搬到线上：区域分工、同屏或联机同步、进度合并 |
| 小游戏平台免安装拼图 | 低门槛分发与广告回收；图库轮换与加载策略决定体验上限 |

共同特征三条：核心资产是图库不是机制（机制变化空间小，新鲜感靠图）；难度靠片数模块化（同一张图从 12 片做到 1000 片）；长期回访靠内容节奏（每日与节令图包），不做就没有回来的理由。

## 3. 设计要点

### 3.1 拼图手感：吸附、旋转、分组、边缘优先

| 零件 | 做法 | 设计口径 |
| --- | --- | --- |
| 吸附 | 拖到正确邻接位置附近自动归位 | 只在「正确邻接」上吸附，错误位置永不粘合；这条消灭了实体拼图最贵的错误：拼错一整片区域要拆掉重来 |
| 旋转 | 碎片带角度，转正后才能吸附 | 默认关闭，做成难度选项；开启时给角度吸附（接近正确角度即自动归正），操作用点按转固定角度这类单手势，并给一键归正兜底 |
| 分组 | 正确相邻的两片粘成一队，可整组拖动，组与组继续吸附合并 | 数字拼图相对实体拼图最大的手感红利；必须做，且要顺：整组拿起、整组吸附、落定只响一声 |
| 边缘优先 | 边缘碎片分类或一键挑边 | 人天然先拼边，这是最顺的开局路径，也是免文字教学（教学纪律对照《解谜》（第一辑）） |

- 抓取、拖动与托盘：抓起放大少许、加阴影与抬升感，拖动中碎片中心略高于触点；放下未吸附就留在原地，不要弹回托盘；吸附容差以碎片边长的一小段计，触屏宽于鼠标，进配置表按档位与设备校准；散片托盘支持按颜色与形状排序，「指出某片在哪」属于提示层（§3.3），与基础工具分开计。
- 吸附反馈三件套：几十毫秒的磁吸位移动画、落定音（音色按区域或进度变化）、小粒子或高光，三者同拍；吸附迟到或无反馈，手感立刻发飘。

手感验收：找 5 个人各拼 24 到 100 片，记录「拖了没跟上」「放对了没反应」「吸附感觉不到」的次数，都应接近零；再看找片耗时占整局的比例，超过一半说明散片管理工具不到位。

### 3.2 图库内容与授权

- 图库是内容本体：拼图产品的资产表上，图库排第一行；一张图配多档片数是摊薄成本的核心杠杆，图库规模决定「一局接一局」的新鲜感储备。题材矩阵（常见组合）：风景旅拍、动物自然、城市建筑、艺术名画、插画绘本、花卉静物、节令节日、抽象渐变；各题材占比按受众校准，长线平台广度优先，单题材不押重注。
- 图源四条路，权属压力从低到高：
  - 委托创作与自有美术（权属最干净、单张成本最高），以及开放素材与公共领域（名画、公有领域摄影、开放许可图库，逐张核对条款，「画作」与翻拍「照片」可能各有权利）；
  - 图库站采购：条款对「把图片作为产品核心内容再分发」常有额外限制，别默认买了就能用；
  - 用户自传照片：定制拼图的常见功能，隐私与审核压力最大，协议与存储先过《法务、专利与竞争手册》。
- 授权台账与红线：每张图一条记录（来源、权利方、授权范围与期限、署名要求、证明材料路径），「找不到来源」的素材一律不用；影视、动漫、游戏角色、明星照片与品牌标识都不碰，同人向与粉丝向同样不行，含人物的素材注意肖像权。
- 拼图专属的美术验收：画面细节密度要均匀，大片纯色（天空、水面）缺线索，过密区域找不到入手点；验收动作是把图缩到目标尺寸随机指五处，每处都要有可辨认的图案线索。

### 3.3 难度系统与辅助功能

难度旋钮只有四个：片数、形状（标准网格或异形）、有无旋转、有无时限；一次只动一个。

| 档位 | 片数（常见） | 默认辅助 | 面向 |
| --- | --- | --- | --- |
| 上手 | 12-48 | 幽灵底图、边缘分类全开 | 新玩家与低龄 |
| 常规 | 100-192 | 参考图常显、可开幽灵 | 大众放松 |
| 挑战 | 300-500 | 参考图可开、幽灵可选 | 熟练玩家 |
| 硬核 | 500-1000 起 | 无预览无幽灵，可自愿更狠 | 核心玩家 |

- 片数与时长量级：常见档位是每档翻倍（12/24/48/96/192）或有整数记忆点的档（100/300/500/1000），同一张图配 3 到 6 档是常态；含找片与犹豫平均每片几十秒，100 片常见半小时到一小时，1000 片是数小时起步的项目（§5）。
- 辅助功能清单（基础项全部免费给，使用不扣分、不扣星、不留记录）：
  - 参考图与幽灵底图：原图可常显可缩放，底板上可淡显图案轮廓，后者是大档位与纯色区域的救命项；
  - 分块与散片工具：整图划区、一次聚焦一块；散片按颜色或形状排序、边缘一键挑出、托盘翻页；
  - 提示分级：A 级指出某片的大致归属区域，B 级直接放到正确位置；免费给有限次数，超出用激励视频或内购续（§3.4），入口是减压阀不是罚款单；
  - 无障碍：两步点击替代拖拽（运动障碍）、碎片边缘描线与高对比模式（低视力与色觉差异）、字号与按钮尺寸达标。
- 时限与计时：想给熟练玩家压力就做独立模式与排行榜，不侵入主线；把默认体验做成计时的产品，等于把放松品类做成考试。

### 3.4 放松定位与移动端变现结构

放松定位先立硬约束：无失败、无惩罚、无强制时限，会话随时被打断、回来必须无缝；移动端长线产品的变现由四层构成，比例与顺序因产品而异，数值按自己的留存与卡点数据校准（方法见《运营与增长手册》）：

- 图库付费：主题图包（风景、节日、联名）、订阅会员（无限图库）、单张点购；免费路径要保证永远有图可拼，付费买的是更新更快、题材更对味。
- 广告：激励视频换提示、预览与当天新图，插屏放在完成结算之后；红线一条，拼的过程中不打断，完成的瞬间与连载式拼图是全品类最贵的注意力。
- 提示与辅助内购：提示包、自动完成尾盘、去广告；免费路径必须有替代（限量提示、等待恢复），付费买的是更快更省事。
- 定制照片：导入自己的照片生成拼图，常作为高级功能；隐私、存储与内容审核义务同步处理（§3.2，《法务、专利与竞争手册》）。
- 买断对照与纪律：PC 与网页端常见买断合集或 DLC 图包，差别在更新承诺，订阅与连载需要产能兜底；数据盯单幅完成率与下一幅启动率，压力变现（时限逼迫、进度清零、羞辱式辅助）会打碎定位与口碑，「为热爱付费，不为焦虑付费」以为准。

### 3.5 变体

| 变体 | 核心改动 | 工程与设计点 | 适用场景 |
| --- | --- | --- | --- |
| 每日拼图 | 全服同题、固定时间窗（常见一天）、完成可分享 | 服务端极轻（题目与结果）、分享图生成、连胜与历史页 | 回访与轻社交 |
| 协作拼图（同屏） | 一台设备一起拼或轮流拼 | 多人拖拽冲突（同一片两人抢）、进度合并 | 家庭与线下聚会 |
| 协作拼图（联机） | 多人在一幅图上分工或同拼 | 权威状态、碎片锁定与超时释放、断线重连；工程量升到小型联机产品档 | 好友社交 |
| 拼图加长线目标 | 拼图产出资源，驱动装修、收集或剧情 | 参照三消加装修的循环，内容账按两套排产 | 移动端长线产品 |

纪律：主线只保留一个「安静地把一幅图拼完」，变体是回访理由的补充；协作与每日是最常见的两种加值，除联机协作外工程量都不重；每日拼图的题库与图库排期合并管理，节令图提前一个周期进库，断更一天就断连胜。

## 4. 技术要点

技术栈浅，没有物理与 AI；难点集中在碎片数据、拖放交互、存档与图库管线四件事上，以下与引擎无关。

- **碎片与吸附**：每片一套数据（图源 ID、行列号、位置与角度、归属组 ID），「正确」由行列邻接关系决定，不做像素比对；渲染取整图子区域加拼块形状遮罩，不必预切小图；吸附判定看「拖动片与已有片或组的边缘槽位」，分组用并查集，组吸附、组拖动与「只剩一个集合」的完成判定一次解决。
- **拖放与交互**：触屏、鼠标、手柄三类输入分别校准（触屏容差与抓取范围放宽），拖动跟随延迟压在一到两帧；抓起、拖动、放下三段状态机要清晰，断触按「放下未吸附」处理；两步点击（点选碎片再点目标位置）的替代路径必须存在；底板超出屏幕时提供缩放与平移，碎片拖拽优先于视角平移。
- **存档与恢复**：每次吸附即存档（位置、角度、归属组、辅助开关全进档），会话随时被系统杀掉，存档粒度就是体验底线；碎片与图源 ID 绑定，图不变则旧档可升级；云存档（若做）按「已归位碎片取并集、组按并查集合并」处理，不做整档覆盖。
- **图库管线与加载**：图库目录数据化（每张图含题材标签、授权记录 ID、可用档位与解锁条件，运营不加代码上新图）；预览、底板与碎片按档位取不同分辨率，图源必须覆盖最高档位；切分模板（标准网格、异形边、整图异形）是形状难度资产。
- **可测性**：埋点最小集为每幅完成率与用时、退出点位、辅助与提示使用次数、下一幅启动率；开发者测试档要能一键跳到「只剩 N 片」与满载散片，尾盘体验与性能才测得了。

## 5. 内容量与工作量参考

以下为常见量级，用于估算范围，不构成承诺。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 机制原型 | 5-10 张图（开放素材） | 2-4 周 | 只验证吸附、分组与存档 |
| 小型买断作品 | 50-150 张图加多档位 | 3-6 个月 | 图库采购是主成本 |
| 移动端长线产品 | 上线 100 张起，持续更新 | 持续投入 | 图库产能与更新节奏绑定 |
| 联机协作产品 | 图库需求减半、工程翻倍 | 中型项目档 | 联机是工程大头 |

换算口径：

- 图库账是主账：按委托插画常见几百到几千元每张、图库站授权常见几十到几百元每张的量级估算，100 张起步的图库是数万元起的采购；一张图配 3 到 6 档摊薄成本，大档位要求更高分辨率图源，采购时按最高档位选图。
- 排期与范围纪律：机制与工具 2-6 周，上线时间由「图库每周新增几张」的产能线性决定，瓶颈在采购与筛选不在代码；题材广度可以从窄起步，授权干净不能妥协，一张侵权图就能让产品下架。

## 6. 第一个原型怎么起步

目标：2-4 周回答一个问题：手指拖着一片碎片靠近正确位置、那一下吸附，能不能让人想继续放第二片。用开放素材，不采购图库。

1. **第 1 周：拖放与吸附。** 一块底板、一副 12-24 片的图；实现拾取、拖动、正确邻接吸附与落定反馈。丑是应该的。
2. **第 2 周：分组与散片管理。** 两片粘组、组拖组吸、边缘一键挑出、散片排序托盘；存档做成每次操作即存，用杀进程反复验证恢复。
3. **第 3 周：辅助与难度档。** 参考图、幽灵底图、分块聚焦；上两档难度（24 与 96）对照测。
4. **第 4 周：盲测与收尾。** 找 3 到 5 个人各拼两幅，只记录不说话：完成用时、找片耗时占比、何时想放弃、拼完是否主动要下一幅；补上完成演出与「下一幅」的衔接。

成功标准（全部可观察）：

- 测试者不用人教就开始拖第一片，多数人自发先挑边。
- 无人因「拖不动、吸附失灵」放弃；完成用时落在 §3.3 的量级内。
- 至少半数测试者拼完主动要下一幅；杀进程重开进度无损；改一个吸附容差参数，5 分钟内在真机验证效果。

原型验收不过，不要买图库：图库是这个类型最贵的一笔采购，手感不成立时买多少图都救不回来。

## 7. 常见坑

1. **吸附按像素判定**：同色区域吸歪或该吸不吸；正确与否应交给行列邻接关系（§4）。
2. **分组做半套**：组能拖但一放手就散，组吸附逐片瀑布；这是相对实体拼图的核心红利，做不好等于白做（§3.1）。
3. **进度不存**：来电、杀进程后清零；这类会话高频被打断，存档不是功能是底线（§4）。
4. **辅助羞耻化**：提示要扣星、扣钱或看长广告；放松定位下，惩罚辅助就是制造挫败（§3.3）。
5. **授权含糊**：用「网上找的图」商用发布即侵权；每张图都要有授权台账（§3.2，《法务、专利与竞争手册》）。
6. **题材单调**：一百张同风格风景，拼到第十张就腻；题材广度是长线产品的新鲜感来源（§3.2）。
7. **档位起步太大**：默认 1000 片，把大众用户挡在门外；从 12 片起步（§3.3）。
8. **时限侵入主线**：默认计时、超时惩罚，把放松品类做成考试（§3.4）。
9. **画面与图源不匹配**：大片纯色、细节过密、边缘与背景同色，或分辨率撑不起大档位；委托时给「拼图观感」验收标准（§3.2、§4）。
10. **每日拼图断更**：承诺每天都有，断一天就断连胜、伤口碑；假期前先把图囤够（§3.5）。

## 延伸阅读

- 《游戏设计手册》：核心循环、难度分层与反馈设计，第 3.1、3.3 节的底稿。
- 《美术与音频手册》：图库生产、外包管理与验收流程，第 3.2 节的展开。
- 《运营与增长手册》：广告、内购与长线内容节奏的口径，第 3.4、5 节的配套。
- 《法务、专利与竞争手册》：图库授权、用户内容与肖像权的合规口径，第 3.2 节的完整展开。
- 《解谜》（第一辑）：姊妹页；拼图不做推理、重辨认与匹配，边界对照见第 1 节。
- 《文字游戏》（第三辑）：每日谜题与分享设计的对照样本，见第 3.5 节。
- 作业：拿一副现成照片在引擎里切 24 片，只做拖放、吸附、分组、存档四件事，拼给自己与家人各一遍；能让人坐到拼完，再谈图库采购。
