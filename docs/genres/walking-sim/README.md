# Ludo Atlas · 类型手册 · 叙事探索（Walking Sim）

> **类型手册 P2 批次**（第 ㊱ 轮扩展）。定位：没有战斗、没有谜题、没有失败状态的叙事类型，玩家用行走、观察与倾听读完一个故事；空间本身就是叙述者，本页覆盖它的交互契约、演出账本、无 HUD 引导与体量控制。
> 配套：《游戏设计手册》（⑨，核心循环与叙事设计）·《美术与音频手册》（⑪，场景与音频规格）·《案例研究集》（⑳，拆解方法）·《独立开发生存手册》（⑱，范围与排期）。
> 本文不放外链。标杆只列大众熟知的作品；文中数字为常见量级，按自己项目的实测校准。

## 1. 定位与核心循环

一句话定位：叙事探索是**把「走、看、听」本身做成内容**的类型。没有失败，没有资源管理，玩家的全部手段是到场与注意；故事不长在过场里，长在空间、物品与声音上。中文社区也常叫它「步行模拟」或「叙事冒险」，本页统一用「叙事探索」。这个类型的节奏以分钟计，每一次停顿与发现都要经得起回看；燃料是好奇心而不是奖励表，停转只有一种方式：玩家既不知道去哪，也不在乎去哪。

核心循环用动词环写：

`行走 → 注意到异常 → 靠近与查看 → 读到一段信息 → 理解发生改变 → 想去下一个地方`

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 视觉小说 | 阅读是第一动作，空间退化为背景板；叙事探索把推进权交给行走，阅读是回报 |
| 点击式冒险 | 谜题是门禁，解开才放行；叙事探索没有门禁，节奏由好奇心支配 |
| 互动电影（奇异人生、底特律：变人一类） | 关键节点由选择与限时操作承担；叙事探索把关键节点交给空间与文本，尽量不打断行走 |
| 恐怖步行类（层层恐惧一类） | 也用行走加音效叙事，但由威胁接管节奏；叙事探索拒绝惩罚，紧张感来自信息本身 |

一个自检问题：拿掉全部战斗、谜题与失败状态，玩家还愿意走完吗？答案若为「愿意」，你做的就是叙事探索；必须靠机制留人的话，它就是别的东西披了一层叙事皮。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **在场感**：玩家相信自己站在那个地方，光线、声音与脚下的细节都在配合。
2. **好奇牵引**：每个拐角之后有东西，且那东西值得走这一段路。
3. **拼图的快感**：信息不一次给完，玩家自己把碎片接起来，得出属于自己的真相。
4. **情感兑现**：走过的每一步最终汇成一次情绪落点，故事在「自己的旅程」里结束。
5. **被尊重**：不被当傻子（不加箭头、不喂提示），也不被惩罚（不死、不卡死、随时可停）。

标杆作品（大众熟知名单，建议亲手通关再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 看火人 | 对讲机双人对话：两名角色全程不同框，关系弧线靠台词与沉默承载；峡谷地形当关卡用 |
| 艾迪芬奇的记忆 | 每个家族成员一段独立交互，两小时里换十几种表达方式；文本、物件与空间拼出家族史 |
| 到家 | 一座 1995 年的房子，全部故事长在物品与便签上；结尾信息投放的教科书 |
| 亲爱的艾丝特 | 行走加独白的极端形态，岛屿即意识；把解读权完整交给玩家 |
| 斯坦利的寓言 | 旁白与玩家的对抗；用「不听话」当玩法，证明叙事探索可以幽默且耐重玩 |
| 风之旅人 | 无文字行走的近亲：空间、音乐与匿名同行构成全部叙事，情绪曲线是唯一目标 |

玩家对这类作品的预期是「一次完整的情感旅程」，不是「一套反复游玩的系统」；这个预期决定了本页几乎所有的设计取舍：可以短，不能拖；可以静，不能闷。

## 3. 设计要点

### 3.1 叙事驱动探索：空间、物品与声音

三大叙事载体，分工不同：

- **环境叙事（空间即叙述）**：布局、陈设、磨损、灯光都在说事。验收方法：关掉全部文本，一个房间能不能读出「谁住在这里、最近发生了什么」；读不出来，它就是摆件不是叙事。
- **物品与文本**：便签、信件、录音、照片、涂鸦。一条文本只承担一个新信息；「长文等于深度」是错觉，跳过率与长度成正比（§7）。
- **声音（含口吻统一）**：环境音层、远处的声音、无线电与独白；声音是唯一「不看向也生效」的叙事层，同时兼任引导（§3.4）。全部文本先立声音表再动笔，多人合写才不串味，做法同《视觉小说》。

信息按三层登记，投放位置与容错策略写进表里：

| 层级 | 内容 | 投放位置 | 玩家错过时 |
| --- | --- | --- | --- |
| 主线信息 | 玩家必须知道的事实 | 必经路径、必经交互 | 系统兜底：换一处再投一次 |
| 角色信息 | 人物性格与关系 | 探索支路、物品文本 | 允许错过，不影响理解主线 |
| 氛围信息 | 世界观细节与余味 | 犄角旮旯、重复观察 | 错过即错过，留给二刷与讨论 |

三条纪律：

- 关键信息至少两条获取渠道：必经之路给一次，一个可回访的物证再给一次；单点触发是这类作品最常见的翻车方式。
- 乱序兼容：玩家可能先到后到、东看西看；文本与对白要经得起乱序访问，指涉不依赖固定顺序。
- 事实表对账：人物、时间、地点、物件全篇一致；魅力全部建立在细节可信上，一处矛盾会拆掉整面墙。

### 3.2 玩家契约：慢的容忍度与拒绝清单

- 进场十分钟是签约期：玩家用这段时间确认两件事，这里没有危险，这里值得看。一个无压力的开场加一次清晰的回报（一眼望见的风景、一个悬念），契约就算签下。
- 慢的容忍度不由时长决定，由回报密度决定：连续三五分钟没有任何新信息（视觉、文本、声音皆无），玩家就会开始怀疑节奏。校准方法：把测试里玩家「主动停下看什么」的时刻标在时间轴上，两处停留之间的空窗就是你的「慢」的上限；自己看回放都觉得难熬的段落，删掉或添上东西。
- 速度也要签进契约：常态走路的速度是玩家的默认触感，标准是「看风景不焦躁、赶路不痛苦」；提供不费力的持续奔跑，不做体力条。

拒绝清单（明确不做，等于把契约写进设计里）：

| 不做 | 理由 |
| --- | --- |
| 失败状态与死亡 | 与「自由观看」的契约相斥；坠落用送回处理 |
| 战斗、追击、潜行 | 改变玩家的注意力分配；恐怖分支是另一套契约，不混用 |
| 时限与倒计时 | 系统层面的焦虑不服务叙事；剧情内的紧迫感靠演出 |
| 资源管理与背包 | 让玩家从「读故事」切换到「算账」 |
| 收集品清单强迫 | 清单让玩家为完成度走路；收集必须服务叙事（影集、录音） |
| 硬性找路 | 找不到路是事故不是关卡；方向感必须由设计提供（§3.4） |
| 强制过场与锁输入 | 演出尽量在行走中发生，少锁玩家 |

舒适底线与清单同等重要：随时暂停退出、自动存档、演出可跳过可回看、字幕与字号可调；这些不是加分项，是契约的一部分。

### 3.3 演出成本：配音、文本与动画的账

成本结构先说清楚：叙事探索不烧玩法系统，烧演出。立项时就要有三张单子：文本字数、口播分钟数、动画与环境动效条目数。

配音是最大变量，演出形式的选择直接决定成本档位：

| 演出形式 | 成本档位 | 适合 | 注意 |
| --- | --- | --- | --- |
| 无线电／对讲机式 | 低 | 双人关系叙事；角色不同框，没有口型与镜头开销 | 声音要有设备质感与空间处理，避免变成旁白 |
| 独白／旁白式 | 低到中 | 私人化、诗化的叙事 | 信息密度要克制，容易滑向朗读剧 |
| 全场景对白加口型 | 高 | 有 NPC 现场互动的作品 | 动画与镜头成本成倍，改稿即重录 |
| 无配音纯文本 | 最低 | 原型、实验与小体量作品 | 情绪上限受限，靠写作与演出补 |

- 文本与配音账：对白、独白、物品文本、字幕分开记账；写作速度与修订倍率沿用《视觉小说》的口径（每天 2000-4000 字初稿，修订按 0.5-1 倍）；配音先统计总口播时长再乘计价，找配音演员试读掐表换算，文本冻结后再进棚，改稿重录预留追加预算。
- 动画与音频账：动画分三本（第一人称手部与道具、可交互物、环境动效），环境动效是氛围大头也最容易被低估；音频承担引导与情绪两条线，混响切换、音乐触发点、无线电音频链都要单列进计划。
- 预算纪律：高成本演出（全屏脚本、光照剧变、大范围动画）只放在情感高点，按章节做预算表；每段都想震撼，等于全篇没有震撼。把重要对话放进「可以边走边听」的形式（无线电、电话、录音带），玩家自控节奏，你也省掉镜头与口型，看火人的对讲机结构是这条路线的经典样本。

### 3.4 无 HUD 引导：方向感设计与焦点引导

原则：这类作品几乎不能有任务箭头与小地图，它们会当场拆掉「自己发现」的乐趣。引导必须长在世界里，工具箱如下：

| 工具 | 做法 | 说明 |
| --- | --- | --- |
| 光 | 主路径与下一步落点保持明亮，黑暗给岔路降权 | 最便宜也最有效的引导 |
| 构图 | 门框、树隙、街角形成取景框，把目标框进画面 | 玩家会顺着「画」走 |
| 地标 | 每个区域一个可远望的锚点（塔、烟、亮窗） | 玩家能说出「我在哪」，才不会迷路 |
| 声音 | 环境音指向目标方位，无线电与音乐牵引视线 | 不看向也能收到的引导 |
| 动 | 风、烟、鸟、闪烁的灯 | 静态画面里唯一动的东西就是焦点 |

- 方向感设计：锚点体系加视线通廊，渐进揭示。每到一个新区域，先给玩家一眼能看到的锚点，再放他自由探索；锚点会被反复用来回答「我该往哪走」。焦点引导也是减法：需要玩家看的东西，周围不能有同样抢眼的东西，演出时刻先清场，再放焦点。
- 迷路是事故：无 HUD 的代价是迷路成本高，用测试兜底，记录三类迷失事件，原地转圈、反复走回头路、长时间没有朝向目标；修法是加光、加声、加地标，而不是加箭头。另做可开关的「引导模式」（更亮的焦点提示、更明显的音效），默认关闭，只给需要的人兜底。

### 3.5 时长控制：2-4 小时为什么成立

- 体量逻辑：行走本身没有成长曲线，好奇心是一次性资源，新鲜感的衰减速度决定了这个类型适合短，2-4 小时对应一到三个晚上的完整旅程，与玩家对这类作品的定价与口碑预期对齐；拉长到 8 小时以上，则需要成倍的场景、文本与演出密度来维持好奇心的半衰期，密度一掉，玩家立刻从「探索」切换到「赶路」。
- 结构模板：开场（5-10 分钟）签约，建立场所、埋悬念、教会「走、看、听」；中段展开与一次信息重组，让玩家对已看过的东西产生第二层理解；末尾 30-60 分钟收束，兑现情绪，走路的距离要短，别让高潮被步行稀释。
- 节奏表（常见量级）：每 2-3 分钟有一个小发现（可读物件、景物变化、一句无线电）；每 10-15 分钟有一个中回报（新区域、关键文本、一次演出）；每 30-40 分钟有一个大节点（剧情转折或情感高点）。白盒全流程计时，再找陌生人通关计时；看分布而不只看平均，最短与最长的两个人各暴露一类问题，引导太直或者迷失太多。

## 4. 技术要点

工程难点集中在四块：第一人称移动、交互与触发器、演出调度、音频与存档。引擎用 Unity、Godot 或虚幻自带的第一人称模板起步即可，自研引擎没有收益。

**第一人称移动**

- 速度调参只信实测：找三五个不熟悉项目的人问两个问题，急不急、慢了没有，速度取感受的交集；常态走速配一个不费力的持续奔跑。
- 视角与晕动：头部晃动、视野角度、动态模糊、镜头摇摆全部做成设置项，默认取保守档；晕动症会直接淘汰一部分玩家，没有选项等于关掉他们的门。
- 台阶与矮墙做成自动跨越加动画，不做跳跃操作；碰撞体要贴合视觉，玩家会尝试挤进每个看得见的角落，「看着能进、实际进不去」最伤在场感。

**交互与触发器**

- 交互物统一模板：可见性条件、动作、反馈、完成后状态四件套；「看一眼」也做成可放大旋转的查看交互，它是最便宜的阅读手势。提示用物件自身的视觉语言（描边、微光）而不是文字标签，存在感越低越好。
- 触发器、状态表与调试命令：体积触发器加事件调度，关键演出用状态检查式触发（条件满足就补上，玩家绕开或提前触发都能兜住），乱序访问按先到先得、后到补看处理；全部旗标集中登记，重复触发或漏触发都从表里查（同一原则见《点击式冒险》）；跳场景、注入与跳过演出、标出可交互物这些调试命令先做，没有它们每次测试都要重走全程。

**演出调度**

- 时间轴加状态机：对白、镜头、音频与动画走同一条时间轴，玩家输入的处理分锁输入、软锁定（可转头不可走）、不锁三档，优先用后两档；过场克制，全屏过场镜头贵且打断在场感，能在空间内发生的事件优先在场内做。演出可以简单，不能露馅，一个卡在半空的动画或一次硬切的声音会把前面十分钟建立的气质打碎。

**音频与存档**

- 空间音频与混响区域是「在场感」的一半，声音先于画面告诉玩家自己在哪里；音乐触发点加淡入淡出，一章两三次起落就够（同《视觉小说》的 BGM 纪律）；无线电音频链（压缩与滤波）值得单独做一套管线。
- 存档与可访问性：自动存档按区域与节点双点触发，配章节选择与已读标记，不允许任何「重开一段」的惩罚；字幕大小与底色、人声／环境／音乐独立音量、晕动选项、引导模式、色弱检查逐项进设置页，发布前实测。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 形态 | 场景量级 | 通关时长 | 周期量级 | 备注 |
| --- | --- | --- | --- | --- |
| 原型 | 1-2 个房间 | 10-15 分钟 | 2-4 周 | 验证行走手感、焦点引导与一条信息链 |
| 短篇／Jam | 3-6 个场景 | 20-40 分钟 | 1-3 个月 | 单一情感主题，个人可完成 |
| 独立发行常见体量 | 8-15 个场景 | 2-4 小时 | 6-18 个月 | 主力成本是文本、配音与场景美术 |
| 更大体量 | 20 个场景以上 | 4-8 小时 | 团队多年 | 密度维护成本陡增，首作不建议 |

- 场景与美术账：每个场景等于白盒布局（数天）加美术细化（数天到数周，视风格）加文本与录音加演出脚本加音频层；从白盒到发行质量，时间通常是白盒的三到五倍。环境资产按主题成组、模块化复用（墙板、地板、家具按套件做），一个场景主题的资产套件常见几十到几百件。
- 文本与配音账：2-4 小时作品的对白与独白常见 1.5 万到 4 万字，物品与笔记另计；写作速度与修订倍率沿用《视觉小说》口径；配音先统计总口播时长再乘计价，改稿重录预留追加预算。
- 排期与本地化：从零到十五分钟可玩原型 2-4 周，到一个达到发行质量的场景（垂直切片）常见 2-4 个月，之后按场景数外推；文本与配音排在美术细化之前，文本没冻结就录，一定返工。环境音设计、混音、文本导出与术语表属于长期工作，从第一天进计划，不属于收尾工作。

## 6. 第一个原型怎么起步

目标：2-4 周做一个 10-15 分钟的「一条路加一个房间」，验证三件事：行走手感、无 HUD 的焦点引导、一条信息链读起来是否成立。不碰配音、正式美术与菜单。

1. 第 1-4 天：装引擎跑通第一人称模板，把走速、视角与晃动参数做成可调，确认默认值在你的场景尺度下不搓火；然后在纸上写一条十分钟的信息链：玩家进门之前该知道什么、房间里有哪三到五件值得看的东西、看完之后应该得出什么结论。
2. 第 5-10 天：白盒实现一条路、一个房间、三到五个可交互物（色块加文字标签），文本全部写正式稿，不用占位垃圾文本，这里文本就是内容；随后做引导实验，去掉全部 HUD 与文字提示，只用光、声音与构图把玩家带到每个交互物，自己走十遍，确认没有提示也能走通。
3. 第 11-12 天：加音频（环境音加一个音乐触发点）与自动存档；找 3-5 个不玩这类游戏的陌生人测试，不提示、不说话，记录迷失点、跳过点与停留最久的位置。
4. 第 13-14 天：按记录迭代，迷失点加光或加声，跳过点砍文本或改形式，停留点记下来，那是正式内容里要复用的手法；结束时只问一句：「你还想知道后来发生了什么吗？」

成功标准（全部可观察）：

- 至少 4 名测试者无提示走完全程，每人迷失事件不超过一次。
- 有人主动停下看细节并说出自己的推测，环境叙事才算成立；拿掉全部美术与音频，白盒加文本仍然读得懂「发生了什么」。
- 通关复述与设计意图一致，测试者说出的故事和你的信息链答案相同或至少不矛盾；离开时在讨论故事，而不是在问「这游戏要干嘛」。

## 7. 常见坑

1. **空间不叙事**：房间只是通道与摆件，走完全程说不出任何地方发生过什么。规避：每个场景回答一句「谁在这里、最近发生了什么」（§3.1）。
2. **信息单点触发**：关键演出只触发一次，走岔路就永久错过。规避：关键信息两条渠道、乱序兼容、状态检查式触发（§4）。
3. **靠 HUD 兜底**：任务箭头与引导条一加，探索感当场归零。规避：先穷尽光、声、构图，箭头只作为可访问性选项存在（§3.4）。
4. **行走手感将就**：默认参数直接上，速度与视角全程别扭，晕动症没有选项，玩家判死刑只需要十分钟。规避：把走速、视角、晃动与晕动设置当成一套系统来调（§4）。
5. **文本自嗨**：便签写成小作文，玩家全跳过。规避：一条文本一个新信息，砍掉氛围描述式填充；跳过率进复盘指标。
6. **配音与音频抢跑**：文本没冻结就进棚，改一行重录一次，预算翻倍；把音频当配乐包外包，场景发闷、空间感丢失。规避：文本冻结后再录，优先「边走边听」的形式集中录音；环境音与混响按场景单列预算，音频工作早期进场（§3.3）。
7. **演出锁死玩家**：每隔几分钟锁一次输入放过场，自主感反复被打断。规避：演出尽量在行走中发生，优先软锁定甚至不锁（§4）。
8. **体量失控**：想做八小时，做到一半发现好奇心撑不住，密度崩塌。规避：首作上限四小时，按 §3.5 的节奏表逐段检查。
9. **动机断线**：玩家不知道为什么要去下一个地方，只能靠「哪里像有路」判断，游戏退化成迷宫。规避：每个目标落地前问「玩家现在想知道什么」，动机由信息差提供。

## 延伸阅读

- 《游戏设计手册》（⑨）§8 叙事设计：世界观呈现、环境叙事与文本投放的方法底座，本文第 3 节的上位方法；拆第 2 节标杆时配合《案例研究集》（⑳）的案例方法。
- 《美术与音频手册》（⑪）：场景美术规格、环境音设计与混音规范，本文 3.3 与第 5 节的扩展账本。
- 《独立开发生存手册》（⑱）与《避坑大全》（⑥）：范围控制、排期与内容生产坑位，与第 5、7 节互为补充。
- 同手册对照：《视觉小说》（文本与演出分工）·《点击式冒险》（引导与防卡死）·《文字冒险》（状态追踪），边界见第 1 节。
- 作业：为一个十五分钟的场景写一条三层信息链（主线／角色／氛围），标注每层信息在哪两处投放；再把一部标杆作品的开头十分钟拆成「走过的路径／给出的信息／你的情绪」三行，排一张时间轴。

叙事探索最终只考验两件事：你放进空间的每个细节是否说了话，玩家走完时是否拼出了完整的真相。
