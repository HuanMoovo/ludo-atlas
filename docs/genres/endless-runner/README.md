# Ludo Atlas · 类型手册 · 无尽跑酷（Endless Runner）

> **类型手册 P3 批次**（第 ㊵ 轮扩展）。定位：把「一直向前跑」做成核心张力，用一到两个手势的操作地板，撑起程序生成的无限跑道；一次失误即终局，距离与金币负责让人再来一局。本页覆盖极简操作与深度、程序生成与难度曲线、速度感与镜头、复活与变现、皮肤收集的长期动力，以及小团队的量级核算。
> 配套：《游戏设计手册》（⑨，核心循环与难度曲线）·《技术实现手册》（⑩，程序生成与性能）·《运营与增长手册》（⑬，留存、变现与长线运营）·《美术与音频手册》（⑪，速度感与反馈）。
> 本文不放外链，标杆只列大众熟知的作品，数字为常见量级，按自己项目的实测校准。

## 1. 定位与核心循环

一句话定位：无尽跑酷是**把「一直向前」做成核心张力**的类型。角色自动前跑，玩家只做少量但高频的决策；跑道无限延伸、程序生成，一局以「跑了多远」结算，失误一次立即收场。

核心循环用动词环写：

`看路 → 滑动或点按 → 闪过障碍与拾取 → 速度继续爬升 → 失误 → 结算 → 再来一局`

这个环以秒计量，一局常见几十秒到几分钟；死亡到重开只隔一次点击。这是它区别于大多数动作类型的要害：惩罚全部落在「本局作废」，而不是进度损失。两条主干：3D 三轨道跑酷（滑动手势为主）与 2D 横版跑酷（点按或按住为主）；骨架同源，区别在操作语法与场面自由度，本页覆盖两者共用的主干。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 平台跳跃 | 平台跳跃有手工关卡与终点；无尽跑酷程序生成、永久向前、一局一结算 |
| 竞速 | 竞速在闭合赛道上比名次与圈速；无尽跑酷是单向前进的生存距离，没有对手与回程 |
| 超休闲 | 超休闲是体量与发行档位，不是玩法骨架；许多超休闲作品正是借跑酷循环成立的 |

一个自检问题：拿掉「一次失误结束本局」的规则，游戏还成立吗？答案若为「不成立」，你做的就是无尽跑酷。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **零门槛起步**：第一局不做任何文字教学，玩家十秒内自己会玩；操作语法一眼看懂。
2. **失败可归因**：每一次死亡都能被解释成看漏、手慢或贪金币，而不是「生成坑了我」。
3. **速度与掌控互相成就**：跑得越远越快，操作精度同步提升；成绩逼近个人纪录或任务目标时，再来一局的冲动最强（§3.4）。
4. **长期收集动机**：皮肤与角色给奔跑一个屏幕中央的持续展示位（§3.5）。

标杆作品（建议亲手玩过再拆，只看视频学不到节奏感）：

| 作品 | 可学的点 |
| --- | --- |
| 神庙逃亡系列 | 三轨道与滑动手势的发轫；追逐者带来的起步紧张与转向节奏 |
| 地铁跑酷 | 快节奏轨道切换、任务系统与皮肤收集的长线运营样例 |
| 天天酷跑 | 跑酷与养成、宠物、社交玩法嫁接的国民级路径 |
| 阿尔托的冒险 | 单键操作的极简克制；坡面与音乐随速度起伏的情绪曲线 |
| 疯狂喷气机 | 按住上升的单一输入；成就任务与局内随机能力带来的变奏 |

## 3. 设计要点

### 3.1 极简操作与深度：一到两个手势的极限

无尽跑酷的操作全集很小，先把它定死：左右滑换道或转向、上滑跳跃、下滑滑铲、点按跳跃（2D 常用点按或按住）。基础动作不超过三个，超出之后手势开始互相抢判定，触屏体验崩塌。

| 手势 | 动作 | 常见误判与对策 |
| --- | --- | --- |
| 左右滑 | 换道或转向 | 斜向滑动被判成错误方向；给方向判定设阈值与主轴优先 |
| 上滑 | 跳跃 | 起跳窗口内重复触发；跳跃期间锁定换道，或明确允许打断 |
| 下滑 | 滑铲、翻滚 | 滑动距离不足被当成点按；按速度与距离双条件识别 |
| 点按 | 跳跃或发射 | 连点丢指令；配输入缓冲，与平台跳跃同款技法 |

三条通用纪律：手势一旦识别就完整执行一次动作，不做半途中断；同一时刻只允许一个未完成手势；操作区与拇指遮挡区分离，可读区域留出安全边距。

深度不从按钮数量来，从路线与时机的取舍得来：把收益（金币、道具、近路）放在危险线，把安全放在空线，玩家每一秒都在做「贪还是不贪」的微型决策。2D 单键跑酷（阿尔托式、喷气机式）把深度全部押在节奏与地形阅读上，操作降到一键，判断密度反而更高。

一条自检：把全部操作讲给一个没玩过的人，讲完不超过三十秒；但他仍会在第十局发现新的路线技巧。

### 3.2 程序生成与难度曲线

生成的单位是「片段」，不是单个障碍。手工设计一批片段（障碍编组），每条标注长度、最低速度档、难度评级与可衔接的进出口类型；运行时按规则拼接，而不是随机撒点。纯随机撒点会在几十秒内产出不可读、甚至不可解的序列，这是本类型最常见的技术性翻车。

生成分四层，各层职责分清：

| 层 | 内容 | 谁来决定 |
| --- | --- | --- |
| 片段 | 障碍编组与安全通路 | 手工设计，逐个测试与标注 |
| 拼接 | 片段的出现顺序 | 规则约束随机：难度预算、防重样、进出口匹配 |
| 参数 | 速度、密度、片段池 | 按距离的曲线函数，全部进数值表 |
| 装饰 | 场景物件、氛围与收集物 | 可自由随机，但不得产生误导或碰撞 |

难度曲线两条轴同时爬：速度随距离递增并封顶，封顶后靠另一条轴继续加压；片段难度按池子分层解锁，先单障碍，后组合，再组合套组合。「难度预算」是核心工具：每段距离给一个预算，抽片段扣预算，高难组合消耗更多，预算见底就强制插入喘息片段。

公平性纪律（生成器的验收线）：

- 可解性与可读性：任何时刻至少存在一条可通行路线，通过条件按「速度乘反应时间」验证，速度变了要重测；不给盲区惊喜，跳跃落点与滑铲出口必须可见。
- 节奏：高难段之间插入空跑或低密度段，连续高压等于隐性死亡陷阱。
- 首次出场：新障碍先在安全环境完整展示一次（教考变奏同款），再进抽取池。
- 种子可复现：随机数由固定种子驱动，每日挑战与好友同图对比才成立（§4）。

### 3.3 速度感与镜头

速度感是本类型的核心商品，它不是仪表上的数字，而是五种手段的合奏：

| 手段 | 做法 | 注意事项 |
| --- | --- | --- |
| 视野 | 视场角随速度渐增并封顶 | 大幅变化会晕，封顶值用手机实机调 |
| 相机 | 跟随距离随速度拉开，换道做缓动，抖动小幅度 | 抖动服务速度感，不遮挡前方可读区 |
| 音高 | 风声、引擎声、脚步声的音高与音量随速度抬升 | 变速平滑过渡，突变会刺耳 |
| 近景 | 贴脸掠过的路灯、栏杆、粒子与速度线 | 不挡住障碍的提前量区域 |
| 角色 | 前倾姿态、残影、动作频率随速度加快 | 视觉与判定必须一致，不许看得到却打不到 |

镜头有三处专项：换道缓冲，视觉横向插值、判定用连续胶囊，两者不得分裂出「人在中间却被判死」的缝；死亡时刻减速并拉近镜头，死因必须被看清，这是玩家接受失败的前提；复活后镜头复位，不能带着死前的倾斜或变焦继续跑。转弯类镜头（直角街口式）辨识度高，但预告必须做实：路面变化、箭头或墙体引导提前给，否则每个转弯都是眩晕源。

### 3.4 结算、复活与变现口径

一局结束时先给三样东西：本局距离（含对个人纪录的逼近度）、本局金币、任务进度；重开一个按钮，间隔不超过一次点击。结算页是移动端最值钱的广告位，也是最容易做恶心的地方，口径建议如下：

- 激励视频只在玩家主动选择时出现：复活、金币翻倍、奖励加抽；局内插屏广告一律不做，奔跑被广告打断，等于亲手制造卸载点。
- 复活是移动端常见设计：原地续跑一次（看广告或花局内货币），但要立三条纪律：每局次数有上限；复活瞬间清空面前障碍或给一段无敌安全距离，不许复活即撞死；复活过的成绩在排行榜要有标记或进独立榜，不污染干净成绩的可信度。
- 内购与广告的边界：卖皮肤、去广告、货币包是主流；卖「跑得更远」的强度直通车会稀释成绩的公信力，好友对比与排行榜随之下滑。

### 3.5 皮肤与角色收集的长期动力

跑酷角色常驻屏幕中央，是移动端价值最高的展示位之一：皮肤在这个类型里的续命效果高于多数品类，因为它每一局都被自己看见。

| 收集层 | 内容 | 动力来源 | 纪律 |
| --- | --- | --- | --- |
| 皮肤 | 外观、主题联动、节日限定 | 展示与稀有度 | 辨识度优先，远景与暗光下也要认得出 |
| 角色 | 外观加极小差异（如起步加速略快） | 手感偏好与身份感 | 差异压到可忽略的幅度，禁止强度分层 |
| 任务与成就 | 每日、每周目标 | 日常登录与目标感 | 任务导向玩法（滑铲到位若干次），不是打卡 |
| 收集册 | 完成度与解锁树 | 收尾的长线目标 | 获取节奏要能撑起数月日常登录，不一次放完 |

三条纪律：皮肤走「同一骨架换皮加装饰件」的复用管线，成本才可控；角色带能力差异时必须做平衡审计，让付费不产生作弊感（变现伦理见《运营与增长手册》（⑬）§10）；限时与活动是回场动机的主力，节日主题皮肤的排期要提前一个大版本锁定。

## 4. 技术要点

工程难点集中在四处：跑者控制、程序生成、移动端性能与输入识别；以下与引擎无关，方法细节见《技术实现手册》（⑩）。

**跑者控制器**

- 用轨道或样条定义前进路径，角色做运动学位移：自己算前进速度、车道横向插值、跳跃抛物线，不交给完整刚体物理；碰撞用胶囊或盒近似，判定从宽，擦肩而过给反馈但不判死，误差方向统一为偏袒玩家。
- 帧率无关：位移按 delta time 计算，低帧率设备上逻辑保持一致；输入到判定的延迟预算优先于画面质量。
- 换道、跳跃、滑铲组成状态机，打断规则明确（空中能不能换道、滑铲时能不能跳），全部写进一张状态表。

**程序生成器**

- 片段库数据驱动：每条片段是配置（长度、难度、速度区间、出口类型）加一份物件清单；生成器只认配置，不认场景。
- 拼接器带约束：难度预算、防重样窗口、进出口匹配、最短安全段；生成逻辑要配单步可视化调试，把预算与抽取结果画在屏幕上。
- 对象池：障碍、金币、装饰件全部池化复用，避免奔跑中的分配抖动；卸载走回收，不走销毁。
- 种子化随机：同一颗种子产出同一条跑道，每日挑战、录像回放与成绩仲裁都靠它。

**移动端性能**

- 预算按最差设备定：锁定目标帧率（常见 60，低端保 30），帧率不稳时优先砍装饰与粒子，不砍可读性。
- 绘制、内存与发热：批量合并材质、共享图集，前方片段流式生成、身后即时回收，内存上限按低端机反推；发热与耗电是留存问题，画质档位、分辨率缩放与刷帧策略从一开始就做成开关。

**输入与手势**

- 手势识别三要素：方向阈值、速度与距离双条件、主轴优先；斜滑误判用真实手指轨迹数据校准，不靠桌面鼠标模拟。
- 输入缓冲与堆叠规则：允许把点按排队到落地后生效；禁止把两个不同手势在同一帧识别成同一个动作。键盘与手柄映射是加分项，但默认体验按触屏打磨，宽容度参数先在手机上过一遍。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 项目形态 | 内容量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 手感原型 | 1 条无限跑道、3 类障碍、2 个手势 | 1-2 周 | 只验证操作、速度曲线与重开 |
| 小型作品 | 1 个场景主题、1-2 个角色 | 1-3 个月 | 生成器与镜头打磨占大头 |
| 常见移动端作品 | 2-4 个场景主题、片段库上百条、4-8 个角色皮肤 | 3-9 个月 | 皮肤与活动是持续成本 |
| 长线运营作品 | 赛季化主题更新 | 上线后持续 | 运营投入超过初期开发 |

- 生成片段是最便宜的内容单位：每条片段白盒一天内能出，难的是逐个测试与难度标注；片段库上百条后，丰富度靠约束系统，不靠继续堆量。
- 皮肤与场景主题按复用管线估算：一个角色的完整动作组（跑、跳、滑、死亡、展示）是一次性投入，之后的皮肤只是一组装饰件与贴图，成本数量级下降；场景主题等于一套模块化场景件加装饰，复用纪律与竞速的赛道相同，一个主题摊多期活动，先榨干再做新的。
- 排期锚点：从零到「一段达发行质量的奔跑体验」（垂直切片）通常 1-2 个月；之后按内容量乘打磨系数外推。范围失控的常见死法是皮肤、系统、活动一起上，把一条跑道都没打磨好。

## 6. 第一个原型怎么起步

第一个原型只做一条无限跑道、一个可操作角色、三类障碍（换道闪避、跳跃、滑铲），1-2 周完成，不碰皮肤、广告、任务与排行榜。

**第 1-2 天：自动前进与镜头。** 角色沿轨道自动向前，速度按距离线性递增，相机跟随；先不生成障碍，把「速度爬升的体感」调顺。

**第 3-5 天：操作全集。** 换道、跳跃、滑铲三件套接上，逐项调输入宽容：手势阈值、缓冲窗口、状态机打断规则。找 2-3 个人试，记录「手势没反应」与「方向判错」两类抱怨。

**第 2 周：生成与重开。** 片段库先做十来条，拼接器上难度预算与防重样；死亡、结算（距离与金币）、一键重开闭环接通。其后只调参数，不加系统。

成功标准（全部可观察）：

- 拿掉全部美术与音效，测试者仍愿意反复跑，单次通常 10 分钟以上。
- 5 名测试者中至少 4 人无口头指导开始奔跑；「明明滑了没反应」类抱怨每人不超过 1 次。
- 死亡原因能被测试者自己说清（看漏、手慢、贪金币），而不是「生成坑人」。
- 有测试者主动要求再来一局，而不是被请求再试一次。
- 任意改一个速度或预算参数，你能在 5 分钟内量化它对平均距离的影响。

操作与生成不通过，就不要开始铺内容；地基上的返工是这个类型最贵的一笔账。

## 7. 常见坑

1. **操作语法未定先铺内容**：手势与镜头还在反复改，皮肤、主题、活动已先行，全部推倒重来；先冻结操作与速度曲线，再量产内容。
2. **纯随机撒障碍**：不可读、甚至不可解的序列会准确摧毁信任；生成单位必须是手工设计、标注过难度的片段（§3.2）。
3. **难度只靠提速**：速度封顶后游戏瞬间平淡；速度与组合复杂度要双轴爬升（§3.2）。
4. **盲区惊喜与死路组合**：生成器不验证可解性与可读性，玩家的死亡从「我菜」变成「游戏坏」，差评与流失都从这里来。
5. **视觉与判定分裂**：换道插值到一半被判死、滑铲动作比判定短；判定从宽且与视觉同向（§3.3、§4）。
6. **速度感单点堆料**：只拉大视场角或只加抖动，玩家晕、画面脏，速度感依然不到；速度感是合奏（§3.3）。
7. **广告打断奔跑**：局中插屏是卸载按钮；激励视频只在玩家主动选择时出现（§3.4）。
8. **复活处理粗糙**：不清理面前障碍、不给安全距离，续命变成二次伤害；复活过的成绩与干净成绩混排，排行榜失去公信力（§3.4）。
9. **皮肤无差别、角色有强度**：换色皮肤没有收集欲，带强度的角色让付费等于作弊；两侧都要按纪律做（§3.5）。

无尽跑酷看起来在卖速度与金币，实际卖的是「差一点就破纪录」：只要死亡足够便宜、成绩足够诚实，下一局永远值得再跑。
