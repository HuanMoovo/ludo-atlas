## 1. 定位与核心循环

换装时尚（中文市场常直呼「换装游戏」）是女性向市场的支柱品类之一：从网页与早期手游的换装玩法起步，暖暖系列（2013 年起的《暖暖环游世界》《奇迹暖暖》《闪耀暖暖》）把「收集服装、搭配过关」做成移动端头部；掌机一侧有《时尚造物主》一路的服装店与选品玩法，生活模拟里的穿搭系统则是同源的表亲。会穿衣就会玩，几乎没有前置门槛。

一句话定位：换装时尚是**把「搭配」做成第一乐趣**的类型。玩家用服装当词汇、用搭配当句子，回答一个又一个「这个场合穿什么」的问题；评分系统负责判卷，衣橱负责供给词汇量。成败系于两件事：评分要能解释（§3.1），单品要能源源不断到手（§3.2、§3.5）；任何一环拖住，玩家就会从「想再配一套」变成「去查攻略」。

核心循环用动词环写：

`读题（场合与风格） → 浏览衣橱 → 挑选与搭配 → 提交评分 → 按反馈改一件再试 → 领取奖励与新单品`

三个尺度的循环都要有结算点：一次搭配以分钟计，提交即出分；一个章节以小时计，由连续关卡加剧情推进结算；一个赛季与图鉴以周月计，靠收集、评选与赛季结算收尾。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 生活模拟 | 那类的穿搭是自我表达的一部分，没有评分与关卡；换装时尚的每次搭配都要过一套判卷系统 |
| 恋爱模拟 | 那类的主循环是关系推进，服装只是影响好感的道具；换装时尚把服装本身做成主菜 |
| 模拟经营 | 服装店经营管进货、定价与客流；换装时尚管「这套对上题没有」，经营顶多当配菜 |
| 收集养成 | 那类的收集是图鉴完成度本身；换装时尚的每件单品必须能穿、能评、能展示，收集是手段不是终点 |

一个自检问题：把服装换成家具、宠物或武器，玩法还成立吗？答案若为「照样成立」，你要做的可能是收集经营；答案若为「不成立」，你做的就是换装时尚。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **表达的兑现**：先满足「像我想的那样」，再满足「分数高」；玩家配完会自己多看两眼，这个瞬间是全品类的核心吸引力。
2. **评判的可解释**：得分高低要能追溯到具体原因（风格不符、缺件、搭配完整度），照反馈改一件就能看到分数变化，评分才不是彩票。
3. **衣橱的成长**：收集的痒来自「还差一件」，也来自「新到的手能配出新的解」；免费路径的供给节奏决定长期留存。
4. **展示的舞台**：搭配要被看见，相册、评选与互评给表达一个尾声；没有展示，收集动力减半。
5. **故事的牵引**：场合与动机来自剧情（面试、晚宴、舞台），评分标准才有意义，关卡才不只是刷分。

标杆作品（建议亲手玩过再拆，重点看评分反馈怎么解释、卡关时玩家怎么办）：

| 作品 | 可学的点 |
| --- | --- |
| 闪耀暖暖 | 3D 换装的工程与演出规格；套装即叙事单元；评选与赛季的长期结构 |
| 奇迹暖暖 | 2D 换装关卡的评分体系与章节推进；轻量文本加高密度服装更新 |
| 时尚造物主（Style Savvy） | 把「读懂顾客需求」做成核心玩法：选品、匹配与展示的小闭环 |
| 模拟人生 4 | 穿搭作为自我表达的证明：没有关卡评分也能成立，展示与分享可独立驱动 |
| 集合啦！动物森友会 | 服装设计与分享的轻量样板：自定义图案与互赠的闭环 |

## 3. 设计要点

### 3.1 搭配评分机制

评分系统要同时干两件事：判对错，教方法。结构从三笔账开始：

`总分 = 基础分（稀有度） + 契合分（标签乘权重） + 组合加成（套装与系列）`

- 基础分按稀有度给一层底盘，负责「拥有」的回报；
- 契合分是主账：单品带 2-4 个风格标签与数值（全库 6-10 个主风格），关卡给一套权重，两者乘加；
- 组合加成奖励「配完整」：成套、同色系、同系列轻量给分，鼓励配一套而不是堆一件。

设计纪律：契合分要占总分的六到八成，保证「对的低星」稳赢「贵的乱搭」；做不到，评分就退化成战力比较，免费玩家全程挫败（§3.5）。

关卡出题的四件套：场合（用剧情语言写清场景，如「同学聚会，舒服又体面」）、权重（主辅风格倍率，如简约 ×3、清新 ×1.5、华丽 ×0.5）、阈值（过关 / 优秀 / 完美三档）、反馈（分数之外的解释，如「缺一件干净的上装」）。

三条验收标准：

1. **反馈说人话**：「面试要端庄，这身太随意」胜过「优雅值不足」；数值派能对着门槛做最优解，直觉派能凭读题猜对方向。
2. **没有万金油**：用脚本对全部关卡扫描衣橱，任意两关的最高分配置重合单品应控制在两三件以内；出现一套通吃，就调权重或轮换主题。
3. **门槛按免费可得衣橱校准**：过关线用免费路径的最优解倒推，留一到两成余量；付费买更快更全，不买「唯一解」（§3.5）。

### 3.2 衣橱内容与美术

衣橱先划槽位再谈产量：头部（发型、妆容、头饰、耳饰）、躯干（上装、下装、连衣裙、外套）、四肢（袜子、鞋、手饰、手持物）、氛围（背景、特效、站姿）；起步做 8-10 个核心槽位，再按产能加，槽位越细组合越多、成本越高。

2D 与 3D 两条路线的账：

| 路线 | 单件内容 | 成本量级 | 代价 |
| --- | --- | --- | --- |
| 2D 差分 | 每件按统一姿态画成图层，共用身体底图 | 半天到两天一件 | 动作与镜头自由度低，姿势一换全套重画 |
| 3D 模型 | 建模、打版、材质、骨骼适配 | 数天到两周一件 | 成本最高，多层布料的穿模是长期维护债 |
| 混合 | 主体走一层路线，演出与特效另做分层 | 介于两者之间 | 规格要尽早冻结，否则两头返工 |

生产纪律（流程与外包管理见《美术与音频手册》（⑪））：

- **新衣要能和旧衣搭**：新单品进流程时就带混搭抽检（与在库单品的组合矩阵抽样），只能成套穿的孤品等于白做。
- **系列化交付**：每个版本或章节围绕一个主题系列成批生产，风格统一、文案成套，外包验收有参考包与样张（⑪）。
- **别漏副产物**：图标、图鉴卡、缩略图、获取文案、试穿数据，每件单品都有这一整套，漏算就返工。
- **先立服装篇的 Art Bible**：时代、廓形、配色、材质、题材边界写清楚，否则外包合起来像素材拼盘（⑪）。

### 3.3 与叙事的结合

时尚题材自带剧本：设计师成长、名模之路、复兴家族品牌、比赛晋级，都适合「一场一个场合」的章节结构；流程固定为：

`剧情引入 → 1 到 3 个搭配关卡 → 剧情反馈（关系推进与奖励）→ 新单品与新钩子`

- **关卡动机由剧情给**：「明天要面试」比「第五关」更能让玩家理解评分标准，场合描述直接影响读题方式。
- **评分标准与剧情要求必须一致**：剧情说要「素雅低调」，评分就不能给华丽高分，这是叙事与玩法互相拆台的最高发点（§7）。
- **服装可以当关系道具**：帮好友救场、给搭档挑衣服的事件，把衣橱接进社交与感情线（恋爱线按对应类型手册的口径做）。
- **文本与演出单独算账**：对白、分支、立绘差分与语音都是叠加成本，按视觉小说的量级先估再写（估算方法见《制作管理手册》（⑫））。
- **长线连载**：剧情按版本连载，章节主题与套装主题对齐；一批衣服讲一段故事，故事再给下一批衣服做预告。

### 3.4 社交与展示

展示分四层：自己看（相册、拍照模式，一键出图带卡框与水印）；互评（主题评选、两两投票，匿名、限次、同档匹配）；比（榜单与赛季，奖励分档但不羞辱落选）；一起玩（好友借衣、协作活动与小游戏）。

- **回报要轻**：参与奖保底、排名只分档，让低分搭配也被善意对待，表达欲才不会变成社交压力。
- **公平感靠机制**：匿名投稿、防刷票（投票限次加服务端结算）、同档位匹配，新手不跟满衣橱的老玩家同台。
- **UGC 先圈范围**：自定义染色、图案与贴纸先行，自由绘制放后期；设计与命名会引入审核、版权与未成年人保护问题（⑦）。
- **分享即增长**：分享图带水印与活动标签，是这个品类最便宜的自然流量；构图模板做进拍照模式，别指望玩家自己裁。

### 3.5 变现结构与合规边界

变现由四层构成（运营节奏与投放见《运营与增长手册》（⑬）），只给结构，数值按自己的留存与卡点校准：

- **直购**：单件、套装与礼包明码标价，是换装品类的口碑基本盘；
- **月卡与通行证**：每日资源加衣柜特权，负责稳定流水与日常回访；
- **限定抽取**：赛季主题套装按概率抽取，与抽卡养成的卡池同构：概率公示、保底与抽取记录沿用同一套口径（⑦、⑬），本页不重复展开；
- **体力与门票**：关卡消耗与恢复节奏，调节内容消耗速度，参数先定再定产出。

红线一条：主线过关阈值必须用免费可得衣橱校准（§3.1），付费买「更多选择与更快节奏」，不买「唯一解」；付费独占单品若是唯一解，评分系统就成了收费站（§7）。

合规边界，立项就过一遍（各自展开见⑦与《全平台上架手册》（⑧））：概率抽取的公示、保底与记录；未成年人消费限额、实名与时长管控；宣传用语不得使用绝对化用语，颜值、原创性一类宣称要有依据；现实品牌标识、明星肖像、时装摄影都可能是权利客体，美术参考不等于可用素材；UGC 内容要过审，未成年人保护措施同步做。

账本纪律：单件定价乘内容量先算一遍，确认「卖得回来」再开产线；这套账与运营指标的口径按⑬。

## 4. 技术要点

工程难点集中在三处：换装渲染、数据与评分可测、衣橱检索与存档；通用架构见《技术实现手册》（⑩）。

**换装渲染**

- 2D 路线：锚点与层序要立规范（每个槽位的贴图基准点写进资产规格，外套压下摆一类的显示顺序进表），组合错位是 2D 换装最常见的事故；换色用调色板与着色器，不重画。预览要秒开：缩略图与图集预处理，别在运行时现场渲染全套。
- 3D 路线：蒙皮与布料模拟、多体型适配、移动端的布料开关；穿模检测做成工具（包围盒抽查加关键组合的目检矩阵），修一件坏三件是常态，检测流程比事后补丁值钱。

**数据驱动与评分可测**

- 一件单品一行：部位、标签向量、稀有度、来源、图标、图鉴文案、上线状态；一个关卡一行：权重、阈值、文案、奖励；代码只读表，公式与表分家（⑩）。已卖出的资产不能删，下架只影响获取入口。
- 批量评分脚本是核心工具：全关卡乘全衣橱搜索，产出每关的最优解与分布，每次上新重跑，防止新件破坏旧关卡（§3.1）；单测覆盖空槽位、重复件、极端权重与压线阈值。

**衣橱 UX 与存档**

- 千件规模的检索体验就是留存：按部位与标签筛选、按颜色与新到排序、收藏夹、套装预设、「按当前关卡权重生成草稿」的一键搭配。
- 存档字段：拥有、收藏、预设、关卡进度、赛季数据全量序列化，带版本号与迁移函数；运营型追加购买与抽取的服务端记录、评选的服务端结算与出图渲染规格。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺。

| 项目形态 | 服装量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 机制原型 | 30-60 件占位单品 | 2-4 周 | 色块代替美术，只验证评分与循环 |
| 小型完整作品 | 200-400 件，按章节配关卡 | 6-12 个月 | 美术占大头，剧情同步产出 |
| 移动端长线产品 | 上线 600 件起，每个版本 60-120 件 | 1 年起，持续投入 | 产能与运营节奏绑死 |
| 3D 高规格产品 | 总量数千件 | 团队多年 | 服装与演出是成本主体 |

单件成本与量级结论（粗口径，按自己实测校准）：2D 差分半天到两天一件（画、拆层、试穿、图标）；3D 单品数天到两周一件（建模、材质、骨骼适配、混搭穿模测试）；一个搭配关卡（权重、文案、阈值、扫描验证）半天到两天；一个剧情章节（5-10 关加对白与演出）数周。服装资产通常是全项目美术预算的大头（常见口径是过半，流程见⑪），先算产能（每月每人出几件）再定内容计划与更新承诺；产能对不上消耗是这个品类的主事故，玩家一周能玩掉一个月的产出；压缩优先级从高到低为服装复用（同款换色、同模改版）＞减少演出规格＞减少剧情分支＞缩图鉴，服装是主菜，动刀放在末位。

## 6. 第一个原型怎么起步

目标：2-4 周回答一个问题：选衣服得分这个循环，能不能让人主动再配一套；全程色块占位，不画美术。

1. **第 1 周：服装骨架**。8-10 个槽位、30-60 件占位单品（色块加标签加数值），一个获取入口（过关奖励或商店）让新衣能到手。
2. **第 2 周：评分与关卡**。一个评分公式（基础分加契合分）、5-8 个关卡（各带权重与三档阈值）、可解释的反馈文案；同步写一个扫描脚本，检查每关最优解不是同一套。
3. **第 3 周：循环闭合与剧情壳**。获取到搭配到评分到奖励再获取；给首章加 3-5 屏对白把「场合」讲明白，观察玩家是否读题。
4. **第 4 周：试玩与调参**。找 5 个没玩过的人，只记录不提示：他们读不读题、能否解释得分、失败后是否主动换一件再战；记录「卡关即弃」的位置。

成功标准（全部可观察）：

- 测试者能用自己的话解释得分原因（「这场要优雅，我穿得太随意」），而不是「不知道为啥」。
- 拿掉美术与音效，测试者愿意为了下一件衣服反复过关，单次 30 分钟以上。
- 任意两关的最优配置不同，且能在 10 分钟内用扫描脚本验证。
- 5 名测试者中至少 3 人在失败后主动调整搭配再战，并能说出调整理由。

原型期不做：3D、布料、社交系统、抽卡、真实货币、多语言；先验证「搭配是不是好玩」，再做上线工程。

## 7. 常见坑

1. **评分不可解释**：玩家不知道分差在哪，玩法退化成查攻略。规避：反馈具体到标签与单品，用场合语言（§3.1）。
2. **单一最优解**：一套万金油通吃全部关卡，收集与搭配同时失去意义。规避：权重轮换加解空间扫描（§3.1）。
3. **稀有度压死搭配**：高星单品数值碾压，评分变成战力比较，免费玩家挫败。规避：契合分占大头，阈值按免费衣橱校准（§3.1、§3.5）。
4. **衣橱检索失控**：千件之后找不到衣服。规避：筛选、收藏、一键草稿（§4）。
5. **服装产能塌方**：更新跟不上消耗，承诺的套装断供。规避：产能先算再定承诺，复用与换色摊薄成本（§5）。
6. **只有衣服没有舞台**：不配关卡、剧情与展示，衣服做出来没处用。规避：每批服装配一批用途，上新即活动（§3.3、§3.4）。
7. **穿模与适配债**：3D 服装层数一多就穿模。规避：检测工具与组合矩阵抽检进流程（§4）。
8. **付费墙挡路**：主线唯一解只能买。规避：免费路径可通关是红线，付费卖选择与节奏（§3.5）。
9. **抽取口径与社交压力**：概率保底不公示、低分被公开处刑，都会把好感玩家推走。规避：与卡池同一套公示规则（⑦）；分档奖励、匿名互评、参与即有奖（§3.4）。

## 延伸阅读

- 《游戏设计手册》（⑨）：核心循环、数值表与反馈设计，第 1 节与第 3.1 节的底稿。
- 《美术与音频手册》（⑪）：服装资产规格、外包管理与风格验收，第 3.2、5 节的完整展开。
- 《运营与增长手册》（⑬）：赛季、活动与变现节奏，第 3.5 节的配套；概率公示口径见《法务、专利与竞争手册》（⑦）；内容类坑位与第 7 节的对照见《避坑大全》（⑥）。
- 《类型手册 · 恋爱模拟》与《类型手册 · 生活模拟》：相邻类型的边界与合流处，立项前先读。
- 玩而不是读：把闪耀暖暖或奇迹暖暖打通一章，记录评分反馈怎么解释、卡关时你的第一反应；再体会《时尚造物主》里「读懂顾客」怎么做成玩法。
- 作业：用纸面表格搭一版评分模型（10 件单品乘 6 个标签乘 3 个关卡），手算每关最优搭配，检查会不会同一套通吃；若是，先改权重再写代码。
