## 1. 定位与核心循环

一句话定位：三消是**以交换与连锁为第一乐趣**的网格类型。规则两句话讲完，深度全在盘面；随机负责提供素材，玩家的每一次选择决定素材被利用的效率。

核心循环用动词环写：

`读盘 → 找可行交换 → 交换 → 判定与连锁 → 掉落补位 → 再读盘`

这个环以秒计：一次有效操作一到三秒，连锁结算再加一到两秒。它成立的前提只有两条：规则一眼看懂（§3.1）；每一步的后果可被理解，连锁来自规则，不来自玄学。

三个尺度的循环：

| 尺度 | 循环 | 玩家得到什么 |
| --- | --- | --- |
| 一次操作（1 到 5 秒） | 读盘 → 交换 → 结算与连锁 | 一次即时的正反馈，或一次能看懂的回弹 |
| 一关（1 到 5 分钟） | 在预算内完成目标，争取星级 | 过关的确信，或「差一点」的重试冲动 |
| 一段关卡（数天至数周） | 新机制登场 → 变奏 → 综合考核 | 棋盘语言不断更新，有持续回来的理由 |

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 解谜 | 解谜的解靠推理导出、结果确定；三消的局面随掉落变化，玩家做的是约束下的最优决策，成功路径不止一条 |
| 俄罗斯方块 | 方块的落点由玩家选定，考验落放与速度；三消的补位交给系统，考验的是「选哪一次交换」 |
| 卡牌构筑 | 构筑在局内成长、以牌库为内容；三消的局内不成长，内容在关卡与障碍上 |
| 放置增量 | 放置把操作省掉、把进度交给时间；三消的每一分进度都要亲手换出来 |

一个自检问题：把连锁与掉落拿掉，只留两两交换的定点消除，游戏还成立吗？答案若为「不成立」，你做的才是三消；这个类型的乐趣有一半来自一只手引出的连串反应。

团队口径：内容型玩法，工程集中在棋盘与关卡工具上；美术是包装，关卡是本体；不依赖联网。真正的工作量在关卡设计与调优，稀缺能力是能把「随机感」调成「公平感」、并且稳定产关的人。一句话结论：三消卖的不是规则，是关卡密度与反馈爽感。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **一眼读懂**：棋盘状态、目标进度、可行动作，扫一眼就能看懂；看不清的棋盘等于事故现场。
2. **操作省力、反馈丰厚**：单次操作是一两秒的滑动，回报是成片的消除与连锁；操作成本与反馈量之间的落差，就是爽感来源。
3. **计划感**：高手能规划连锁路线，新手乱点也有收益；水平差异体现在「能看到几步」，不体现在手速上。
4. **差一点的张力**：结算时差一两个目标收尾，才会产生再来一次的冲动；差距要靠进度条与结算面板讲清楚。
5. **低压重试与稳定新鲜**：失败重开便宜、原因可归；新机制按节奏登场，长期玩不重样。

反面感受（出现任意一条都是红灯）：操作失灵（滑了没反应、回弹看不懂）；被系统坑（死盘、目标不可达）；被遮挡（特效盖住棋盘）；被重复消磨（只堆数量不换花样）。

标杆作品（均为大众熟知的作品，建议亲手玩过再拆）：

| 作品 | 可学的点 |
| --- | --- |
| 宝石迷阵（Bejeweled） | 类型的原点：交换判定、连锁与特效反馈的基准；限时与放松两种节奏的分野 |
| 开心消消乐 | 关卡制的大众化样本：步数制、目标与障碍的关卡语言、低门槛的日常节奏 |
| 糖果传奇（Candy Crush Saga） | 长线关卡序列：目标类型轮换、难度起伏的排布、地图推进的仪式感 |
| 梦幻花园 | 三消底盘加长线目标：消除产出资源，装修与剧情提供回来的理由 |
| 天天爱消除 | 手机端短关形态：单局目标清晰、节奏轻快、随开随玩 |

## 3. 设计要点

### 3.1 基础规则与手感：交换、连锁、特效

规则骨架两句话：交换相邻两枚，凑成三枚及以上即消除；上方补位后再判定，直到棋盘稳定。两句话讲不清的规则组合，先别进原型。

交换的输入方式，移动端以滑动手感为第一优先级：

| 输入方式 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| 拖动滑动 | 按住格子向相邻方向滑 | 跟手，移动端主流 | 快速连滑容易丢输入 |
| 点选两次 | 点起点再点相邻格 | 精准，误触少 | 多一次点击，节奏偏慢 |
| 光标加方向键 | 选中格后用方向键移动 | 桌面与手柄可用 | 触屏不可用，要做两套映射 |

- 判定与节奏纪律：不成立的交换要回弹，回弹尽快结束（常见目标 200ms 以内），判定先走逻辑层，动画跟着逻辑走；连锁（玩家口中的连击）按固定节拍推进，一次结算链（消除 → 掉落 → 再消除）的常见拍点是 0.15 到 0.35 秒，每升一级连锁，特效与音高升一级，具体秒数以逐帧调参为准。
- 特殊块：四消、五消一般生成方向消除、爆炸与同色清除类块；特殊块互换触发的组合效果是深度的重要来源，规则要能一句话讲清，第一次触发要一眼看懂。
- 反馈三件套：粒子闪光、连锁音阶上行、大消除的短顿帧与震动，三者落在同一拍点上；少任何一件，连锁都会发飘。
- 闲置提示：数秒无操作时给一个「哪里还能动」的轻提示，只指方向，不代操作。

手感验收：找 5 个人各玩 5 分钟，记录「滑了没反应」与「回弹看不懂」的次数，两者都该接近零；回弹时长、连锁节拍、特效时长全部进数值表，用录屏调。

### 3.2 关卡数值骨架：预算、目标、障碍

一关的数值可以压缩成一句话：给定棋盘与障碍，在预算内达成目标。三根柱子分别是预算（步数或时间）、目标、障碍。

- 步数预算的推导：先用模拟（§4）测出单步平均产出，再乘容错系数（常见 1.2 到 1.5，即留两成到五成余量），人工试玩校准。拍脑袋填数字，是难度失控的头号来源。
- 目标类型：收集（凑齐 N 个指定元素）、清除（清掉全部目标格）、运输（把物件送到底行）、冲分（限时或限步得分）。可以两两叠加，三种叠加要谨慎。

| 目标 | 玩法动作 | 设计要点 |
| --- | --- | --- |
| 收集 | 消掉 N 个指定元素 | 最基础的骨架；数量与棋盘颜色数共同决定难度 |
| 清除 | 清掉全部目标格（果冻、泥土类） | 位置固定，考验覆盖路径与顺序 |
| 运输 | 让物件穿盘落到底行 | 与障碍、掉落路径博弈，教学成本最高 |
| 冲分 | 限时或限步内得分达标 | 天然支持重玩与轻排行，适合放松关 |

障碍按行为分四类，一类一类加，不并行：

| 障碍 | 行为 | 教学要点 |
| --- | --- | --- |
| 挡路（冰、锁链类） | 占住格子或元素，需相邻消除解除 | 先教「消它旁边那一枚」 |
| 吸收（果冻、藤蔓类） | 命中多次才清除，状态要可视 | 教「还差几下」的可视读法 |
| 扩张（毒液、岩浆类） | 自行蔓延，制造时间压力 | 必须有蔓延上限与减速阀 |
| 地形（墙、洞、传送类） | 改变连通与掉落路径 | 先立好地图语法，再谈数值 |

- 难度旋钮就六七个：预算余量、目标数量、棋盘大小与形状、颜色数（常见五到六种）、障碍种类与数量、掉落权重。一次只动一到两个，动多了就分不清难度来自哪。
- 每关一条数据：编号、目标、预算、棋盘布局、颜色数、障碍清单、掉落参数、预期评级；实测数据（通过率、平均剩余步数）回填同一张表。星级门槛用剩余步数或分数划两三档，让重复挑战有第二层目标，门槛值同样从模拟数据里取；表的管理方法见《制作管理手册》（⑫）。

### 3.3 难度阶梯与心理曲线

三消的难度不是一条爬坡线，而是一段锯齿：几关顺畅、一关吃紧、再回一口气。设计工作是给这段锯齿排布高峰与低谷的位置。

- 大结构：教学段（几乎不失败）→ 节奏段（锯齿交替）→ 里程碑（新机制或新障碍登场）→ 检定关（旧机制组合考核）→ 呼吸关，如此循环推进；一次只放一个新东西登场，组合只出现在分项都学过之后。压力峰值的三个天然位置是机制考核点、里程碑关与章节收尾关，峰值关前后各留一关呼吸位，连续两个高压关，挫败感翻倍。
- 「差一点」是工程不是玄学：结算面板要精确告诉玩家差多少（还差几只、几步之内有希望）；差一点产生动力，差太多产生放弃，你要校准的就是这两者之间的区间。
- 三层反馈的节奏要分开：操作层（每次消除的粒子与音效）、关卡层（进度条与星级）、序列层（新机制与新章节的解锁感）；任何一层给得过密，都会麻木。
- 付费点的位置设计：长线产品里，玩家最想求助的位置（加步数、重试、道具）与难度峰值天然重合；这些位置放在哪、间隔多长，属于难度曲线的排布问题；位置对了，玩家得到的是「还能救一下」的余地。本文只谈位置怎么排，不展开变现方式。
- 自测问题：把最近连续二十关的首次通过率排成一行看形状，接近一条直线，说明你排的是关卡序列，不是曲线。

### 3.4 关卡量产流水线：编辑器与测试工具

三消是内容型类型，产关速度决定项目生死。流水线的标准只有一条：策划不改代码，就能建关、测试、调数。

- 关卡即数据：一关一行记录（§3.2），代码只做解释器；任何写进代码的关卡参数，都是给未来埋的一次返工。
- 编辑器验收标准：策划 30 秒内摆出一关新棋盘并一键热重载进实机；预览界面能直接叠出目标、障碍与掉落走向。
- 批量校验器：字段完整性与引用合法性；再配合 §4 的无解检测，对全库关卡跑种子化模拟，统计达成率与平均步数，偏差过大的关自动进复查队列。
- 无头模拟器：把棋盘逻辑做成不依赖动画的独立模块，就能批量自我对局；用简单策略（贪心消目标）跑几千局，得到每关的通过率画像，同时服务难度分级、回归测试与平衡调整三个用途。
- 回归纪律：改动机制、掉落或障碍之后，全库模拟回归一遍再往下走；跳过这一步，等于把一百关的命运押在运气上。

### 3.5 棋盘可读性与表现预算

- 颜色数量克制在六种上下，色相区分要经得起小屏幕与户外光，同时给色觉障碍留一条非颜色线索（形状或纹理）；特殊块与障碍要有剪影级差异，状态变化（被消过一次的果冻类）要一眼读得出「还差几下」。
- 特效预算：一次大连锁的粒子与音效并发要有上限；表现层的任务是放大反馈，不是遮住棋盘。所有动画都要能加速或跳过，跳过不影响结算结果。

## 4. 技术要点

工程难点集中在棋盘逻辑与工具链上，渲染是相对不重要的部分；以下与引擎无关。

**棋盘、生成与随机**

- 数据结构：二维网格，每格记录元素类型与状态（普通、特殊块、障碍、目标格）；棋盘大小常见 7×7 到 9×9。
- 开局生成四条约束：不出现现成三连；至少存在一条可行交换；颜色分布符合关卡配置；目标物件与特殊块的产出口可达。任何一条不满足就重摇，不放行。
- 掉落与补位：从顶部补齐、按列下坠；一次把整列的下坠顺序算清楚，避免逐格下坠造成的排序错误。
- 随机与可复现：每关一个随机种子，开局与掉落序列由种子决定，同种子必须复现，测试、模拟与回放共用同一套随机实现；掉落权重（颜色分布、目标物出率）进关卡配置，禁止散落成代码里的魔法数字。

**交换判定与连锁结算**

- 合法性判定只看受影响的行与列：虚拟执行交换后，检查涉及的两格所在横竖线是否成三，不做全盘重扫。
- 连锁结算用循环队列：消除标记 → 计分 → 掉落 → 补位 → 再判定，直到棋盘稳定；特殊块的链式触发进同一个队列，顺序才可预期。逻辑层先产出完整结算序列（结算剧本），表现层按序播放；加速与跳过只改播放速度，不改逻辑结果，这条纪律同时养活模拟器与回放。

**无解检测与重排（必做工程）**

- 判定方法：遍历每个格子与右侧、下方邻居，虚拟交换后检查是否成三；全部落空即为无解死盘。全盘遍历是小账，别省。
- 触发时机：每次结算稳定后检测；开局生成后同样要检测。
- 洗牌与重排：保留特殊块与障碍状态，重洗普通元素；重洗结果必须同时满足「无现成三连」与「至少一条可行交换」，不满足就再洗，并给玩家一段可见的「棋盘重排」提示动画；连续失败要有兜底策略与日志。
- 频率观察：洗牌频繁，说明掉落权重或障碍布局有问题，先回头查关卡数据，而不是调高洗牌门槛。

**表现与性能**

- 输入与性能：滑动按角度分桶并做起点格吸附，处理断触（滑到一半抬手）与快速连续操作，不丢指令；粒子、飘字、音效通道、震动通道全部设对象池与并发上限，连锁越长，越要克制单拍的特效数量。
- 埋点：每关尝试次数、平均剩余步数、失败点位、退出点位；原型期用本地日志即可，它是难度曲线唯一的复盘原料。

## 5. 内容量与工作量参考

以下为常见量级，用于估算范围，不构成承诺。

| 形态 | 关卡量级 | 周期量级 | 备注 |
| --- | --- | --- | --- |
| 原型 | 10 到 30 关 | 2 到 6 周 | 三种目标、两种障碍，只验证循环与难度 |
| 小型完整作品 | 100 到 300 关 | 3 到 9 个月 | 一套机制语言做深，含编辑器与模拟器 |
| 长线关卡产品 | 500 关起、持续补关 | 持续投入 | 内容产线是长期账单，按包排产 |

换算与纪律：

- 单关工时：设计、模拟、试玩、调优合起来常见半天到两天，后期返修多在上架测试之后；一个新机制的产出门槛是至少撑得起 15 到 30 关的变奏与组合，撑不到就不要加。
- 美术是模板活：棋盘与元素一套材质、一套特效图集、一套 UI 框架可以撑全库；成本的大头永远在关卡与调优上。
- 范围纪律：砍关永远比救关便宜；一千关的平直线，不如三百关的好曲线。

## 6. 第一个原型怎么起步

目标：两周内回答一个问题：这个交换、连锁、结算的循环，烦不烦。不碰美术、存档与排行榜。

1. **第 1 到 3 天：网格与交换。** 7×7 或 8×8、五到六种颜色；交换、回弹、成三判定、掉落补位与连锁结算。丑是应该的。
2. **第 4 到 6 天：无解检测与洗牌。** 这条在原型期就要做完整；晚做会把死盘当设计常态，坏习惯一路带进正式关卡。
3. **第 7 到 10 天：三种目标、两种障碍、最简预算。** 收集、清除、运输各来一关；预算按「单步平均产出乘容错系数」（§3.2）估算，调一遍。
4. **第 11 到 14 天：盲测。** 找 3 到 5 个人各打 10 关；记录每关通过率、平均剩余步数、重试意愿与「哪里看不懂」。

成功标准（全部可观察）：

- 测试者不需要口头指导，30 秒内自己发起第一次交换。
- 「滑了没反应」与「死盘了」这两类抱怨一次都不出现。
- 教学段通过率明显高于挑战段，曲线的锯齿已经成形。
- 过半测试者主动要求继续打下一关。

原型通过之后，先把关卡数据外部化（一关一行），再谈编辑器与内容量产；顺序反了，产能会被代码锁死。

## 7. 常见坑

1. **无解检测缺位或只做半套**：洗牌后仍是无解，或把死盘直接留给玩家；检测与洗牌都是必做项（§4）。
2. **交换判定不跟手**：滑动丢输入、斜滑方向分不清、回弹太慢；手感验收过不了，后面都是空中楼阁。
3. **结算不可打断**：长连锁无法加速或跳过，玩家被迫看表演；跳过又破坏状态同步（§4 结算剧本）。
4. **难度靠调大目标数**：目标加码、预算不动，挑战变成刁难；该调的是余量与布局。
5. **生成与可达性没管住**：一开局就有现成三连、颜色失衡，或障碍与掉落权重让目标物不可达；生成四条约束（§4）与全库模拟（§3.4）都要在早期就位。
6. **机制叠加过载**：障碍全往一张盘里挤、新机制没有教学关；一次只教一个新东西。
7. **难度曲线是直线**：全平让人腻，全陡让人走；锯齿才是可玩的形状（§3.3）。
8. **特效盖过信息**：粒子遮盘、连锁音效互盖、顿帧过密；表现是放大器，不是主角（§3.5）。
9. **拍脑袋排期**：按「一天十关」排内容量，结果全卡在调优与返修上（§5）。
10. **埋点缺失**：没有每关通过率与剩余步数数据，曲线没法复盘，调优变成玄学（§4）。
11. **编辑器缺席**：策划改关要等程序员，产能从第一天就被锁死；把编辑器排进第一批里程碑。

## 延伸阅读

- 《游戏设计手册》（⑨）：核心循环、奖励心理与难度曲线方法，第 1、3 节的底稿。
- 《技术实现手册》（⑩）：数据结构、随机实现与工具链纪律，对应第 4 节。
- 《制作管理手册》（⑫）：内容量估算与排期口径，与第 5 节对照使用。
- 《独立开发生存手册》（⑱）：范围控制与持续内容账，决定你铺多少关、用什么节奏补。
- 《解谜》（P0 批次）：姊妹页；教学三段式与防挫败的通用纪律以它为准，本文只写三消专属的棋盘、随机与量产工程。
