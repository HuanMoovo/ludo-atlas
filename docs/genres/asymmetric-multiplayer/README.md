# Ludo Atlas · 类型手册 · 非对称对抗（Asymmetric Multiplayer）

> **类型手册 · 第四辑**。定位：把「双方规则不同」做成核心卖点的多人对抗类型。人数、能力、信息与胜利条件至少有一条不对等；1v4 是主流结构，平衡与匹配是这个类型的两本长期账。
> 配套：《游戏设计手册》（核心循环与数值）·《技术实现手册》（架构与网络）·《联机与后端深入手册》（匹配、反作弊与成本）·《电竞与竞技设计手册》（平衡与观战）。
> 本文不放外链；标杆只列大众熟知的作品，数字为常见量级，按自己项目的实测校准。

## 1. 定位与核心循环

一句话定位：非对称对抗是**把「双方规则不同」做成核心卖点**的多人对抗类型。人数、能力、信息与胜利条件至少有一条不对等，玩家选的不只是角色，而是整套玩法：强侧（少的一方）以少打多，弱侧（多的一方）靠协作与周旋翻盘。本页以 1v4 结构为主线展开，它是这个类型最主流也最成熟的形态。

家族位置：归在社交与多人对抗的家族，骨架却是一套**不对等博弈**，与题材无关；把恐怖换成怪谈、把猎杀换成捉迷藏或竞速，结构不变。追逐与空间博弈的手感与动作类同源，短局房内循环的结构与派对类同源，信息设计又与潜行类共用一套语言。同一个「不对等」骨架也养活非对称合作（分工互补的解谜与冒险），本页只写对抗形态。

核心循环用动词环写（两方各一条）：弱侧 `分头推进目标 → 被察觉 → 周旋与救援 → 扛过追猎 → 完成终局条件 → 逃脱结算`；强侧 `巡场侦查 → 锁敌追击 → 打断进度 → 守点拦截 → 阻止逃脱 → 结算`。

环成立的前提两条：弱侧要有主动权（不是只在躲，而是在推自己的目标，§3.1）；双方都要能从过程里读出因果（谁为什么赢、输在哪一步，§3.2）。缺前者，弱侧沦为猎物；缺后者，输赢都像被系统安排。

与相邻类型划边界：

| 相邻类型 | 边界 |
| --- | --- |
| 对称竞技 | 对称竞技双方同一套规则与资源，胜负全部来自操作与决策；非对称对抗的差异从选阵营那一刻就成立，平衡的对象是两套不同的规则。 |
| 社交推理 | 社交推理两边力量相当，藏在暗处的是身份与意图；非对称对抗的力量与规则公开不对等，信息差异只是手段之一，比的是能力与周旋。 |
| 联机恐怖 | 联机恐怖是同一阵营对环境的合作体验，玩家之间没有对抗关系；非对称对抗的两个阵营互为对手，恐怖只是可选的外衣。 |
| 合作闯关 | 合作闯关全员同规则、共胜负；非对称对抗至少有一方按单独规则设计，且两方目标互斥。 |

与《类型手册 · 社交推理》的边界一句话：社交推理比的是「谁在说谎」，非对称对抗比的是「谁更会用自己这套规则」。与联机恐怖（多人合作恐怖）的边界一句话：联机恐怖里玩家一致对外，非对称对抗里玩家互为对手。

一个自检问题：把两方换成同一套能力、同一组目标，游戏还剩下什么？若剩下的是一个完整好玩的游戏，非对称这张牌就不要打；这个类型的全部增量，来自「两边玩的是两个游戏」这句话能不能立住。

## 2. 玩家体验目标与标杆作品

体验目标（按优先级排序）：

1. **换边就是换游戏**：同一张地图、同一套骨架，两个阵营的视角与压力完全不同；轮换阵营本身就是重玩动力。
2. **弱侧的协作与翻盘**：分工、救援、声东击西；「差点跑掉」和「全员救回来」是这个类型最贵的心跳。
3. **强侧的狩猎掌控**：侦查、读位、施压、收割；强侧的乐趣不是数值碾压，而是「我把四个人的动线读出来了」。
4. **过程可复述、输得明白**：追与逃天然生产故事，转角遇人、残局一换二，传播素材不用额外制造；结算能落到具体决策（该不该救、哪里被读、目标顺序错没错），而不是一句「对面太强」。

反模式（出现就停手修）：两边互相找不到、干等时间流走；强侧一穿四或弱侧从头遛到尾，整局没有任何悬念起伏。

标杆作品（建议亲手玩过再拆；两边的压力差异藏在手上，不在视频里）：

| 作品 | 拆什么 |
| --- | --- |
| 黎明杀机 | 1v4 结构的定义者：周旋资源的地图语言（板与窗）、双阵营的技能成长、联动角色的内容引擎。 |
| 第五人格 | 移动端与长线运营的完整样本：恐怖题材的风格化处理、双阵营角色池与赛季节奏、2v8 一类的变体模式。 |
| 猫和老鼠 | 卡通追逃改编的样本：把 1v4 搬进合家欢场景，弱化恐惧、放大操作与欢乐，证明这个骨架不依赖恐怖题材。 |
| 进化 | 4v1 猎杀结构的反例教材：内容与商业化节奏没跟上，人口流失后匹配崩坏；本类型最贵的是活着的匹配池。 |

共同点：骨架都是「1v4 加周旋」，差别在题材、平台与视角；能不能长线，取决于两件事，人口与平衡（§3.2、§3.4）。

## 3. 设计要点

### 3.1 非对称设计：以 1v4 为例

非对称不是「把一边数值调高」，拆开看是四条轴：人数、能力、信息、目标；1v4 是把四条轴同时拧过一遍的成熟组合。以它为例，双方的差异先摊在桌面上：

| 维度 | 强侧（1 人） | 弱侧（4 人） |
| --- | --- | --- |
| 人数 | 单点作战，随时一对多 | 数量优势，但常要分散行动 |
| 能力 | 手段集中：移动、攻击、控制都在一人身上 | 个体弱、工具化：每人一两件专用手段 |
| 信息 | 靠侦查获取：视野与感知是第一资源 | 共享进度与视野，但接触即暴露 |
| 目标 | 阻止弱侧完成条件，追与守并用 | 推进多目标并逃脱，救人还是做事时刻二选一 |
| 失误代价 | 一次失误丢节奏，但可以反复找机会 | 一人倒地拉全队下水，失误会滚雪球 |

- 差异要一眼可懂、一局可学：玩家进局五分钟内，能说出对方的强处与自己的解法；读不懂的不对等，只会被当成不公平。
- 每一方都要有自己的精通曲线与高光：强侧的高光是预判与收割，弱侧的高光是周旋与救人，不允许一方只是另一方的背景板；每次平衡实验只动一条轴，人数、能力、信息、目标一起动，任何读数都解释不了（§3.2）。

### 3.2 平衡：胜率与体验的双重指标

非对称的平衡是结构性难题：两边规则不同，不存在「各砍一半」的简单教条；它要同时服务两套指标，结果指标看胜负与节奏，体验指标看双方是否相信「有的打」。

| 指标 | 归类 | 读法 |
| --- | --- | --- |
| 弱侧逃脱率、强侧猎杀率 | 结果 | 不看单点，看区间（常见参考带：弱侧四到五成）；破带才触发干预。 |
| 碾压局与翻盘局占比 | 结果与体验 | 前者是失去悬念的局，后者是逆转发生的局；一个过高、一个过低，说明强度曲线或地图失衡。 |
| 单局时长分布 | 结果与体验 | 过短等于一边倒，过长等于僵持；按分位数看，不看平均。 |
| 分片读数 | 校准 | 换边意愿、退出与举报率，以及以上全部指标，都要按地图、角色与水平段位拆开看；总平均会藏住坏账。 |

调参纪律：

- 优先动机制、后动数值：地图周旋资源、目标进度速度、信息提示范围（心跳一类感知手段）都是更可控的旋钮，直接砍数值最容易砍掉手感；新角色与新地图上线等于重开一轮对位测试，成本提前算进排期（§5）。
- 两边体感都要采集：只看数据会做出「数字平衡、体感糟糕」的版本，出现两边都觉得自己在挨打的奇观。

### 3.3 地图与目标结构

地图同时服务两方：给弱侧周旋与推进的空间，给强侧侦查与施压的路径；目标结构决定一局的时间轴。三种常见骨架：

| 骨架 | 弱侧在做什么 | 强侧在做什么 | 说明 |
| --- | --- | --- | --- |
| 多目标推进型 | 分散推进多处目标，完成终局条件后逃脱 | 巡场打断进度，逐个击破 | 1v4 的主流写法；进度可见，制造「继续做事还是去救人」的取舍。 |
| 阶段推进型 | 按阶段完成任务链，每阶段换一次压力 | 按阶段改变守备重点 | 节奏接近线性关卡，适合叙事与教学。 |
| 争夺型 | 抢夺并保有点位或资源 | 反抢并驱赶 | 压力更连续，对地图布局与复活规则要求高。 |

- 弱侧的空间要「有得绕」：环形动线与周旋资源（板、窗、拐角一类的可交互物）是弱侧的生命线；每个资源要有代价与消耗，用一次少一次，否则弱侧可以无限绕圈。
- 强侧的空间要「有得读」：地标清晰、区域功能可辨（高价值区、过路区、死角），让侦查是判断而不是撞运气。
- 目标点要分散但可争夺，终局要留谈判空间：分散迫使弱侧分工，可争夺给强侧打断的机会；开门或终局目标阶段是张力顶点，给弱侧留翻盘窗口，也给强侧收割窗口，加时与拖时间的规则写死，不让「耗着」变成一种策略。

检查表：有没有绕不死的点、有没有必死的死角？从任意位置出发，弱侧有没有三条以上逃生路线？强侧能不能靠信息推导出「人大概在哪」，还是只能随机撞？每张图过一遍这三问。

### 3.4 匹配与冷启动：小众品类的人数账

一局 5 人、配比固定 1v4，这道算术决定整个类型的生死：两个阵营的在线配比只要偏离，就有一边在排队。非对称对抗比对称竞技更早撞上人口问题，因为它的队列天然是两组互相牵制的。

- **配比失衡**：偏好强侧的玩家过多，强侧排队；过少，四个弱侧等一个强侧。用角色券、任务引导这类激励把供需拉回配比，比放宽匹配质量有效得多。
- **冷启动的次序**：先服务一个地区的一个核心时段，再谈扩张；先把 5 人局凑出来，再谈第二种模式；模式、段位、地区每加一层分池，小人群就薄一层，第一版宁可单池排队，也不要每个模式都排不上。
- **好友房是入口，不是妥协**：「5 缺 1」的房间码天然带拉新；熟人局撑住早期人口，把房间码进人与分享做成核心路径。
- **机器人只进练习与新手区**：陪练可以，进真人对局一眼穿帮，还会把两边的博弈价值一起做废。

先把一道乘法做出来：目标排队时长、单局时长与每局人数相乘，反推需要的同时在线规模；这个数字比「首月买多少量」重要得多。再盯四组读数：按阵营分开的排队时长、队列取消率、首局完成率、两侧等待时间差；差异过大先用激励修，不要用放宽匹配质量来掩盖。

### 3.5 更新与角色池纪律

- 更新必须两边都照顾：只给强侧出角色，弱侧玩家会觉得产品已经放弃自己；一个版本里两边各给一点，是维持双人群的基本礼貌。
- 新角色的标准是改变打法，平衡债要记账：新强侧意味着「所有人的新对手」，新弱侧意味着「强侧的新题目」，纯数值加成的角色不产生新对局，只制造平衡债；每上线一个角色，与既有角色的对位关系全部复习一轮（§5）。商业化守线是外观、通行证、角色解锁都可以卖，对局信息与胜负资源不卖。

## 4. 技术要点

工程难点集中在三处：小规模高精度同步、信息隔离、对局完整性与数据工具。以下与引擎无关；同步与匹配的完整方法见《联机与后端深入手册》，架构与性能见《技术实现手册》。

**服务器权威与小规模同步**

- 1v4 是低人数高精度场景：专用服务器加服务端权威模拟，客户端只做输入采集与表现预测；追逐对延迟最敏感（擦身、翻越、攻击判定），把「打到了却不算」一类事故压到最低，是手感工程的第一条。
- 动作判定全部服务端裁定，攻击、技能、交互都是本地先给表现、服务器再纠正，修正要平滑到玩家看不出；小房间架构反而有利，实例人数少，单机成本低，也方便做逐局回放与日志。

**信息隔离：玩法地基与反作弊地基是同一件事**

- 服务器按玩家逐个裁量可见信息：强侧的客户端不持有尚未暴露的弱侧位置，弱侧的客户端不持有强侧的未来手段；一旦全量下发，「透视」外挂一夜间废掉全部悬念。
- 观战与直播要内置遮蔽：默认延迟加信息裁剪；观众视角泄露强侧位置，等于给弱侧全员报点，主播模式要进首发范围。

**断线、对局完整性与数据工具**

- 5 人局掉 1 人就是两成战力：重连要能回到原局，短暂断线的托管规则（AI 接替或减速保护）提前写死；强侧掉线的处置（中止还是判负）与申诉流程一起定。
- 挂机、消极比赛与恶意组队进信誉系统，证据（对局日志与回放）从第一天就留。
- 事件日志：击杀、逃生、技能、目标进度全部带时间戳落库；§3.2 的平衡读数全部从日志里算，靠手感回忆一定会偏。
- 开发者回放与上帝视角：复盘「这一局为什么一边倒」的效率，决定调平衡的速度；埋点口径见《技术实现手册》与《联机与后端深入手册》。

## 5. 内容量与工作量参考

以下为同类项目的常见量级，用于估算范围，不构成承诺；数字是尺子，用自己团队的速度校准。

| 内容 | 首个可玩版本 | 公开上线版本 | 备注 |
| --- | --- | --- | --- |
| 强侧角色 | 1 个 | 4-8 个 | 每个都带技能组、动画与全量对位测试，是产能大头。 |
| 弱侧角色 | 1-2 个（同模板） | 8-20 个 | 共用骨架与动画框架，差异放进工具与天赋。 |
| 地图 | 1 张灰盒 | 3-6 张 | 每张图要过路线、周旋点与目标分布的完整验证。 |
| 技能与天赋 | 每角色 2-3 个 | 每角色 3-4 个 | 复用框架，组合测试占大头。 |
| 系统 | 房间码与好友房 | 匹配、排位、举报、观战 | 后端是长期投入，从小规模起步也不省。 |

工作量量级（小团队，含联机经验）：

- 白盒原型（1 张图、1v4、好友房、无匹配）：2-6 周；首个可玩循环（含联机与最简匹配）：2-4 个月。
- 到能公开测试（匹配、反作弊、举报、双阵营内容起步）：6-12 个月，随做到哪一层浮动。
- 上线之后是持续账：新角色双份出、平衡双份测，先按《独立开发生存手册》的框架备好余粮。

小团队的现实警告：非对称把内容成本与平衡成本同时乘二，还要过人口这道硬门槛。砍法按优先级排：弱侧先做同模板（差异放进天赋与工具）；地图先做一张吃满内容期；变体先用规则开关（限时模式），而不是新地图。三条都嫌贵时，先考虑把对抗降级为非对称合作（分工互补的协作结构），内容与人口压力都会小一截。

## 6. 第一个原型怎么起步

目标：4-6 周，验证一件事：规则不对等，能不能让两边的人都想再开一局。不碰排位、不碰多角色、不碰赛季。

1. （第 1 周）追逐地基：一张灰盒图，双方先共用同一套移动与相机；强侧给一个主动技能（冲刺或投掷），弱侧给一个周旋手段（可消耗的障碍）。先验证「跑与追」本身好不好玩。
2. （第 2 周）目标循环：弱侧推进多处目标，完成终局条件后逃脱；强侧打断与收割；胜负、结算与「再来一局」进界面。
3. （第 3 周）信息与提示：距离心跳、目标进度、救援提示；把界面文字关掉测一轮，玩家能自己读懂局势才算合格。
4. （第 4-6 周）好友局测试与调参：找 5 人一组、至少三组，双方轮换阵营各打几局；只调数值与地图布局，不加新系统。

起步参数（可直接抄来改）：5 人局（1v4）；弱侧目标 4-6 处；单局目标 10 分钟上下；强侧主动技能冷却 15-30 秒（参考量级，按实测调）。

成功标准（全部可观察）：

- 拿掉全部美术与音效，两组测试者都愿意连玩三局以上。
- 两组玩家都主动要求轮换阵营；这一条不过，非对称就不成立。
- 弱侧至少发生过一次被主动复述的协作翻盘；强侧至少一次能说清「我是读出来的」，而不是运气。

原型期不做：多角色、匹配、排位、赛季、皮肤。例外是信息隔离：它改架构，从第一天做对，其余都是放大器。

## 7. 常见坑

1. **用对称思维配平**：追求「总体五五开」会抹掉差异本身；平衡看的是双重指标（§3.2），不是单一胜率。
2. **弱侧只会躲**：没有主动目标与工具，弱侧沦为猎物的扮演者；弱侧必须一直在推自己的进度。
3. **强侧强度曲线失控**：要么全程碾压、要么后期废掉；把「前期施压、中期被周旋、后期看关键决策」这类起伏设计出来。
4. **无敌点与必死死角**：一个绕不死的点位或一处死角，会让整张图的博弈塌掉；周旋资源要有消耗（§3.3）。
5. **信息全量下发**：客户端能拿到不该拿的，透视外挂一夜间废掉类型；可见性必须在服务端裁量（§4）。
6. **单局拖成僵持**：弱侧龟缩、强侧站桩互等；双向时间压力与终局规则必须写死。
7. **匹配池被切碎、供需失衡**：上线即多模式多段位，小众人口撑不住；一侧排队一侧秒进也会很快散场；第一版单池单模式，用激励调节配比（§3.4）。
8. **只更一边的内容**：半个产品的玩家觉得被放弃；每轮更新两边都要有东西（§3.5）。
9. **掉线与挂机规则缺席**：5 人局少 1 人即崩；重连、托管、判负与信誉系统一起进第一版。

## 延伸阅读

- 《游戏设计手册》：核心循环、数值与验证方法，第 1、3 节的底稿。
- 《技术实现手册》：架构、网络与性能，第 4 节的配套。
- 《联机与后端深入手册》：同步、匹配、反作弊与成本，第 3.4、4 节按它执行。
- 《电竞与竞技设计手册》：平衡方法论与观战预留，第 3.2 节的展开。
- 《独立开发生存手册》与《避坑大全》：范围、排期与高频坑位，与第 5、7 节互为补充。
- 《类型手册 · 社交推理》（第三辑）：边界见第 1 节。
- 作业：拉 4 个朋友开一局非对称对抗的自定义房，双方各打一轮，赛后每人回答两个问题：「赢的一方赢在哪个决策」「你愿意换边再打吗」。第二个问题答「不愿意」的人，正是你要设计去说服的玩家。
